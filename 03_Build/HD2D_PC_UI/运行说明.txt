冒牌炼金术士 · Windows 最新测试版

运行方式
完整解压 ZIP，双击“启动Demo.cmd”。请保留旁边完整的 Windows 文件夹，不要单独转发 EXE 或 CMD。
运行无需安装 Unreal Engine。通过 Git 获取时先执行 git lfs install 和 git lfs pull。

操作
WASD 移动，Space 闪避，技能自动瞄准敌人。
在村庄上方入口附近按 F 进入关卡选择；图鉴台、强化台也使用 F 交互。
Tab 炼金，C 图鉴，B 技能储备，Esc 暂停/返回。
F7 调整中号和大号字体；推荐起点90%/72%。

本次重点
新增局内流浪商人：教学完成后在约80/175/265秒附近出现，靠近金色标记按F交易。
商人现使用独立紫帽旅行者立绘，出场有金青炼金环、聚拢光点及短促粒子，约1.4秒后自动消散。
商人增加逐帧呼吸眨眼待机与招手：出场后招手，靠近时按8秒冷却再次招手，交易/暂停时动画一起暂停。
三个随机货位可重复但至少两种，支持购买、卖1、确认全卖；刷新消耗本局金币，费用5/10/15/20/25封顶。
交易界面暂停战斗与离场计时。Boss预警后商人离场；Boss开场清怪并收入奖励，战圈限制移动，具有冲刺、扇形弹幕和直线冲击波。
炼金术士具有侧面、正面、背面待机、走路、投掷、受击和死亡动作；向左使用镜像。
基础攻击投掷药瓶，命中出现玻璃碎片和药液飞溅。
移动时角色保持走路方向，药瓶独立瞄准敌人；停下播放完整投掷。可重点测试“向左走、敌人在右边”的情况。
受伤播放受击，生命归零后倒地，再显示结算。

存档和反馈
此分发ZIP不包含玩家存档、PDB或调试证据。更新已有运行目录时请保留 Saved 中的存档。
反馈问题请附上截图、操作步骤和分辨率；请分别留意动作衔接、药瓶命中、遮挡和移动方向。
这是可玩原型测试版，完整通关、满场性能和战斗平衡仍需继续试玩验证。

快捷测试
双击“测试商人.cmd”直接进入独立商人测试局；双击“测试Boss.cmd”直接进入独立Boss测试局。
这两个入口使用临时进度，不读取或覆盖正常试玩存档。普通启动Demo.cmd仍从据点开始。
