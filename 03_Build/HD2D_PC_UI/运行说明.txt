冒牌炼金术士 Demo（Windows PC）

运行：完整解压本压缩包到任意目录，双击“启动Demo.cmd”。
启动脚本必须和完整的 Windows 文件夹放在一起。不要单独转发 CMD 或 EXE。
运行不需要安装 Unreal Engine；源码 Build.ps1 的引擎路径只影响重新编译。
若使用 Git 获取，先 git lfs install，再 git lfs pull，确保拿到真实的 EXE/DLL/资源，而非指针文本。

字体调试：游戏中按 F7，或点击任意面板右上“F7 字体调试”。
小号固定100%；中号、大号分别以1%或5%步进调整，立即生效并保存。
推荐起点中号90%、大号72%。请反馈“中号XX%、大号YY%、窗口分辨率”。
F7 或 Esc 关闭面板；调试时战斗暂停。WASD移动、Space闪避、Tab炼金。

本包不包含玩家存档、调试证据和PDB。已有本地运行目录的存档不会被本次打包覆盖。

本轮：普通小怪无血条，精英常驻，Boss条移至上方。金币、六类材料和宝箱使用放大图标。
关卡/技能编辑工具在完整UE工程中使用：打开02_Prototype/AlchemyHD2D/打开关卡与技能编辑器.cmd。试玩ZIP不包含Unreal编辑器。
