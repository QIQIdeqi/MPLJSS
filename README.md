## 获取完整资源

本仓库使用 Git LFS 保存UE资源、打包程序与其他大二进制文件。请安装 Git LFS，再克隆：

```sh
git lfs install
git clone https://github.com/QIQIdeqi/MPLJSS.git
cd MPLJSS
git lfs pull
```

仅下载网页上的单个LFS文件可能得到指针文本；运行当前Demo需要完整的 `03_Build/HD2D_PC_UI/Windows` 目录。UE缓存、编译中间产物及本机运行存档不纳入版本控制。
