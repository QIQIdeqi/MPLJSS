# 3. 玩家操作与技能控制

## 3.1 输入规则

| 输入 | 已确认行为 | 待确认细节 |
|---|---|---|
| WASD | 控制玩家移动 | 移动速度、斜向移动是否归一化等数值 / 细节待确认。 |
| Space | 触发短距离冲刺 / 闪避，冲刺期间无敌 | 冲刺方向、距离、持续时间、冷却或次数限制待确认。 |
| 鼠标位置 | 决定部分指向性技能的释放方向 | 鼠标屏幕坐标转世界坐标的实现细节及鼠标位置无效时的处理待确认。 |
| 基础普攻 | 首测沿用自动攻击，不单独新增普攻键 | 攻击形态、目标与数值待验证。 |
| 炼丹入口 / 起炼输入 | 默认由玩家单独操作，与基础攻击分开 | 具体键位、确认方式与可重映射方案待验证。 |
| 炼制过程输入 | 按局外选择的炼金模式执行驻留、回收、择时等操作 | 具体窗口和打断代价见第 12 章，数值待验证。 |

“不设置独立普通攻击键”只表示首测沿用自动基础攻击，不表示取消基础普攻。基础普攻的攻击形态和数值待验证；炼丹是额外主动操作。

## 3.2 基础攻击与丹药技能规则

**已确认规则：**

1. 基础普攻支撑吸血鬼like 的持续清怪、生存和收集；玩家成长主要依靠炼丹获得、强化和改造技能。
2. 炼丹默认需要单独操作；局外模式或明确的局内因素可将指定环节改为自动或条件触发。炼丹主动操作与丹药技能是否自动发动分别配置。
3. 默认自动攻击目标优先选择距离最近的敌人。
4. 对于指向性技能，技能仍可自动触发，但释放方向由鼠标位置决定；这不等同于玩家点击鼠标主动施法。

**规则整理：**

- 一般自动目标技能：在该技能可选目标中，优先选择距离最近的敌人。
- 鼠标指向技能：技能触发时，根据当前鼠标位置确定释放方向。
- 完善建议：已装备丹药先沿用冷却／条件自动发动，特殊丹药再按独立技能规格定义主动施放；不要求玩家每次攻击都重新配料。
- 已制成的丹药不会每次发动都重抽本体或词条，也不重复消耗制丹用的成长材料。
- 玩家是否可在技能执行时继续移动、自动目标技能的有效射程、无合法目标时的处理、技能冷却从何时开始计算，均为待确认项。

## 3.3 目标选择与方向

默认目标优先级是“距离最近的敌人”。具体技能的目标类型、射程、目标过滤条件尚未确定，因此不能默认所有技能都攻击最近单位，也不能默认所有技能都使用鼠标方向。

| 技能控制类型 | 触发方式 | 目标 / 方向规则 |
|---|---|---|
| 自动目标技能 | 满足冷却或触发条件后自动释放 | 默认优先选择距离最近的敌人 |
| 鼠标指向技能 | 满足冷却或触发条件后自动释放 | 按鼠标位置确定方向 |
| 炼丹过程效果 | 由炼金模式规定的泄药、起炉或完成事件触发 | 按器具位置、玩家位置或模式定义的目标执行；完整成品与过程效果分别结算 |
| 其他特殊技能 | 待具体技能设计确定 | 待确认 |

# 4. 玩家生命、受伤与无敌规则

## 4.1 玩家受伤来源

目前明确存在以下伤害来源：

- 玩家与怪物接触产生的接触伤害；
- 怪物主动近战攻击产生的攻击伤害；
- 远程怪物投射物命中造成的攻击伤害；
- 精英怪与最终 BOSS 的攻击伤害。

各类伤害的具体数值、抗性、减伤、暴击或其他属性机制尚未确认，本文不定义相关公式。

## 4.2 受伤结算流程

**规则整理：**

1. 战斗系统产生一次伤害请求，记录伤害来源与所属攻击实例。
2. 检查玩家是否处于受伤无敌或闪避无敌状态。
3. 若任意一种无敌状态生效，本次伤害不扣除生命值。
4. 若均未生效，则按对应攻击的配置扣除生命值，并触发受击表现与受伤无敌。
5. 玩家生命值归零时，立即结束本局并进入失败结算。

> **待确认：** 受伤无敌期间被判定无效的接触伤害，是否仍消耗接触伤害计时；无敌结束时，持续接触是否立即造成一次伤害。该规则尚未确定，不能由程序自行选择最终行为。

## 4.3 受伤无敌与闪避无敌

| 规则项 | 已确认规则 |
|---|---|
| 受伤无敌触发 | 玩家受到有效伤害后触发。 |
| 闪避无敌触发 | 玩家执行 Space 闪避 / 冲刺期间触发。 |
| 计时方式 | 两种无敌独立计时，彼此不覆盖。 |
| 持续时间 | 两种无敌使用相同的持续时间配置值；具体时长待确认。 |
| 免疫范围 | 任意一种无敌生效时，免疫所有来源的伤害。 |
| 同时存在 | 两个计时器可以同时处于生效状态；只要其中任意一个有效，就不接受伤害。 |

**实现建议：** 用两个独立状态计时器 `HurtInvulnerabilityTimer` 与 `DodgeInvulnerabilityTimer`；它们读取同一配置值 `SharedInvulnerabilityDuration`。统一伤害入口只需判断任意计时器是否有效，避免不同攻击组件各自实现无敌判断。

## 4.4 接触伤害规则

**已确认规则：**

1. 玩家与怪物首次接触时触发一次接触伤害判定。
2. 在持续接触期间，按固定间隔继续判定接触伤害。
3. 接触伤害间隔为配置项，具体时间待确认。
4. 玩家处于任意无敌状态时，不会因该次伤害判定而扣除生命值。
5. 怪物处于主动近战攻击期间，只计算主动攻击伤害，不额外计算该怪物的接触伤害。

**待确认：** 接触结束后再次接触是否重置计时、无敌期间接触伤害计时是否继续运行，需由项目方进一步确认。

## 4.5 受击反馈

**已确认规则：** 玩家被攻击命中后播放受击表现，但不影响玩家移动。

受击表现的具体动画、闪烁、音效、屏幕反馈与时长尚未确认。不得在未确认的情况下增加强制硬直、击退或移动锁定。

## 4.6 玩家死亡

玩家生命值归零时，立即结束本局并进入失败结算。失败界面的内容、重新开始 / 返回菜单流程及局内奖励结算归属，由整体 UI / 系统策划案另行确定。

# 5. 闪避 / 冲刺规则

## 5.1 已确认规则

- 通过 Space 触发闪避 / 短距离冲刺。
- 冲刺期间获得无敌效果。
- 闪避无敌与受伤无敌独立计时，但使用相同的持续时间配置值。
- 任意一种无敌生效时，免疫所有伤害。
- 闪避冲刺的具体移动距离与数值参数待确认。

## 5.2 待确认的实现输入

| 项目 | 当前状态 |
|---|---|
| 冲刺方向 | 待确认：按当前 WASD 输入、面向方向或其他规则。 |
| 无移动输入时按 Space | 待确认。 |
| 冲刺距离 / 速度曲线 | 待确认。 |
| 冲刺冷却、次数或资源消耗 | 待确认。 |
| 冲刺是否受地形碰撞限制、撞墙时如何处理 | 待确认。 |
| 冲刺能否穿过怪物或障碍物 | 待确认；无敌不自动代表可穿越障碍。 |

**实现边界：** 当前只确认“短距离冲刺 + 冲刺期间无敌”，不代表角色可穿墙、瞬移或免疫碰撞以外的控制效果。

**炼丹输入的完善建议：** Space 保留紧急闪避职责；择时炼制先使用独立、可重映射的确认输入。若后续验证共用 Space，则必须明确界面提示、状态切换及闪避优先级，不能让炼丹品质窗口吞掉救命输入。闪避可中止需要驻留的动作，但不因此删除已有丹药技能。

# 6. 敌人共通战斗规则

## 6.1 行为按怪物配置

普通怪物存在近战与远程等多种行为。不同近战怪物、不同远程怪物可以分别配置行为，不采用所有敌人共用同一套 AI 的设计。

## 6.2 遇到障碍物

**已确认规则：** 怪物遇到不可穿越障碍物时，尝试绕过障碍物继续追击玩家。

远程攻击另有单独规则：怪物在攻击范围内即可尝试发动远程攻击，不要求与玩家之间的视线无遮挡；但远程投射物遇到不可穿越障碍物会被阻挡。因此，“能否发动攻击”与“投射物能否穿过障碍物命中玩家”必须分开判定。

## 6.3 攻击预警

| 攻击类型 | 反馈规则 |
|---|---|
| 普通攻击 | 不强调明显预警。 |
| 强力攻击 | 必须提供提示，让玩家有机会观察并躲避。 |
| 精英怪强力攻击 | 需要预警。 |
| 最终 BOSS 大范围强力攻击 | 需要预警并要求玩家躲避。 |

具体预警形态、显示时间、视觉资产与音效尚未确定；最终 BOSS 登场预警属于关卡事件，持续时间为 10 秒。

## 6.4 单次攻击命中限制

**已确认规则：** 同一次攻击对玩家最多造成一次伤害。即使玩家持续处于同一次攻击的伤害区域，也不能仅因为区域仍然存在而反复扣血。

**实现建议：** 为每次独立攻击分配 `AttackInstanceId`，记录该次攻击是否已经命中过玩家。伤害区域持续存在时，不得对同一玩家重复结算同一攻击实例。新的独立攻击实例可以重新命中，但仍受玩家无敌状态约束。

# 7. 普通怪物行为配置

## 7.1 近战怪物

不同近战怪物分别配置行为，至少包括以下已确认的行为方向：

| 行为类型 | 行为规则 |
|---|---|
| 接近型近战怪 | 主动接近玩家，但不主动发动攻击；玩家仍会因接触而受到接触伤害。 |
| 主动近战攻击型 | 接近玩家，进入其攻击范围后主动攻击。主动攻击期间只计算攻击伤害，不额外计算接触伤害。 |

具体每种怪物属于哪一种行为、攻击范围、移动速度、攻击冷却、伤害值待怪物配置与数值设计确认。

## 7.2 远程怪物

不同远程怪物分别配置行为与投射物规则。目前已确认两种行为方向：

### A. 攻击后按攻击范围追击

1. 怪物按自身规则尝试攻击玩家。
2. 若攻击冷却结束，但玩家位于攻击范围外，则不能发动该次远程攻击。
3. 当玩家超出该怪物的攻击范围时，怪物继续追击玩家，直至重新进入攻击范围。
4. 进入攻击范围且攻击冷却已结束后，才可发动攻击。

### B. 攻击后主动接近玩家

1. 怪物完成首次远程攻击后，主动靠近玩家。
2. 攻击冷却在移动期间持续计时。
3. 冷却结束后，仍必须满足攻击距离条件才可发动攻击。
4. 满足攻击条件后，怪物在当前位置发动远程攻击，随后继续主动靠近玩家。

> **行为冲突检查：** “冷却结束”只代表招式可进入距离检查，并不自动代表可以无视攻击距离立即发射投射物。

## 7.3 普通怪物受伤与死亡

普通怪物对玩家造成接触伤害或主动攻击伤害的具体数值待数值策划确定。普通怪物的生命值、受击表现、死亡动画、死亡清理时机和掉落规则不在当前战斗规则中具体冻结；关卡和奖励系统须另行定义普通怪物的掉落。

# 8. 精英怪战斗规则

## 8.1 战斗定位

**已确认规则：**

- 精英怪拥有高于普通怪物的生命值或攻击能力（具体体现可按精英怪配置确定，当前未要求每只精英怪同时高于两者）。
- 精英怪拥有需要玩家躲避的强力攻击，并且强力攻击必须有预警。
- 精英怪的具体攻击行为和数值尚未逐只设计。

## 8.2 与关卡系统的交互

- 精英怪由关卡的时间窗口、固定刷新间隔和轮换顺序配置生成；此规则由关卡策划案负责。
- 精英怪死亡后必定掉落宝箱；玩家靠近宝箱后自动开启。
- 宝箱奖励包括该精英怪对应的专属材料，并额外获得普通炼金材料。
- 材料种类、数量、随机规则与库存入账时机待系统 / 数值策划确认。

## 8.3 精英怪制作要求

每只精英怪至少需要在配置中指定其战斗行为与强力攻击。强力攻击的预警、命中区域、伤害参数与动画时序须有明确数据；在具体攻击设计未确定前，不应以普通怪物参数直接替代所有精英怪行为。

# 9. 最终 BOSS 战斗规则

> 本章原 5:00 预警、5:10 原图强制出 Boss 的时序是历史基线。当前采用 1.4关卡中已确认的主动传送与独立 Boss 场地；双阶段、攻击预警和命中规则在没有后续覆盖时仍有效。本次炼丹修订不另行改动 Boss 招式与数值。

## 9.1 Demo 最终 BOSS 的定位

- Demo 只有一个最终 BOSS。
- 生存计时达到 5:00 时开始登场预警；预警持续 10 秒游戏内有效时间，结束后 BOSS 正式出现，即当前规则下的 5:10。
- BOSS 主动寻找并追击玩家。
- 拥有大范围强力攻击，需要玩家观察预警并躲避。
- 生命值下降至配置阈值后进入第二阶段。
- 主要通过较高生命值、攻击能力和攻击频率形成挑战；具体数值待确认。
- 击败最终 BOSS 后结束整局；最终 BOSS 当前暂定不掉落宝箱或材料。

## 9.2 双阶段规则

| 项目 | 第一阶段 | 第二阶段 |
|---|---|---|
| 可用攻击 | 第一阶段配置的攻击招式 | 保留第一阶段攻击，并加入第二阶段新招式 |
| 阶段切换条件 | 当前阶段，等待配置的生命值阈值触发 | 第二阶段为最终阶段；不会按当前已知规则再次转入第三阶段 |
| 阶段阈值 | 第一阶段触发第二阶段的阈值由 BOSS 配置表单独配置 | 具体值待确认 |
| 生命值 | 正常扣除 | 阶段切换时保留剩余生命值，不恢复 |

## 9.3 阶段转换规则

当 BOSS 生命值达到配置的第二阶段阈值时：

1. 触发短暂的阶段转换动作。
2. BOSS 原地执行转换动作，不移动。
3. 转换期间 BOSS 暂停发动攻击。
4. 玩家仍然可以移动、闪避和攻击 BOSS。
5. BOSS 在转换期间仍可正常受到伤害，不获得额外无敌状态。
6. 转换完成后，进入第二阶段；保留剩余生命值。
7. 转换持续时间由 BOSS 配置表单独配置。

**待确认的边界情况：** 如果 BOSS 在转换动作尚未结束时生命值归零，应由死亡流程优先终止阶段转换；该处理符合常见状态机实现，但尚未由项目方单独确认。转换开始前已生成、尚未结束的攻击区域或远程攻击如何处理，也待确认。

## 9.4 BOSS 攻击招式选择

**已确认规则：**

- BOSS 根据攻击冷却，从当前可用招式中选择。
- 每个招式支持独立随机权重。
- 当多个招式同时可用时，根据配置权重随机选择。
- 尽量避免连续两次选择相同招式；如果还有其他招式可用，优先从其他招式中选择。
- 如果除上一招式外没有其他可用招式，则允许继续选择该招式。

**规则整理后的选择流程：**

1. 读取当前阶段允许使用的招式集合。
2. 筛选冷却已经结束、当前阶段允许使用的招式。
3. 若候选中包含上一次使用的招式，且至少存在一个其他候选招式，则从候选中排除上一次招式。
4. 按候选招式的随机权重进行抽选。
5. 执行被选中的招式并记录最近使用的招式。

> **待确认：** 权重为零、所有可用招式权重均为零、攻击条件除冷却外是否需要玩家距离或其他判定，以及冷却计时从攻击开始还是攻击结束时起算，均需要在具体 BOSS 招式配置前明确。

## 9.5 BOSS 攻击流程

- 普通攻击使用统一的流程结构；不同招式的时间参数可以独立配置。
- 强力攻击采用独立配置的执行流程，并需要提供预警。
- BOSS 攻击在攻击动画的指定帧生成伤害区域。
- 同一次攻击对玩家最多造成一次伤害。
- 攻击范围与伤害区域的形状、位置和范围尚未确定，不能在本版中假设所有攻击都使用相同的圆形区域或扇形区域。

可配置的攻击流程字段建议见第 15 章。普通攻击统一的是流程结构，而不是所有招式共用相同时间参数。

# 10. 攻击流程、命中与伤害区域

## 10.1 BOSS 攻击的通用执行框架

**实现建议：** 统一执行状态可组织为：

`选择招式 → 前摇 / 准备 → （强力攻击预警）→ 攻击动画 → 指定帧生成伤害区域 → 攻击恢复 → 等待下一次选择`

该状态名称是便于程序组织的技术方案；强力攻击可以按自身配置使用不同流程。具体阶段是否全部必需，由该招式的设计决定；不应在没有数据时强制每个招式都必须播放相同阶段的演出。

## 10.2 攻击实例与单次命中

- 每个独立攻击执行过程建立独立的攻击实例。
- 一个攻击实例对玩家最多造成一次伤害。
- 伤害区域可以在配置指定的动画帧出现；区域形状、尺寸、位置、持续时间需要由具体攻击配置。
- 伤害区域持续期间，不因为每帧仍检测到重叠而重复扣血。
- 新的独立攻击实例可以重新判断命中，但玩家仍受无敌状态约束。

## 10.3 命中判定与玩家无敌判定的顺序

**实现建议：**

1. 攻击实例在配置的时机创建或启用伤害区域。
2. 检测玩家是否进入伤害区域。
3. 检查该攻击实例是否已命中过该玩家；若已命中，不再为同一实例重复结算。
4. 若未命中，向统一伤害入口提交伤害请求。
5. 统一伤害入口检查受伤无敌与闪避无敌；若任意一种生效，则忽略该伤害请求，不扣血。
6. 若伤害有效，扣除生命值、记录本次命中并触发受伤无敌与受击反馈。

这里需要程序实现时注意“攻击实例最多命中一次”与“玩家无敌期间忽略伤害请求”的先后关系。建议即便该次攻击被无敌拦截，也不要因为攻击区域持续存在而在每帧重复提交同一伤害请求；但无敌结束后是否仍应允许同一个仍存在的区域命中，需依据攻击实例的单次命中规则处理。该边界建议在实现前通过测试样例固定。

## 10.4 伤害区域配置项

目前仅确认 BOSS 攻击会在指定动画帧生成伤害区域，以及所有攻击对玩家单次最多造成一次伤害。下列具体字段须由攻击设计确认：

- 伤害区域形状；
- 区域相对 BOSS 的位置 / 朝向偏移；
- 区域大小与范围；
- 区域启用时长；
- 生效动画帧或对应事件标记；
- 伤害数值与伤害类别；
- 是否拥有强力攻击预警及预警表现。

# 11. 远程投射物规则

## 11.1 已确认规则

1. 不同远程怪物可配置不同投射物飞行规则。
2. 攻击冷却结束后，仍需满足攻击距离才能发动远程攻击。
3. 远程攻击发起不要求与玩家之间的视线无遮挡。
4. 投射物会被不可穿越障碍物阻挡。
5. 普通攻击不强调预警；强力攻击需要提示。

## 11.2 投射物类型

可以按具体怪物配置直线飞行、追踪等行为，但这些是可支持的类型示例，不代表 Demo 已经确定必须制作其中所有类型。每只远程怪物使用哪些投射物，仍需在怪物设计中单独确认。

## 11.3 判定顺序

**规则整理：**

- 怪物先执行攻击距离检查；超出攻击范围时不能因冷却结束而无视距离发射。
- 满足距离条件后，怪物按照其投射物配置发射攻击。
- 投射物按自身配置更新位置 / 轨迹。
- 投射物遇到不可穿越障碍物时被阻挡，不应穿过障碍物继续命中玩家。
- 由于没有要求攻击发起前视线无遮挡，因此不能以“被墙遮挡”为唯一理由阻止怪物开始攻击；是否发射后立即碰到墙由投射物碰撞决定。

投射物速度、寿命、碰撞半径、碰墙效果、命中后的表现、是否可穿透多个目标等均待确认。

# 12. 丹药技能、材料重炼与局外炼金模式

## 12.1 设计目标与确认边界

目标：让玩家在持续清怪的压力下，通过选材和炼制操作逐步塑造自己的技能，能够解释结果、保留满意构筑，并主动调整不满意的部分。

**已确认方向：**

- 丹药实际就是本局技能；变强主要靠继续炼丹、重炼和强化。
- 制丹结构为“必要材料＋辅助材料／特殊材料”，保留一定随机性，同时由材料种类和数量提供明确倾向。
- 换主要材料根据材料重抽技能本体；换辅助材料根据材料重抽效果词条。
- 材料分等级，等级影响技能或对应效果的强度；炼制操作影响品质、稳定性及正负变异。
- 炼丹默认需要单独操作，局外可选择炼金模式，角色、遗物等局内因素也可能改变指定操作环节。
- 普通小怪减少材料掉落，以少量碎片自动归集形成材料；不同地图提供不同材料生态与药方。

以下具体继承、拒绝结果、模式代价和结算细节为完善建议；不把此前五工艺直接定为五个英雄，也不沿用旧六槽、固定投料量或品质概率作为新规则。

## 12.2 一局中的炼丹循环

`局外选择炼金模式 → 进入箱庭地图 → 基础普攻、走位与清怪 → 回收碎片并形成材料 → 选择新制／强化／重炼 → 按模式完成炼制 → 装备或保留丹药技能 → 继续战斗和积累材料`

**完善建议：** 材料足够时提示可炼，不强制弹出界面。玩家主动选择目标丹药和材料，可以立即提升，也可以攒料追求更高等级或更明确的词条倾向。选材与结果比较界面暂停战斗；起炼后返回战场执行所选模式，炼制计时与战斗时间一起推进。

制丹／重炼消耗成长材料。已装备丹药的药效按技能条件反复发动，不再次消耗这些材料；如果个别技能有战斗消耗，需单独定义。首次炼丹前、库存见底或 Boss 无补给时，基础普攻和已装备技能仍可运行。

## 12.3 材料如何控制结果

丹药技能由四部分构成：技能本体、基础强度、效果词条、正负变异。材料与操作的职责如下：

- **必要材料／主材：** 决定本次技能候选及属性倾向。例：木炭偏向火系，改变主材种类或比例会改变技能本体的候选权重。
- **辅助材料：** 提高某类效果词条的出现概率。例：扩散类材料使范围、分裂、溅射等兼容词条更容易出现；并非一定获得某个指定效果。
- **特殊材料：** 候选用途为锁定本体、保留指定词条、净化负面或定向转换；每种材料只执行其明确写出的功能。普通倾向材料与确定转换材料必须在界面中区分。
- **材料数量：** 改变对应标签的倾向和投入价值，不把每多一份材料都等同于增加一个技能或词条槽。
- **材料等级：** 主材等级影响基础强度，辅材等级影响对应效果强度；等级与概率倾向分开配置，不能用高级材料保证掉出完全不同的技能。
- **炼制操作：** 影响品质、稳定性和变异风险；正常操作不从无关候选池随机改写整颗丹药。

投料前显示可出现的技能类别、词条方向、材料消耗、锁定内容和变异风险；只有配置支持时才显示具体概率。药方限定合法材料与候选范围，地图药方改变可尝试的方向，但不预先指定本局唯一构筑。

## 12.4 新制、强化与分层重炼

**已确认的分层原则：** 主材管“是什么技能”，辅材管“技能怎样变化”，等级管“有多强”，操作管“结果有多稳定”。

**完善建议：**

- **新制丹药：** 必要材料足够即可起炼；辅材用于塑造效果，特殊材料用于控制结果。辅材是否为具体药方的必需项由药方注明。
- **同方温养／强化：** 保留满意的本体与词条，把同方向材料投入成长，先提供稳定提升的路径。升阶阈值及高等级材料要求待验证。
- **换辅材重炼：** 保留技能本体与已有成长，只重抽所选效果层；普通辅材改变候选倾向，特殊材料可按规则锁定或转换指定词条。
- **换主材重炼：** 根据新主材重抽技能本体，不默认再把全部效果词条一起洗掉。首测建议只纳入能兼容保留词条的技能；无合法候选则提交前提示，不扣料。
- **成长继承：** 已投入的丹药成长不因一次换材直接清零；新主材仍决定新本体的基础强度。成长折算、低等级材料替换及不同本体的强度预算另行验证，界面预览可能的强度变化。
- **特殊材料干预：** 锁定、净化或转换只作用于明确指定的层。锁定冲突、材料不匹配或无候选时不能开始炼制。

例如，玩家已有带范围词条的火弹丹：继续投入同方向材料可以强化；换扩散辅材时仍是火弹，但效果可能偏向更大范围或溅射；换主材时技能本体进入新材料对应的候选池，保留的范围词条与成长按上述继承规则处理。例子说明改造层次，不是已冻结药方或概率表。

## 12.5 不满意结果的处理

**完善建议：** 重炼完成后比较旧丹与新丹，显示本体、强度、保留／变化词条和负面变异。玩家可以接受新丹，也可以保留旧丹；保留旧丹仍消耗本次已用于炼制的材料，避免强制洗坏构筑，也避免无成本反复抽取。

首次制丹的不满意成品可不装备，暂存或回收的容量与收益待验证。负面变异必须说明实际代价，并有后续重炼或对应特殊材料的处理路径；不能要求先集齐稀有组合才有可用攻击。

一次完成只生成一个结果。关掉结果页、重新进入或恢复存档不再次抽样；新结果被接受前，旧丹仍是生效技能。替换本体不作为免费重置技能冷却或补发一次攻击的手段。

## 12.6 局外炼金模式

**已确认方向：** 局外可以改变炼金模式。开局前选择模式，决定本局如何投入、操作、完成及交付丹药；材料仍决定技能与词条。不同模式是战斗节奏与风险的选择，局外成长可解锁模式或变体，具体解锁条件待验证。

候选模式及代价均为待验证设计，不要求首版全部制作：

- **随身试剂：** 边移动边炼，维持游走与收集；候选代价是炼制较慢或精炼收益较低。
- **驻留坩埚：** 留在原地维持炼制，可按规则向周围泄出药效；候选代价是驻留暴露和被迫离开造成的炼制损失。
- **布置丹炉：** 投料后离开，完成后回来处理或取丹；候选代价是绕路回收、器具过热或受袭。具体风险须在起炼前提示。
- **择时炼制：** 观察火候并在窗口内确认，操作影响品质与变异；紧急闪避能退出操作，不能为追求品质禁止逃生。
- **条件炼制：** 玩家先配置材料、目标丹药及改造层，满足明确条件后自动执行指定炼制环节；材料不足或未配置时不触发，不自动花料重抽玩家未选中的技能。

基础手动炼制从首局可用，局外选择不锁住基础普攻或必要操作提示。首测建议每局只选一个主模式；局内因素可以明确改变某个环节，不默认同时叠加五套操作。模式对品质、速度或变异的影响需显示，不能出现毫无代价的全自动模式全面优于手动模式。

## 12.7 炼制、过程伤害与结算边界

**完善建议的结算顺序：**

1. 配置阶段选择目标、主辅材料和特殊材料；取消配置不扣料、不抽结果。
2. 确认起炼时检查库存、合法候选、保留项及技能容量；有效后一次性扣除本次材料，建立一炉的独立记录。
3. 进入战场执行模式。过程中显示进度、火候、危险和可中止状态；所有实际炼制进度随系统暂停一起冻结。
4. 完成时按材料倾向和操作结果生成一次新丹；失败、泄药或提前终止按模式结算，已有丹药不被删除。
5. 结果页选择接受或保留旧丹；未处理完本炉前不能对同一目标重复提交。条件触发、回收和完成事件均只能结算一次。

部分炼制可以在过程中或失败时产生原地伤害，但过程伤害、完整成品和材料返还分别定义。首测建议起炼后的失败／拒绝不全额返料；若模式允许恢复进度或返料，应写出代价。禁止“故意取消造成伤害＋材料全额退回”的无限输出循环。器具伤害沿用战斗命中和状态接口，不绕开统一结算。

## 12.8 箱庭、供给与首版范围

箱庭提供绕行、驻留点、放炉地点及回收路线，持续怪潮仍是战斗压力。普通怪少量掉碎片并自动归集为材料，减少逐个拾取与打开背包的频率；碎片合成阈值、库存和溢出处理待验证。各地图的材料生态和药方须覆盖基础炼丹与成长路径，不能把通用玩法只放在某张地图的稀有掉落中。

首版建议先验证一套手动模式和一个有明显操作差异的局外模式，以及新制、同方强化、换主材、换辅材、特殊材料控制和旧新结果比较。技能数量、丹药槽位、词条上限、投入数量、等级曲线和掉落节奏在该闭环验证后确定。

## 12.9 炼金反应的后续接口

元素反应作为后续扩展，先保证单颗丹药和重炼循环独立成立。旧“收齐指定技能才出连锁”不作为新炼丹体验的前置门槛；本轮不冻结具体元素反应公式。

实现时区分制丹起炼／完成、技能替换、药效发动、技能命中、状态施加／结束和伤害完成事件。制丹改变构筑，技能命中参与战斗反应；不能把重炼完成当作击中敌人，或用反应事件自动重炼导致递归。

# 13. 暂停与战斗计时

## 13.1 已确认规则

打开任何局内系统界面时，整个游戏模拟与所有计时暂停。

暂停范围至少包括：

- 玩家与敌人的移动及 AI 行为；
- 普通怪物、精英怪与 BOSS 的生成计时；
- 生存计时与 BOSS 预警倒计时；
- 攻击前摇、强力攻击预警、攻击恢复与攻击冷却；
- 远程投射物和伤害区域的模拟；
- 受伤无敌、闪避无敌及接触伤害的游戏内计时。
- 炼制进度、丹炉计时、品质窗口、模式条件累计及过程药效的游戏内计时。

上表是“整个游戏模拟与所有计时暂停”的直接实现范围。界面自身必须完成的按钮交互或 UI 动画不属于战斗模拟；其是否播放不影响上述游戏逻辑冻结。

## 13.2 恢复规则

关闭局内系统界面后，从暂停时保存的游戏状态与剩余计时继续执行，不应把 BOSS 预警、技能冷却或生成间隔重置为初始值。

**待确认：** 多个系统界面之间切换时的暂停计数方式、是否允许暂停期间调整技能 / 装备、以及最终结算界面是否复用同一暂停系统，需由 UI / 系统策划补充。

**炼丹的完善建议：** 选材与旧新丹比较属于暂停界面；战场上的驻留、火候和丹炉进度属于游戏模拟。不能在暂停的配料界面中等待炉子完成或累积条件触发进度。关闭界面从剩余进度恢复，不因重开界面获得免费炼制或重抽结果。

## 14.1 程序实现约束

- 所有伤害来源应统一调用玩家伤害入口，不要让各敌人组件绕开无敌状态直接扣除生命值。
- 攻击实例需可追踪，以保证同一次攻击不因碰撞持续存在而多次扣血。
- 受伤无敌与闪避无敌分开计时，但读取同一个持续时间配置。
- 游戏暂停应冻结所有游戏内逻辑时钟，而不只是停止玩家输入。
- 敌人行为与攻击招式数据应可配置，避免为每只怪物复制整套攻击系统。
- 炼金连锁规则尚未确认，当前只建立可扩展接口，不在程序里硬编码某个毒 + 火组合为最终通用规则。

新增炼丹验收方案（规则检查与建议验证分开，以下尚未执行）：

- **CMB-027 主材重炼：** 改变主材后使用对应技能候选及权重；保留层不被无关随机改写。
- **CMB-028 辅材重炼：** 改变辅材后技能本体不变，词条候选方向可解释；扩散倾向与确定转换有不同提示。
- **CMB-029 等级与强化：** 材料等级影响对应强度；同方强化提供稳定成长路径，换材继承按实际采用规则验收。
- **CMB-030 特殊材料：** 锁定／转换只作用于声明的层；无候选、锁定冲突和材料不足均不扣料。
- **CMB-031 旧新丹比较：** 接受前旧技能仍可用；拒绝不强制洗坏构筑，且不形成免费反复抽取。
- **CMB-032 局外模式：** 同一配料在不同模式下呈现不同操作或交付方式，材料倾向保持一致；首局已有可用基础模式。
- **CMB-033 自动条件：** 未配置、材料不足、已有待处理炉时不重复起炼；回收与完成重复事件不重复给药。
- **CMB-034 暂停与打断：** 配料／结果页冻结炼制计时；恢复不重抽。紧急闪避有效，打断不删除已有技能。
- **CMB-035 供给与箱庭：** 低掉落情况下仍可进行基本战斗和成长；放炉后可达可回收，零补给 Boss 不令已有技能失效。
- **CMB-036 失败利用：** 不存在故意失败反复输出且全额返料、换丹刷冷却或重开界面刷结果的循环。

- 同时持有／装备的丹药数量、暂存与回收规则、词条数量及锁定成本；旧六槽不直接作为新确认值。
- 材料数量如何修正候选权重，主辅材等级如何影响强度，以及合法药方与兼容词条的边界。
- 稳定强化的升阶曲线、换主材后的成长折算、低等级主材替换及技能强度预算。
- 起炼后失败、提前泄药、闪避打断、器具受袭的成本、是否恢复进度与成品质量规则。
- 各炼金模式的具体时长、品质／变异代价、交付要求及实际采用的模式数量。

# 18. 已确认规则摘要

以下为最新方向摘要；涉及具体流程的完善建议仍以第 12 章标记为准，设计确认不等于工程实现：

1. 玩家使用 WASD 移动，Space 执行短距离冲刺 / 闪避；基础普攻支持持续战斗，炼丹默认单独操作。
2. 丹药实际是本局技能，玩家主要靠继续炼丹强化和改造构筑；药效发动与消耗材料的制丹分开，目标与方向按技能配置。
3. 玩家碰到怪物和被怪物攻击均会受到伤害；主动近战攻击期间只计算主动攻击伤害，不额外叠加同一怪物的接触伤害。
4. 玩家受到有效伤害后获得短暂无敌；闪避期间也有无敌。两者独立计时、使用相同持续时间，任意一种生效都免疫所有伤害。
5. 同一次攻击对玩家最多造成一次伤害；玩家受击表现不影响移动。
6. 普通怪物存在多种近战与远程行为，且可逐只配置。远程攻击受攻击距离限制，投射物会被不可穿越障碍物挡住，但发动攻击时不要求视线无遮挡。
7. 普通攻击不强调提示；强力攻击必须提供预警。精英怪拥有更高生命值或攻击能力，并有需要躲避且带预警的强力攻击。
8. Demo 最终 BOSS 主动追击玩家，拥有大范围强力攻击，并固定为两个阶段。进入第二阶段时增加新招式，保留第一阶段攻击。
9. BOSS 阶段转换期间原地播放转换动作并暂停攻击，但玩家仍能移动、闪避、攻击，BOSS 仍可受到伤害；阶段切换保留剩余生命值。
10. BOSS 从当前阶段冷却结束的可用招式中按配置权重随机选择，并尽量避免连续重复同一招式。
11. BOSS 攻击在动画指定帧生成伤害区域；所有攻击对玩家均遵守同一次攻击最多造成一次伤害的规则。
12. 打开任何局内系统界面时，整个游戏模拟与所有游戏内计时暂停。
13. 制丹采用必要材料＋辅助材料／特殊材料；换主材重抽技能本体，换辅材重抽效果词条，材料种类与数量提供可理解的随机倾向。
14. 材料等级影响对应强度，炼制操作影响品质、稳定性及正负变异；不让一次随机默认洗掉所有成长与满意部分。
15. 局外可以选择炼金模式，改变局内炼制操作、战斗风险和成品交付；局内因素可按明确规则改变指定环节。
16. 普通怪少量掉碎片归集为材料，不同箱庭地图有不同材料生态与药方；当前先验证炼丹闭环，元素反应后续展开。

> **本次制作建议：** 在现有基础战斗上先验证“选模式—收材料—新制—强化／分层重炼—旧新结果比较—继续战斗”。系统入口同步见[1.5系统](协作策划/1.5系统.md)。本次仅更新文档；原型、UI、掉落配置、技能数据和试玩包均需后续实施与验证。
