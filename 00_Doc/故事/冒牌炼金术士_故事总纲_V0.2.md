## 一、故事核心

莉莉塔由不会魔法的草药医生格蕾丝抚养长大，猎巫逼近时格蕾丝不告而别，莉莉塔又因寻找失踪士兵主动走出村庄，在救人、学习炼金与建设家园的过程中，逐步追到养母的去向和猎巫、魔物共同的源头。

世界原本没有魔物：皇室药剂师奉命研制壮阳药，意外发现药中魔法病毒具有强大修复效应，遂将其扩展为净化药并推广至灾区；病毒随用药与接触传播，又根据宿主持续感受到的威胁，将修复推向威吓、防御与攻击性的身体改造。

人们把粮食灾害归咎于巫术，把药剂造成的异变视为巫术罪证，再以强制服药、拘禁和虐待加剧病程，亲手制造出原本不存在的魔物。

格蕾丝最终发现真相，却没有让身体变回人样的方法，最终阶段的人性损毁更无法挽回；莉莉塔必须学会保护仍保有人性者、阻止新的异变，并在必要时杀死无法救治的最终阶段宿主，以保护其他人。

情感核心是莉莉塔对家的依恋、格蕾丝不告而别造成的伤害，以及救助存在边界之后仍愿意承担责任；前期以生活化幽默建立人物，后期逐步增加情感重量。

## 三、真实前史与异变规则

本节供作者掌握完整因果，游戏开场不直接揭露。

### 3.1 皇室药剂、猎巫与魔物的形成

**皇室壮阳需求 → 发现修复效应 → 仓促扩大用途 → 粮食灾害提供试药机会 → 地方推责引发猎巫 → 早期好转推动全国发药 → 病毒传播与迫害诱发异变 → 异变被解释成巫术 → 加药和搜捕制造更多魔物。**

| 环节 | 实际发生的事情 | 如何推动下一步 |
| --- | --- | --- |
| 皇室起源 | 皇室药剂师奉命开发壮阳药，利用魔法病毒改善身体机能，意外观察到显著的损伤修复效果 | 他看到扩大研究与获得地位的机会，推动将药剂转为面向全身的治疗实验 |
| 仓促扩展 | 受照料的短期试用显示体力和伤口恢复，药剂被寄望于强身健体、治疗百病，但远期结果与人际传播尚未查清 | 药剂师和支持者急于扩大样本，将药送往急需治疗的灾区 |
| 灾区试用 | 地方主管私卖合格救济粮，以受潮旧粮替代并造成集中发病，随后接收实验药以尽快平息灾情 | 初始食源性疾病与后续病毒感染从此叠加，短期修复掩盖了长期危险 |
| 诬陷医生 | 草药医生要求停发问题粮并记录用药疑点，主管为掩盖粮食去向，宣称她借治病施咒 | 医生被拘押，病历被删改，其日常药材联系人被逼写为同伙 |
| 猎巫扩大 | 调查官采信跨地供词并上报中央，国家以恢复秩序为由派兵排查，承诺供人减责并追究包庇 | 举报、自保、报复和办案压力制造更多名单，格蕾丝与接生婆因普通医药往来被列名 |
| 全国发药 | 换发合格粮、药物短期修复与医生被处决在时间上接近，官方将好转宣传为猎巫和净化有效 | 实验药以净化药名义送入灾区、军队和拘押点，对病人、伤者和嫌疑人强制使用 |
| 魔物出现 | 病毒传播后，受持续威胁与虐待的宿主产生防御、威吓方向的不可逆改造，部分进一步丧失人性 | 身体变得可怕使人群后退，病毒将这一结果继续强化，最终可能只剩攻击反应 |
| 错误循环 | 尚未真正死亡的僵直患者被送往弃尸处，部分异变加重后活动，被解释成染病者死后成为魔物 | 当局认定巫术未除，增加药量与残酷处置，反而推动更多感染者恶化 |
| 掩盖责任 | 药剂师发现用药与异变的联系，却把失败归为患者已受巫术污染，调查官收到疑点后也维护既有判决 | 病历、发药记录和失败病例被分开、删改或销毁，需要多位证人与原始文书互证 |

最初的粮食灾害、后来的病毒感染、最终的身体异变具有明确先后：问题粮本身不含魔法病毒，猎巫先于魔物出现，魔物又被用来替持续猎巫和发药辩护。

### 3.2 不可逆异变与救助边界

| 阶段 | 状态 | 能够采取的行动 | 无法做到的事 |
| --- | --- | --- | --- |
| 感染但未异变 | 病毒可能短期促进修复，尚未形成身体改造 | 停止继续服药、采取防护并观察，后期研究寻找抑制病毒与预防异变的方法 | 安慰不能直接清除病毒，停止服药不保证既有感染消失 |
| 异变但保有人性 | 已有硬化、增生或体态改变，仍保有可持续辨认的记忆、沟通与自主选择 | 照护、防护并尝试抑制进一步恶化，让其以改变后的身体继续生活 | 已形成的身体变化无法逆转，不能变回原本的人样 |
| 最终阶段 | 身体与认知彻底受损，人性和自主控制不可恢复，具有极强攻击性 | 只能杀死宿主才能终止其攻击，行动目标是保护其他人 | 没有治愈、亲情唤回、净化或复活办法，没有特殊角色例外 |

病毒根据长期威胁反应改变修复方向，并不理解善恶；持续的身体改造最终可能损毁认知，使宿主把周围一切都当作威胁。

恐惧等宿主状态须以已感染为前提才影响病程，不将普通悲伤、愤怒或精神困扰等同于会变成魔物，也不以患者意志薄弱解释其受害。

传播暂按服药及特定高风险接触成立，普通交谈和共同生活不自动等于感染；具体接触条件、潜伏期和防护方式待定，但村庄必须能靠实际措施安全维持救援与照护。

最终阶段是客观的不可救状态，识别须由持续病程、认知观察和研究记录支撑，不能仅凭通缉、丑陋外表、语言障碍或一次防御性攻击作判断。

## 四、故事一级大纲

每段一句话；前史按真实时间排列供制作参考，药剂来源与危险在游戏中通过后续调查揭露。

1. 格蕾丝年轻时来到偏僻的格雷弗德，以普通草药行医，在多年生活中见证村庄逐渐壮大。
2. 她在集市购入一捆旧医书时随手收下一本晦涩药典，将它用于查阅植物和压制草药标本。
3. 一支来历含糊的商队经过村庄，将年幼的莉莉塔留给村民照看，却没有依约回来。
4. 格蕾丝因无法生育而收养莉莉塔，并在日复一日的照料中与她建立母女般的感情。
5. 莉莉塔成长期间多次目睹旅者称格蕾丝为魔女，格蕾丝虽然用玩笑化解，却始终无法消除外人的敌意。
6. 多年后，皇室药剂师奉命研制壮阳药，意外发现其中魔法病毒具有强大修复效应，遂推动将其扩大为实验性全身治疗药。
7. 远方村庄因主管私卖好粮、发放受潮旧粮而集中发病，主管接受实验药试用，希望尽快压下灾情。
8. 一名草药医生提出停发问题粮并记录用药疑点，却被主管诬陷施咒，其普通医药联系人经刑讯被写成跨地同伙。
9. 调查官采信假案并上报中央，国家开始猎巫，又将短暂好转宣传为处决与净化药有效，逐步推广发药和搜捕。
10. 病毒随发药与高风险接触扩散，长期遭迫害的宿主陆续发生不可逆异变，但各地最初只流传怪病与死后复起的消息。
11. 格蕾丝得知自己因草药交易进入名单，一个早晨仍让莉莉塔前往熟悉的野外采药，玩家由此学习移动与采集。
12. 莉莉塔回来后首次在格蕾丝指导下合成基础草药，并听见她反常地叮嘱自己学会保护自己。
13. 当晚莉莉塔起夜，看见格蕾丝焦虑地伏在桌前、床边放着打包一半的行囊，却没有意识到她正准备离开。
14. 格蕾丝得知搜捕即将抵达，在带孩子逃亡的危险与将她留在熟悉村庄的风险之间仓促取舍，趁夜离开且没有留下信件或口信。
15. 次晨莉莉塔找不到格蕾丝，开门看见士兵盘问村民，随后被冲入药屋搜查与追问，最终被登记身份并留在村内。
16. 搜查后的药屋仍有村民前来取药，莉莉塔决定完成格蕾丝留下的工作，沿昨日的道路重新外出。
17. 她在药圃附近首次亲眼遭遇魔物，勉强取回材料并向士兵报告异常，而当地守军此时仍按危险怪病处理。
18. 她为处理损坏的药材翻阅旧药典，意外完成真正的炼金操作，唤醒自恋而博学的拉结尔。
19. 数名士兵前往调查后失踪，次日晚魔物袭村，守军艰难抵挡，幸存伤者又按命令接受被认为能够防病与恢复体力的净化药。
20. 莉莉塔因担忧失踪者仍活着而主动寻找，循装备与拖行痕迹救回年轻士兵，得知其余人曾为救援难民深入林地。
21. 她在废弃驿站救出士兵、难民与接生婆，注意到有人服药后伤口迅速恢复，也有人出现难以解释的皮肤变化。
22. 一名士兵认出接生婆在同伙名单，要求拘押，获救年轻士兵则以她曾冒险救人的亲历反对立即移交。
23. 村民随之分裂，有人害怕包庇获罪，有人认为没有伤害证据便处死救人者只会带来更多死亡，莉莉塔也追问士兵是否亲眼见过她害人。
24. 驻村队长承担暂缓移交的责任，让接生婆在留置看管下自愿救治伤者，而有关村庄包庇巫师的举报仍被送往上级。
25. 接生婆告知格蕾丝曾打听西行道路，并记录到净化药能够短期修复伤口、却未必让患者长期好转的异常。
26. 莉莉塔沿西行路线探索、收集材料并回村研究炼金，药屋逐渐成为搜集格蕾丝消息和照料获救者的据点。
27. 她救回流亡铁匠，铁匠自愿留村修复装备与设施，又随医护需要提供清洁器具、防护与安全照护空间。
28. 她打通商路并与行商恢复交易，从旅人得知格蕾丝曾替人治病，又发现多个异变地点都收到过同一体系供应的净化药。
29. 一名获救者的身体变化在长期照料下暂时趋稳却始终没有消退，莉莉塔开始明白仍保有人性的人未必还能恢复原貌。
30. 随后的救援中，她遇到一名彻底失控并持续攻击的异变者，救护与沟通均告失败，众人只能杀死他才能保护被困者。
31. 接生婆将病程与军中发药记录对照，怀疑继续强制服药和粗暴拘禁正在加速恶化，促使队长暂缓村内发药并采用防护而非驱逐患者。
32. 莉莉塔在封闭集镇发现首批患者吃过同批救济粮、魔物记录却晚于净化药进入，意识到最初发病与后来的异变可能具有不同原因。
33. 她救回保存原始文书的书记员，发现停粮建议被删除、医药往来被写成同伙关系，而服药后的失踪与死亡未被计入试药结果。
34. 书记员与行商拼合出净化药最早来自皇室壮阳药项目、后来仓促扩大用途的经历，众人开始追查成功宣传之外的失败病例。
35. 沿途证言显示格蕾丝发现了受药者共同的异常，并为追查原始病历前往源头村庄，让莉莉塔的寻亲与查药汇成同一方向。
36. 调查官因庇护举报及拒绝继续发药抵达格雷弗德，将村内稳定异变者视为包庇证据，要求移交嫌疑人并恢复净化程序。
37. 年轻士兵提供医护记录、驻村队长拒绝以外貌代替危险判断，双方公开分裂，调查官则收缴证言并向药剂供应方通报泄密。
38. 莉莉塔与伙伴保留并分散文书副本，在原始档案被销毁前赶往源头废村，途中对最终阶段魔物作战并继续救出尚有人性的幸存者。
39. 她在废村找到仍照顾幸存者的格蕾丝，母女在救护间隙爆发争执，莉莉塔终于问出为何一句话也没有留下。
40. 格蕾丝说明自己的恐惧与误判，却无法补回缺失的告别，母女暂时共同追查患者恶化的原因而没有立即消除隔阂。
41. 她们从粮仓账册、病历和刑讯记录确认粮食灾害被掩盖、医生被诬陷及猎巫扩大的经过，又从当地试药设施找到修复与异变前后相接的记录。
42. 格蕾丝以亲历病程与试验记录互证，确认病毒会受长期威胁感影响改造宿主、身体变化不可逆，最终阶段的人性损毁更无法挽回。
43. 在失败档案外流后赶来回收证据的皇室药剂师试图归罪于患者本性，母女以同批用药者的不同病程反驳其推责，并取得被隐瞒的传播记录。
44. 调查官随后封锁设施，害怕假案与强制服药责任同时暴露而要求扣押证人与档案，此时拘押区已因持续迫害出现更多最终阶段宿主。
45. 莉莉塔先疏散仍可救助的人，再与守军阻止冲出的最终阶段魔物，为撤离争取时间并放弃携走全部研究设备的机会。
46. 获救者按先前建立的协作安排护送证人、保存副本并拦截药剂补给，使揭露真相与停止下一轮发药不依赖莉莉塔独自完成。
47. 证据促使相关地区停发药剂、调查供应和传播渠道并重审案件，但既有感染、不可逆身体损伤与已死亡者均不会因此消失。
48. 格蕾丝与村内医护继续寻找抑制恶化的方法，莉莉塔以炼金知识协助研究，并将已有防护和照料经验带往仍受灾的地方。
49. 莉莉塔与格蕾丝回到众人共同恢复的村庄，逐步修复母女关系，也学会接纳那些外貌永远改变却仍愿意共同生活的人。
50. 此后莉莉塔继续外出救援、截断污染药剂与调查遗留病例，回村建设和研究，并承担消灭无法救治的最终阶段魔物以保护幸存者的责任。

## 五、贯穿全篇的明线与暗线

| 脉络 | 起点与推进 | 后期回收 |
| --- | --- | --- |
| 明线：寻找格蕾丝 | 不告而别、西行证言、她追查病历的踪迹 | 废村重逢并开始修复关系 |
| 明线：救援与守村 | 寻找士兵、救回NPC、建立设施、面对收留分歧 | 获救者共同护送证人、阻止发药，村庄接纳稳定异变者 |
| 明线：炼金学习 | 草药基础、旧书苏醒、材料与配方积累 | 支持战斗、防护与抑制研究，不能逆转既有异变 |
| 暗线：猎巫假案 | 食物与病程矛盾、刑讯、联系人被改为同伙 | 揭示地方牟利如何经误判、自保与政策变成全国运动 |
| 暗线：药剂来源 | 神奇恢复、同源药瓶、失踪试药者、发药路线 | 揭露皇室壮阳药如何扩大为净化药并传播病毒 |
| 暗线：异变与迫害 | 受威胁者恶化、受照护者暂稳、最终阶段无法挽回 | 证明处置影响病程，却不能撤销已形成的损伤 |
| 情感线：救助的边界 | 莉莉塔相信自己至少能做些事，随后遇到无法救回的人 | 她既不放弃尚有人性者，也不以能治好一切作为承担责任的条件 |

## 六、长期玩法与NPC功能关联

正式循环为：外出战斗、探索与救援 → 带回材料、证据及愿意留下的NPC → 回村制作、照护与建设 → 获得下一次远行条件。

| NPC或事件 | 叙事作用 | 功能方向 |
| --- | --- | --- |
| 格蕾丝与药屋 | 建立家庭和医学经验基础，后期观察病程 | 草药教学、药物安全与抑制方向研究 |
| 拉结尔 | 提供炼金知识并体现知识边界 | 配方理解、材料分析、防护与战斗手段 |
| 年轻士兵与队长 | 从执行命令转向有依据的守护 | 危险情报、守村协作与护送 |
| 接生婆 | 从被指控者成为病程记录者 | 医护、防护、观察与稳定期照料 |
| 铁匠 | 将救援关系转为持续互助 | 工具装备、防御与照护设施 |
| 行商 | 维持物资与消息并追索药剂流向 | 交易、补给、路线与药批线索 |
| 书记员 | 将零散观察整理为可核对的时间线 | 档案、证据互证与研究记录 |
| 稳定异变者 | 展现外貌不可逆与仍可共同生活 | 自愿提供的村庄工作及个人任务，具体角色待定 |
| 最终阶段魔物 | 展现无法挽回的后果和必要战斗 | 正式战斗及区域威胁清理，怪物与首领待设计 |

救援要有防护与安置条件，稳定异变者保留自主选择；本稿不默认加入感染倒计时、NPC随机恶化或所有敌人都可捕获的玩法，具体机制另行设计。

## 七、玩家发现真相的顺序

| 阶段 | 玩家看到的信息 | 当时能够得出的判断 |
| --- | --- | --- |
| 开场 | 猎巫告示、搜查、净化药宣传、死后复起的传闻 | 社会相信巫术致病与净化有效，魔物起源未知 |
| 士兵与接生婆救援 | 短期恢复、发药记录、无辜者被列名及细小外形变化 | 指控与亲历不一致，短期有效无法解释后续变化 |
| 村庄中期 | 一人获照护后暂稳但未恢复外貌，另一最终失控者无法救回 | 外貌变化和人性丧失不能混同，病程存在不同阶段 |
| 集镇与书记员 | 发病早于服药、异变晚于推广，供词和试药结果被改写 | 粮食灾害、假案与药剂异变是叠加的不同事件 |
| 商路与项目旧档 | 皇室早期用途、药剂流向和病例重合，格蕾丝也在追查 | 净化药有共同来源，传播不只来自官方口中的巫师 |
| 废村研究 | 完整病程、不同处置的对照、被隐瞒的传播和失败记录 | 持续威胁影响修复方向，异变不可逆，最终阶段无药可救 |
| 终局 | 原件、副本、证人与停药后仍存在的病例 | 真相能阻止继续犯错，无法让失去的人和身体复原 |

## 八、关键设定与连续性约束

1. **世界原本没有魔物**：魔物首次产生于药剂扩散与猎巫处置之后，不能在早期前史安排既存魔物生态或古代讨伐史。
2. **格蕾丝不会魔法**：她以医学经验观察病程，莉莉塔与拉结尔协助炼金分析，均不能凭空获知答案。
3. **没有告别信**：格蕾丝不告而别，莉莉塔逐步理解，重逢不自动获得原谅。
4. **旧书来源普通**：拉结尔不是格蕾丝创造，不默认与药剂项目或莉莉塔血统同源。
5. **草药与魔法分开**：格蕾丝教普通合药，真正炼金另行展开，搜查时旧书尚未暴露性质。
6. **原始病因与异变病因分开**：问题粮先致病，实验药后来引入病毒，旧粮不含该病毒。
7. **药剂师逐步承担责任**：原始壮阳用途有限，修复效应引发扩展，其责任在仓促推广与知情后隐瞒，不在开场便全知地制造魔物。
8. **病毒能传播**：停药只截断一种来源，不清除既有感染，传播与防护条件必须一致。
9. **身体异变不可逆**：稳定、抑制和继续生活不等于恢复人样。
10. **最终阶段只能杀死**：没有特效药、亲情唤回、净化、复活或主角例外。
11. **识别不能只看外貌**：感染、稳定异变和最终阶段需要病程与认知证据区分，不能将军方偏见当成正确标准。
12. **迫害影响病程不等于患者有罪**：不以普通精神困扰、性格或意志薄弱解释被害者异变。
13. **保留接生婆冲突**：士兵与村民分歧、队长担责、留置和举报，延续为后期停药与庇护争议。
14. **调查官逐步知情**：先相信卷宗和疗效，中期压制疑点，后期维护判决与发药命令，和主管、药剂师各有动机。
15. **证据分层互证**：名册解释定罪，账册解释初病，药批与病程解释传播和异变，不能只凭单本日记解决全部真相。
16. **终局阻止新增伤害**：停药、阻断传播、照护未到最终阶段者并处理不可救威胁，不让世界病例在结局自动消失。
17. **NPC关系先铺后收**：副本、护送路线、停药依据与协作在终局前建立。
18. **替换旧版魔物解释**：不采用古来存在或结界魔女遇害释放魔物的解释，巡防调离只加重应对失败。

## 九、待确认事项

- 莉莉塔幼年教学与正式战斗之间的时间跨度，以及区域往返距离和全篇持续时间。
- 新增NPC姓名、年龄和外貌，稳定异变者与最终阶段战斗对象的具体身份。
- 商队为何留下莉莉塔及其后续回收。
- 格蕾丝临行掌握的信息、为何没有留话，以及认为留村更安全的具体依据。
- 拉结尔的来源、苏醒条件、知识边界和旧书长期未暴露的原因。
- 病毒传播条件、潜伏期、异变阶段与最终阶段的可靠辨认依据。
- 药剂师如何取得病毒、皇室如何批准扩展用途，以及发药与审查的机构和时间线。
- 抑制手段能达到什么程度、何时取得阶段成果，以及结局后仍需处理的感染范围。
- 怪物与首领战斗设计，以及如何逐步教会玩家区分可救助者与最终阶段威胁。
- 接生婆解除看管、村民接纳稳定异变者与旧案重审的具体过程。
