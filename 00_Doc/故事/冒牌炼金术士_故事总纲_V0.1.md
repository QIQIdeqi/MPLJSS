## 一、故事核心

被商队留在村庄的莉莉塔由普通草药医生格蕾丝抚养长大，因猎巫失去养母的陪伴，又在寻找失踪士兵的过程中开始主动救人、探索和使用炼金术，逐步与获救者共同建设村庄，并追查格蕾丝的去向与猎巫运动的起因。

故事的情感核心是莉莉塔对家的依恋、对格蕾丝不告而别的困惑，以及她如何在恐惧与偏见中选择帮助具体的人。

故事前期保留生活化幽默与角色反差，随着搜查、逃亡和真相调查逐渐增加情感重量；幽默主要来自莉莉塔的认真直白、格蕾丝的口是心非与拉结尔的自恋。

## 三、故事一级大纲

### 3.1 猎巫运动的真实前因后果

本节供作者理解实际发生的事情；游戏开场只让莉莉塔接触官方说法，完整真相在中后期逐步揭露。

**地方主管私卖好粮 → 以受潮旧粮充当救济 → 村民集中发病 → 医生要求停发问题粮 → 主管将医生诬为施咒者 → 逼供把普通往来变成跨地区同伙名单 → 中央误判为全国性威胁 → 举报与搜捕制度使迫害自行扩张。**

| 环节 | 具体发生的事情 | 为什么推动下一步 |
| --- | --- | --- |
| 1. 有人制造了隐患 | 地方主管为获利私卖拨给灾民的合格粮食，用仓内受潮旧粮补足发放数量 | 领取问题粮的家庭陆续发病，主管面临查账与追责 |
| 2. 医生发现疑点 | 前来救治的草药医生发现首批患者吃过同批救济粮，在接诊记录中提出关联并要求暂停发粮 | 主管意识到她的调查会暴露粮食去向，需要使她失去可信度 |
| 3. 既有偏见被利用 | 主管借病人服药后仍然死亡的事实，宣称医生借治病施咒，并隐去患者在服药前已经发病的时间记录 | 恐慌的家属本就不信任草药与陌生医者，指控因此获得部分支持 |
| 4. 逼供制造同伙 | 医生在刑讯中被要求承认施咒并供出同伙，审讯者把她平日交换药材、请教接生技术的熟人写进供词 | 这些真实存在于不同城镇的联系人，使一桩地方案件看起来像跨地区组织 |
| 5. 假案获得国家认可 | 调查官起初相信地方提交的供词、名单和被修改的接诊摘要，向中央上报多地串联的巫术威胁 | 中央为平息灾情恐慌、展现恢复秩序的能力，设立专项审查并向各地派兵排查 |
| 6. 搜捕产生更多名字 | 专项审查承诺对坦白并供出同伙者从轻处置，同时追究隐瞒与包庇者，各地官员需上报办案进展 | 被捕者为自保攀认他人，邻里借机报复，地方官把新增名单当作成绩，案件不断扩大 |
| 7. 扩大本身被当成证据 | 各地搜捕产生的供词被汇总为存在全国巫师网络的证明，普通医者的交往和逃亡也被解释为串联与畏罪 | 调查者用审讯制造的结果验证最初的判断，格蕾丝与接生婆因真实医药往来被卷入名单 |
| 8. 发现错误后仍继续 | 随着原始记录与病人证言出现，调查官逐渐发现初案可能有假，却担心承认错误会推翻已签署的判决并使自己承担处决责任 | 他开始压制证人、回收原始档案，地方主管也继续掩盖粮食账目，两者以不同动机维护同一个假案 |

这里的“疫情”是民众与官方对集中发病的称呼，实际源头为问题粮食造成的群体性食源性灾害，其具体病理不在本稿定死；初案中的施咒指控没有事实依据。

最初推责的地方主管、起初相信卷宗的中央与调查官、后来借举报自保或获利的人各有动机，运动是在这些行为相互推动中扩大的。

### 3.2 全篇推进顺序

每段保持一句话；第7—8段呈现开场时传入村庄的说法，第33段以后逐步推翻这些说法。

1. 格蕾丝来到偏僻的格雷弗德，以采集草药、配制药物和照料病人为生，在数十年间见证小村逐渐壮大。
2. 她偶尔在集市购置旧医书，一次随手收下一本夹在书捆中的晦涩药典，将它用于查阅植物和压制草药标本。
3. 一支来历含糊的商队经过村庄，将尚且年幼的莉莉塔留给村民照看，却没有依约回来。
4. 格蕾丝因无法生育而收养莉莉塔，并在日复一日的照料中与她建立母女般的感情。
5. 莉莉塔成长期间，多次目睹外来旅者因格蕾丝的职业和生活方式而称她为魔女，并向她表达恐惧与憎恶。
6. 格蕾丝用玩笑和日常劳作淡化这些敌意，莉莉塔却慢慢记住了别人看向养母时的目光。
7. 远方一个村庄集中出现病人与死亡，传入格雷弗德的告示宣称一名草药医生已经供认施咒，并供出了分布于多个城镇的同伙。
8. 中央据此下令各地排查医药往来、鼓励供出同伙并追究包庇者，新的举报与供词不断扩大搜捕范围，格蕾丝也得知自己因普通草药交易被写入了关联名单。
9. 一个普通的早晨，格蕾丝让莉莉塔独自前往熟悉的野外采药，玩家由此完成移动与采集教学。
10. 莉莉塔回家后第一次在格蕾丝指导下合成基础草药，并听见她反常地叮嘱自己记住这些办法、学会保护自己。
11. 当晚莉莉塔起夜时看见格蕾丝焦虑地伏在桌前，床边放着打包一半的行囊，却没有意识到这意味着什么。
12. 格蕾丝得知搜捕即将抵达，在带孩子逃亡与让她留在熟悉的村庄之间作出仓促决定，趁夜离开且没有留下任何信件或口信。
13. 次日清晨，莉莉塔找遍屋内仍不见格蕾丝，开门后发现士兵正在挨家盘问，而村民的目光陆续落到自己身上。
14. 士兵冲入药屋翻查物品、追问格蕾丝的下落，莉莉塔在惊恐中无法回答，最终被登记身份并留在村内。
15. 搜查结束后，一位熟悉的村民前来取药并留下饭食，莉莉塔决定完成格蕾丝尚未配好的药，重新走上昨日的采药路。
16. 莉莉塔在药圃附近发现魔物与破坏痕迹，勉强取得材料返回村庄，并将异常报告给驻村士兵。
17. 她为处理损坏的药材翻阅旧药典，意外完成一次真正的炼金操作，唤醒了藏在书中的拉结尔。
18. 数名士兵依据莉莉塔的报告前往野外调查，第二天仍未返回，而当晚袭来的魔物又让守军付出沉重代价。
19. 莉莉塔照料伤者时得知失踪者的救援将被延后，因担忧他们仍然活着，决定沿自己熟悉的道路寻找。
20. 她循着遗落装备和拖行痕迹救回一名年轻士兵，得知其余人曾为援救难民而深入林地。
21. 莉莉塔在废弃驿站找到被困的士兵与难民，并将照顾伤者的接生婆一同救回村庄。
22. 一名士兵认出接生婆位于巫术同伙名单，尽管名单依据只是她曾向被捕医生提供草药与接生用品，仍要求拘押并指责收留者正在包庇巫师。
23. 获救的年轻士兵出面反对，说明接生婆曾冒险救治自己，其他人则坚持救过人也不能证明她没有犯罪。
24. 村民随之分裂，有人害怕包庇嫌疑人招来惩罚，也有人认为她没有做错任何事，继续屠杀只会让村庄失去能够救人的人。
25. 莉莉塔面对争执说不出大道理，只问士兵是否亲眼见过接生婆害人，并坚持不能仅凭通缉令就将她带走处置。
26. 驻村队长决定将接生婆登记留置、由自己承担暂缓移交的责任，允许她在看管下救治伤者，却未能平息双方的不满。
27. 接生婆在获得暂时容身之处后主动承担医护工作，并告诉莉莉塔格蕾丝曾向她打听西行道路，使搜寻首次有了可靠方向。
28. 随着接生婆救治更多村民，部分反对者开始动摇，但关于村庄包庇巫师的举报也沿商路传向上级。
29. 莉莉塔开始反复探索村外、收集材料并回村学习炼金，逐步恢复药屋，也获得前往更远地区的能力。
30. 她在废弃农庄救出流亡铁匠，铁匠定居后修复工具与设施，使村庄能够制作装备并支持更长的探索。
31. 她打通受阻商路，与行商建立往来，借由持续进入村庄的物资和旅人追查格蕾丝的行踪。
32. 沿途的证言显示格蕾丝曾替人治病、以劳动换取食宿，并因身份暴露再次逃走，让莉莉塔逐渐看见养母逃亡中的脆弱。
33. 莉莉塔在封闭集镇发现早期患者领取过同批救济粮、部分患者在服药前便已发病，并开始怀疑官方所说的草药致病。
34. 她救出携带旧案文书的书记员并带回村庄，发现初稿曾提及停发粮食与刑讯追问，而正式卷宗删去这些内容、将普通医药联系人写成施咒同伙。
35. 随着获救NPC陆续选择留下，村庄恢复医护、锻造、交易和研究功能，也因庇护逃亡者及莉莉塔的炼金传闻受到调查官关注。
36. 调查官抵达格雷弗德，以既有供词和包庇规定要求交出接生婆与书记员、追查莉莉塔的力量来源，迫使获救士兵和驻村队长选择是否执行已有明显疑点的命令。
37. 莉莉塔得知格蕾丝曾追问初案中的粮食问题，并发现调查官收到相反证言后仍下令收缴原件，由此决定赶在旧案证据消失前抵达源头村庄。
38. 她在村民与伙伴支持下穿过被魔物占据的道路，最终抵达最初发生疫情、如今已经荒废的村庄。
39. 莉莉塔在废村找到仍在照顾幸存者的格蕾丝，既确认养母活着，也终于当面追问她为何不告而别。
40. 母女未能立即消除隔阂，却共同从粮仓找到好粮被私卖及旧粮被替换的账目、从诊所找到发病与停粮记录，并从旧法庭找到刑讯记录和卷宗改写痕迹。
41. 她们以账目、病历和幸存者证言互证，串起主管盗卖粮食、以旧粮致病、诬陷医生、逼出联系人、上报跨地组织并引发全国搜捕的完整经过。
42. 她们进一步确认医生被捕后出现的短暂好转来自问题粮耗尽及新粮到达、却被官方宣传为处决奏效，而后续魔物灾情又因巡防调离和村庄失序加剧并被归咎于漏网巫师。
43. 调查官追至废村封锁现场，承认重查初案将动摇自己已签署的判决、仍要求扣下证人与档案，莉莉塔则在争夺完整档案与保护活人之间选择先救人。
44. 此前获救的士兵、难民与村民分别保存副本、护送证人和传递消息，使真相不再依赖莉莉塔独自带出。
45. 证据与证言促使旧案重审、部分被捕者获释，当地猎巫受到遏制，但社会中的恐惧和偏见仍然存在。
46. 莉莉塔与格蕾丝回到由众人共同恢复的村庄，开始修复彼此的关系，而莉莉塔继续以外出探索、救助旅人与回村建设守护这个家。

## 五、长期玩法与NPC功能关联

正式循环为：外出探索与战斗 → 获取材料、消息并救援NPC → 回村制作与建设 → 获得远行条件 → 探索新区域。

| NPC或事件 | 叙事作用 | 对应功能方向 |
| --- | --- | --- |
| 格蕾丝与药屋 | 建立家庭关系及最初的失落 | 移动、采集、草药合成教学及初始据点 |
| 拉结尔苏醒 | 引入真正的炼金术及日常互动 | 配方解释、炼金学习与研究 |
| 救回年轻士兵 | 建立互相亏欠的关系，提供救援方向 | 野外情报、危险提示，具体功能待定 |
| 接生婆留村 | 让帮助无辜者产生现实争议与代价 | 医护点及草药相关服务 |
| 铁匠定居 | 将救援转化为双方愿意维持的合作 | 器具修复、装备制作与设施改善 |
| 商路恢复 | 将村庄重新接入外部世界 | 交易、物资补充与消息收集 |
| 书记员获救 | 将零散疑点整理为可追查的问题 | 线索整理、档案辨认与调查进展 |
| 多位NPC共同生活 | 展现村庄的恢复、分歧与互助 | 逐步开放建设和养成内容 |

上述为功能方向，具体系统规则、成本和解锁条件需另行设计；NPC是否留下由其处境和选择支撑，接生婆受到的看管限制也应在后续剧情中处理。

## 六、关键设定与连续性约束

1. **格蕾丝不会魔法**：她以普通草药和行医经验救人，炼金魔女是外界加诸她的称呼。
2. **格蕾丝没有留下信件或口信**：夜间焦虑、未打包完的行囊与清晨失踪是开场信息，莉莉塔当时不知道她的真实去向。
3. **魔法书来自普通交易**：旧药典夹在购入的旧书中，其来历不在开场被强调，拉结尔不由格蕾丝创造。
4. **草药教学与真正炼金分开**：格蕾丝教的是自己理解的普通药物制作，后续超常效果由莉莉塔探索旧书时发现。
5. **搜查未能识别魔法书**：旧书当时与药典、账册混杂，外观与已翻阅内容没有暴露其真实性质，具体演出待细化。
6. **救回接生婆后必须发生分歧**：士兵与村民各有立场，暂缓移交是队长承担责任的决定，不能直接跳到毫无争议的功能解锁。
7. **留置不等于洗清指控**：暂时医护、后续举报、调查官到来和NPC处境变化应保持因果连续。
8. **猎巫指控与真实魔法不能混为一谈**：接触药材、行医或拥有魔法都不能自动证明某人实施过伤害。
9. **猎巫起因逐步揭示**：作者按第3.1节掌握完整因果，玩家依次经历相信或不解官方说法、发现病程矛盾、发现卷宗改写、确认利益动机与全国扩散机制的过程。
10. **格蕾丝的离开同时包含恐惧与保护意图**：她作出的判断会伤害莉莉塔，重逢不会自动消除这种伤害。
11. **NPC关系参与终局回收**：证人、档案副本和传递渠道需在中期建立，终局不能突然出现解决一切的援助。
12. **旧版设定在本稿中调整**：天生魔女格蕾丝、她创造拉结尔、告别信等内容不沿用；结界魔女遇害的旧设定未纳入本稿，是否保留需单独决定。
13. **灾情好转有实际原因**：初案处决后的病情变化由问题粮断供与新粮到达解释，官方将时间上的相邻宣传成因果，玩家需从日期和证言中识别这一误导。
14. **调查官的知情程度随剧情变化**：起初采信被篡改的卷宗，中期接到矛盾证言后主动压制，终局维护既有判决；不能从开场就把他写成全知的幕后策划者。
15. **实际魔法不替初案作证**：拉结尔、莉莉塔的炼金术与魔物不造成最初的粮食灾害，魔法存在本身不能证明医生施咒害人。

### 玩家发现真相的顺序

| 阶段 | 玩家看到的信息 | 当时能够得出的判断 |
| --- | --- | --- |
| 开场 | 告示宣称已有供认与跨地同伙，士兵据名单搜查 | 国家宣称存在威胁，但莉莉塔尚不知道指控是否可信 |
| 接生婆事件 | 普通药材往来也足以进入名单，士兵对名单与亲眼所见产生分歧 | 被列名与实际害人之间存在缺口，尚不能解释全国运动的起因 |
| 中期调查 | 首批病人领取同批粮、发病早于服药，初稿与正式卷宗不同 | 施咒解释受到动摇，案件可能由人为改写推动，但粮食去向与改写动机仍待查证 |
| 接近终点 | 书记员证实供词来自刑讯、跨地名字来自普通联系，调查官主动回收原件 | 多地搜捕的依据存在问题，且有人正在维护既有判决 |
| 废村终局 | 私卖与替换粮食的账目、病历、刑讯记录、换粮日期及幸存者证言互证 | 能完整解释谁制造灾害、为何诬陷、国家为何采信以及运动为何持续扩大 |

## 七、待确认事项

- 莉莉塔正式开场的确切年龄，以及幼年教学与正式战斗之间是否存在时间跨度。
- 格蕾丝及新增NPC的年龄、外貌、姓名与最终角色数量。
- 商队为何留下莉莉塔、后来发生了什么，以及这条线是否需要后期回收。
- 格蕾丝临行时掌握了哪些消息、为什么认为莉莉塔留村更安全，以及为何来不及留下任何信息。
- 拉结尔的真实来源、苏醒条件、能力边界及旧药典长期未被发现的具体原因。
- 接生婆的具体指控内容、留置期间的行动自由与后续身份变化。
- 魔物本身的来源、活动规律，以及各区域的战斗事件和首领如何嵌入主线。
- 粮食灾害的具体表现、地方主管与首案医生的姓名，以及中央发布专项审查的具体机构、执行周期与证据流转时间。
- 各地举报奖励、从轻承诺与包庇处罚的具体执行方式，以及如何用少量场景呈现而不堆积解释。
- 格蕾丝在废村重逢的安排、母女冲突的解决过程及最终证据如何获得重审机会。
- 各区域往返距离、故事持续时间及回村循环与远行叙事之间的衔接。
