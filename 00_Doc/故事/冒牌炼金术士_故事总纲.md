# 《冒牌炼金术士》故事总纲

更新日期：2026-10-31。当前故事设计依据。

制作状态：序章[八画首版图片](../美术/序章绘本/storyboard/README.md)已交付，角色设计板与最终美术尚未冻结，未制作动画或配音。第一幕分场仍为叙事蓝图，尚未逐节点接入现有Flow；故事节点与教学时序不能据文档表述认定已经实机实现。

游戏形式：类幸存者战斗＋村庄炼金养成；叙事形式：静态绘本与短文字、村内NPC立绘AVG对话。

## 一、故事概述

莉莉塔只想找到格蕾丝、带她回家，沿途做的是讨伐魔物、获取材料、炼金和安置获救者；猎巫与药剂灾难藏在这些行动遇到的人、物件和环境变化中。

故事从边境村庄出发，逐渐走向破败王都，玩家直接体验的是风趣轻快的西幻冒险；越留心途中细节，越能发现魔物并非突然降临的天灾，而是人类追逐疗效、掩盖责任与相互迫害造成的后果。

人物共同面对的问题是：掌握知识、保住肉体，并不等于理解一个人或有权替他决定生活；莉莉塔最终带回的是愿意一起生活的人，拉结尔则开始承认真切而具体的人比文字记录更难理解。

## 二、世界背景与主要地点

### 社会与日常

- **时代气质**：以欧洲猎巫运动为灵感的架空封建王国，生活围绕农田、林地、工坊、集市、旅店和教堂展开，主要依靠步行、马车与信使往来。
- **权力关系**：王室掌握征调与搜捕命令，贵族控制领地、粮仓及道路，教会的巫术指控为迫害提供依据，地方士兵执行盘查；不同地区和个人并不完全一致。
- **医药地位**：普通人依赖民间草药医者，医药知识在无庇护者手中可能成为巫术罪证，在宫廷与贵族庇护下却可以被称为御药研究。
- **猎巫氛围**：草药交易、亲属关系和一次收留都可能造成牵连，告发者既有逐利者，也有害怕家人受害的普通人；救济、信仰和迫害可以来自同一套权力。
- **开场局势**：王都的灾情已沿粮道、药车和流亡者向外扩散，偏远村庄消息迟缓，仍在维持日常，直到搜捕与魔物先后抵达。

### 地点与旅程

| 地点 | 基本面貌与主线作用 |
| --- | --- |
| 格雷弗德 | 约二十户的边境村庄，以农作、手艺和少量贸易维生，是莉莉塔的家与前期采集、炼金、安置获救者的据点 |
| 旧商路与河畔集镇 | 原有商旅网络的一部分，搜捕与魔物使道路中断、药铺停业，莉莉塔在恢复通行时获得西行线索 |
| 早期受灾村庄 | 位于旧粮道，留下粮食问题、施药与猎巫发生先后的痕迹，是途中拼出前史的地点 |
| 贵族庄园 | 粮仓和药房相对完整，受庇护者仍能开展炼金研究，莉莉塔在此遇见药剂师并接受他的便利 |
| 朝圣路 | 通往王都的长途道路，药车、朝圣者、逃难家庭与押送队交错，显露全国猎巫的规模及身份差别 |
| 王都下城与王宫 | 告示仍称灾病已平，实际人口锐减、街区荒废，医者被征用到宫廷附近，国王在持续服药中逐渐变成魔物 |

村庄贯穿全程，是每次战斗后的归返与养成据点，选关路线逐步向王都推进；战斗关卡呈现外出途中需要操作的遭遇，远方路途与时间流逝用绘本省略，一次出战可以代表一次较长远行的往返，不按单局战斗时长计算旅途天数。

## 三、魔法、药剂与魔物

| 要素 | 规则 |
| --- | --- |
| 草药与炼金 | 格蕾丝靠草药经验行医，不会魔法；莉莉塔通过拉结尔学习用材料、器具与配方完成炼金，成长依靠实践，不增加命定血统 |
| 拉结尔 | 保存大量炼金及生命修复知识，能够交流，但知道原理不等于理解使用者，也不能代替病例观察或凭空给出所有解法 |
| 净化灵药 | 最初是为国王开发的壮阳药，短期修复效果真实，药剂师为扩大成果将它推广为治病强身的恩赐；民间最初的粮食疾病与药剂引发的灾难是两件相继叠加的事 |
| 魔法病毒 | 来自禁忌修复知识的应用，随药剂使用及后续传播扩散，长期恐惧和受威胁的状态会使修复偏向威吓、防御性的身体结构，并非单凭恐惧便能变成魔物 |
| 异变阶段 | 世界原本没有魔物，魔物由感染者异变而来，身体变化不可逆；尚有人性者可以照护、尝试抑制恶化，却不能恢复原貌，外貌也不能作为定罪依据 |
| 最终阶段 | 宿主彻底丧失人性与自主控制、极具攻击性，无法救治，只能在战斗中杀死；亲情、解药或讨伐国王都不能逆转这一结果 |

人们起初把灾难当成普通瘟疫，误以为患者死后才会变成魔物；格蕾丝后来确认变化发生于活着的人身上，而猎巫制造的持续恐惧正在加重这种变化。

传播途径、防护措施和可靠辨认末期的具体表现，待战斗与救援玩法细化时确定；规则须允许照护幸存者，不能用丑陋外貌、语言障碍或一次防御行为替代末期判断。

## 四、主线人物

| 人物与外貌 | 性格 | 主线动机与变化 |
| --- | --- | --- |
| **莉莉塔，14岁，女**；瘦小，白发红瞳，红花环、棕披风 | 认真直白、不擅表达，心软又怕被留下 | 想找回养母；救人供药后仍因养母的嫌疑受到排斥，逐渐学会自己决定保护谁、拒绝什么 |
| **格蕾丝，42岁，女**；偏瘦，灰发、旧裙与药草围裙 | 嘴硬心软，习惯替别人作决定 | **不会魔法**；为保护莉莉塔不告而别，沿途又放不下病人，重逢后需要承认错误、接受孩子已经能作选择 |
| **拉结尔，年龄不详，无性别**；磨损的厚皮面旧书 | 博学、自恋、爱受吹捧，懂知识却不懂人 | 想炫耀旧学生的成就，后来面对知识如何被野心利用，逐渐学会倾听具体的人 |
| **皇室药剂师，52岁，男**；清瘦，仪容整齐、精细长袍 | 有才华、善交易，也愿教人，却不能容忍自己变得可有可无 | 想靠研究成为不可替代的人；购书失败便以帮助换合作，借调查官的权力控制人书，失败后仍想保住原稿与解释权 |
| **调查官，48岁，男**；清瘦，整洁外套、黑手套 | 克制、能干，会照料人也习惯替人作主，难以承认自己曾把事情办坏 | 想治好国王、办结巫案，以王令收束搜捕、恢复粮路；早年亲签扩大搜捕的处置，后期面对错案证据却选择封存，仍真诚地组织救济 |
| **驻村队长，30岁，男**；高瘦，短棕发、旧甲衣 | 爱面子、讲纪律，务实而怕失职，真心想保护乡民 | 先信名单、亲自搜家，外查失踪后被莉莉塔救回，逐渐以亲历行为判断人，为她签担保，最终拒令被撤职，仍自愿协助救人 |
| **国王，58岁，男**；早期肥胖、华贵寝衣，后期严重异变 | 好享受、怕衰老，把自身需要当作王国需要 | 从恢复精力到不断加药、征人求治，最终成为无法救治的末期魔物；主要通过前史物件、绘本与最后战斗出现 |

其余行商、村民、教士及官员按情节需要承担功能，已被处决的医者只存在于猎巫前史中，暂不展开额外角色的个人故事线。

队长是唯一持续出场的驻军角色，其余士兵承担守村、巡查与救援功能，不单独开人物线；他的立场变化由搜查、被救、担保和拒令逐步体现，不以一次报恩代替整个转变。

调查官相信治好国王、交出明确结论后，自己才能取得收束各地乱捕的王令；他真想恢复地方生活，也真赏识莉莉塔的本领，却将受宫廷征用视为替她安排了更好的未来，忽略她只想带养母回家的意愿。

他的转变是误信案卷、纠正个别不实指控，继而以征用换取可控的研究成果，最终在旧令与病历面前拒绝承认整体处置有误；药剂师要证明研究成功，调查官则需要相信自己签过的处置没有白白害人。

## 五、必要前史

- 格蕾丝年轻时在小村行医，无法生育的她后来收养商队留下的孤儿莉莉塔，莉莉塔自幼见过旅者对养母的巫术指控与敌意；格蕾丝又偶然在一捆廉价旧书里买到拉结尔，不知道它曾经的主人是谁。
- 药剂师早年从拉结尔抄下部分生命修复知识，赴宫途中装书的行李被盗，外表普通的旧书随赃物转卖流入旧货市场，他多次寻书无果，只能依靠抄本继续研究，后来凭奉命研制的皇室壮阳药取得地位，又为扩大成果将它推广为净化灵药。
- 王都及周边先因官员挪卖好粮、发放问题粮而集中患病，追问病因的医者遭巫术指控与处决，调查官采信经刑讯加工的供词、签发扩大搜捕的处置，净化灵药则被当成对抗巫术的恩赐。
- 世界原本没有魔物，药剂中的魔法病毒具有传播性，长期恐惧会引导其修复出恐吓与防御性的身体结构，猎巫加重异变，异变又被用来证明猎巫必要，最终蔓延成全国灾难。
- 格蕾丝发现搜捕正在追查自己的买药者，又听闻西边行医旧识所在的村庄出事，误以为独自离开能让莉莉塔脱离牵连，便想查清情况后回来，却在沿途救人时被捕。

### Act I／第一幕：建立与出发

#### Sequence 1：日常与催化事件（第1—2条）

1. 序章绘本从被格蕾丝抱起的莉莉塔视角开始，经喂饭、看她行医、偷配药失败、野外认药及集市受旅人非议，最后停在夜里焦虑的格蕾丝和半打包的行囊上。
2. 序章最后一画中莉莉塔次晨找不到格蕾丝，也没有任何留言，进入村庄后通过队长与村民的AVG对话经历搜家，发现驻军正在追查自己的养母。

#### Sequence 2：困境与锁入（第3—8条）

3. 莉莉塔为补齐草药首次出村战斗，归村向队长报告魔物后，又在处理材料时唤醒自恋的旧书拉结尔，学会新的炼金配方。
4. 队长留下守兵、亲率小队外查后失踪，下一关战前绘本交代村庄夜袭与留守士兵无力另派救援，莉莉塔决定带药出门找人。
5. 她在战后绘本中救回当初搜家的队长和幸存伤兵，回村后又用自己合成的药照护伤者，想继续维持格蕾丝留下的药屋。
6. 部分村民因格蕾丝的嫌疑要求停药，获救的队长承认莉莉塔救过自己、暂准药屋供药，反对者仍向教会举报药屋继续营业。
7. 莉莉塔为去集镇打听养母清通商路，往来恢复后，常来村里买药的商旅告诉她曾看见格蕾丝往河畔集镇方向去，寻母首次有了可靠线索。
8. 调查官到村发放救济、排除未经证实的害人指控，却仍要求药屋受查，队长以救人清路的实绩争取担保，调查官准她继续供药与有限外出。

### Act II／第二幕：追寻与代价

#### Sequence 3：最初阻碍与利害扩大（第9—11条）

9. 莉莉塔沿恢复的商路到河畔集镇寻找格蕾丝，看到药铺被封、医者家属逃亡，贵族药车却可以优先通行，普通买药往来也会被记进搜捕名单。
10. 她循格蕾丝的行医足迹到受灾村庄清路取材，沿途遗物显示饥病早于施药和猎巫，旧搜捕令上调查官的署名为其过往处置留下线索。
11. 莉莉塔得知格蕾丝曾往贵族庄园借药，便带着沿途收集的材料前往药房，在那里遇见正在收购药材的皇室药剂师。

#### Sequence 4：第一次高潮／中点（第12—15条）

12. 药剂师付清报酬、教她改良配方，认出寻觅多年的拉结尔后立即高价求购，拉结尔却先要求旧学生承认那些被抄走的知识究竟是谁教的。
13. 莉莉塔拒绝出售伙伴，药剂师仍兑现教学和报酬，从征用名册查明格蕾丝已被押往王都，随后提出用入城与见人的门路换取同行借阅。
14. 药剂师致信仍在村庄的调查官申请御药协作，调查官认可莉莉塔的本领、签发征用通行文书，她却只被告知可以免受盘查，不知道两人已私下议定研究条件。
15. 调查官先行返都，传令队长随药车入城说明担保情况，队长交代留守安排后启程复命，莉莉塔也借药车门路继续寻母，沿途看见其他家庭仍受盘查阻拦。

#### Sequence 5：进展与逆转（第16—19条）

16. 朝圣路上的药瓶题签、庄园批注与用药痕迹，逐渐拼出净化灵药最初只是皇室壮阳药、后来才被扩大用途的经过，药剂师却总将失败病例归为研究尚未完成。
17. 莉莉塔清通运输道路、随药车进入告示中安宁繁盛的王都，实际见到的却是空集市、封死的药铺、挤满病人的院落和继续押送医者的队伍。
18. 王都粮账与沿途遗物揭出贪腐被包装成巫术、失踪死亡被删出疗效统计，旧处置与死者记录中的相同名字又表明，调查官的签印曾推动真实的搜捕与处决。
19. 莉莉塔借药剂师的门路找到格蕾丝，开口问什么时候回家，格蕾丝却先让她搬开挡路的药箱，两人才在照顾病人的间隙说起那场没有告别的离开。

#### Sequence 6：主要危机／第二幕转折（第20—23条）

20. 莉莉塔为返程讨伐取材，格蕾丝则将亲自积累的病历、拉结尔的原理与宫廷记录对照，发现恐惧会引导病毒的异常修复，而猎巫正在不断制造这种恐惧。
21. 格蕾丝确认既成异变无法逆转、尚有人性者可以照护稳定、彻底失去人性的末期无法救治，拉结尔也发现旧学生为了尽快交出成果跳过了长期观察。
22. 药剂师拿出同样盖着调查官签印的附条，要求独家研究合作、继续使用征用者试药以换取格蕾丝获释与返乡庇护，莉莉塔才发现早在庄园两人便已替她议定了条件。
23. 莉莉塔拒绝交易、药剂师撤回庇护，调查官仍认定宫廷征用才是妥当安排、按附条扣留人书，队长因拒绝押送医者和患者被撤职收剑。

### Act III／第三幕：撤离与归家

#### Sequence 7：新的行动与最终高潮（第24—26条）

24. 队长凭守备经验协助众人安排撤离，宫廷却为救治国王封锁出路，莉莉塔在打通通道时从寝床、门框、药具与连续处方看见国王不断加药后的变化。
25. 格蕾丝以病历和旧处置指出御药危害与猎巫错案，药剂师仍称肉体存活便算成功，调查官拒绝重审、坚持先救国王，直到国王彻底失控堵住撤离通道。
26. 莉莉塔讨伐国王、队长与自愿帮忙的守卫撤出幸存者，调查官留下调粮安置其余灾民，同时封存御体、王印及自己签过的旧案。

#### Sequence 8：结果与尾声（第27—28条）

27. 药剂师趁乱携原稿逃离，在撤离队伍中被格蕾丝发现后，交出记录换取同行并接受看管，仍坚持自己只差最后一步，失去支配同行患者与药物的权力却没有得到原谅。
28. 母女回村商量行医与外出的安排，失去军职的队长仍以村民身份帮忙，而调查官签发的灾病已平告示与仍需救济的流民一同传到村外。

## 七、幕后约定与叙事呈现

- **固定循环**：村庄准备与选关 → 需要时播放一次战前绘本 → 类幸存者战斗 → 需要时播放一次战后绘本 → 结算归村、炼金养成及重要NPC短对话；每个位置都是可用机会，不要求每局全部填满。
- **绘本分工**：序章交代母女过去与失踪，战前交代本次外出的动机，战后表现带回的人、物与新发现；通常一至两幅静态画面配短文字，序章集中使用八幅画面，以羊皮纸与单色手绘为主、特殊内容少量点色；序章八画首版已按现行画风交付，后续继续精修，不等于最终美术冻结。
- **村内AVG**：NPC有新主线内容时显示提示，当前剧情阶段只进行一次短对话，群体争执合并为同一场，不让玩家反复找多人确认相同事实；战斗中的救援过程用战后绘本收束。
- **推进规则**：主线节点首次完成才推进相应剧情，重复刷取材料不会反复播放、重复救人或继续推进事件，失败重试也不提前触发救援成功；选关时保留下一目标的一句话说明，跳过演出仍能知道去哪里、为什么去。
- **私下约定（创作说明）**：药剂师在庄园求购遭拒后，以补全御药申请征用协作、争取独家主持研究；调查官想以救王成果取得收束搜捕的王令，因而暂缓查扣、准许通行和接触格蕾丝，要求结论先报宫廷、未经许可不得离开，拒绝协作便恢复扣押；格蕾丝须待成果获准后才可释放，药剂师不能自行放人。
- **莉莉塔的知情范围**：庄园阶段只知道借阅与通行安排，不知道药剂师把暂缓扣押和母亲获释都系在研究条件上，药剂师以保护者自居、隐去附条，直到她提出带格蕾丝回家才出示完整条件；玩家前期只看见来往信使与调查官签印，不插入两人密谈的旁观过场。
- **玩家的明确目标**：出村打怪取材、回村合药与解锁下一关，寻找格蕾丝提供持续方向；剧情不另加护送操作、路途中长对话或多人往返的长任务线，连续发生的重要事件可收在同一主线关卡的前后。
- **碎片化线索**：绘本画面中的告示、药瓶纹章与异常器物，以及少量物品描述互相印证；每次重点只增加一项认知，前史不依赖大量文书阅读。
- **直接演出的冲突**：搜家、莉莉塔配药遭质疑、药剂师的附带条件、队长的拒令由村内AVG或关卡前后绘本清楚呈现，人物当前为何阻拦或帮助莉莉塔始终清楚。
- **轻快与黑暗的分工**：轻快感来自莉莉塔的直白、拉结尔的虚荣、母女斗嘴和有回报的炼金建设，沉重内容留在细节与后果里，不以患者的苦难充当笑料。
- **村庄养成范围**：保留获救者定居、医护和设施解锁的玩法框架，暂不展开工坊经营剧情或独立救赎支线，具体招募角色待功能需要明确后再决定。
- **药屋与早期审查**：莉莉塔承接日常供药与炼金成长，医护由药屋功能表现；调查官早期核查的是她沿用涉案医者配方的行为，缺乏害人实据时可由队长担保暂缓限制，保留归村与外出的玩法空间，拉结尔则尚未被发现。
- **调查官的认知变化**：前期误信正式案卷、能纠正个别不实举报，中期真心认可莉莉塔却把征用当作保护，王都阶段确知反证后，为维护自己曾经批准的处置而拒绝重审、封存旧案；这些选择均发生于原有节点。
- **队长的行程与权限**：他外查失踪时由留下的士兵守村，获救休养后才能继续履职；中期主要在村庄，直到奉召随药车赴王都复命，离村期间不在两地同时出现；撤职后只能凭经验和他人自愿协助救人，不能继续签新担保或以军令调兵，返乡也不自动恢复军职。
- **结局余波**：回家解决的是莉莉塔的寻找与母女关系，既有异变仍在，药剂师仍须面对责任，队长仍承受追责，全国猎巫与宫廷隐瞒不会随国王死亡自动结束。
