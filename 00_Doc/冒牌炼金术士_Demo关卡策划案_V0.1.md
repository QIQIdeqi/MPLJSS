## 2.1 关卡设计目标

- 玩家进入固定地图后立即进入战斗循环，不依赖额外探索交互。

- 普通怪物压力由波次配置控制；怪物强度按生存时间逐步提升。怪物数量不得使用未配置的时间线性增长公式。

- 最终 BOSS 是整局胜利目标；最终 BOSS 暂定不掉落宝箱或材料。

- 局内系统界面打开时完全暂停战斗模拟与计时，避免玩家管理系统时继续承受战斗压力。

# 4. 单局主流程与状态流转

## 4.1 主流程

**1.** 进入 Demo 关卡，加载固定地图、固定出生点、摄像机边界与本关配置。

**2.** 初始化游戏内计时器与普通怪物波次配置；在数量上限约束下立即生成初始普通怪物。

**3.** 关卡进入进行中状态：普通怪物按波次配置持续生成；精英怪按时间窗口、固定间隔及轮换顺序刷新。

**4.** 游戏内生存计时达到 5:00，启动最终 BOSS 预警。播放特殊演出、音效和 UI 提示；关卡模拟与其他生成器继续运行。

**5.** 预警持续 10 秒游戏内时间后，最终 BOSS 正式出现，并主动寻找、追击玩家。普通怪物与精英怪继续按已有规则刷新。

**6.** 玩家继续战斗；若玩家死亡，立即进入失败流程。若最终 BOSS 被击败，则结束本局并进入胜利流程。

**7.** 精英怪死亡时生成宝箱；玩家靠近宝箱后自动开启，获得该精英怪对应的专属材料及额外普通材料。

## 4.2 核心状态

| **状态**     | **进入条件**             | **状态行为**                     | **退出条件**                                         |
|--------------|--------------------------|----------------------------------|------------------------------------------------------|
| 关卡初始化   | 玩家进入关卡             | 加载地图与配置；生成初始怪物     | 初始化完成后进入进行中                               |
| 进行中       | 初始化完成或系统界面关闭 | 推进计时、战斗、怪物生成与事件   | 打开系统 UI、BOSS 预警、胜负终止                     |
| 系统暂停     | 打开任一局内系统界面     | 整个游戏模拟与所有计时冻结       | 关闭系统界面                                         |
| BOSS 预警    | 生存计时达到 5:00        | 演出/音效/UI 警告；计时仍推进    | 预警剩余时间归零；系统暂停为覆盖态，关闭后继续倒计时 |
| 最终 BOSS 战 | 预警结束，BOSS 生成      | 继续普通/精英生成；BOSS 追击玩家 | 玩家死亡或 BOSS 被击败                               |

## 5.1 地图制作要求

- 地图资源与碰撞层分离管理：装饰表现不应默认等同于不可通行碰撞。

- 固定地图须提供明确的可玩边界与玩家出生坐标。

- 摄像机移动范围以地图边界为准，边缘处不得显示边界之外的可玩空白区域。

- 普通怪物与精英怪的生成点必须通过合法性检查；不可把单位直接生成在地图外或已确认的不可穿越障碍物内部。

> **待确认：怪物寻路与碰撞**
>
> 当前尚未确定普通怪物、精英怪、最终 BOSS 是否都必须绕过不可穿越障碍物，以及是否允许某些敌人穿越障碍。正式制作敌人导航前必须锁定该规则。

# 7. 普通怪物生成系统

## 7.1 设计原则

普通怪物生成参考《吸血鬼幸存者》的时间波次配置思路：初始生成后，常规生成器按波次表运行。波次表负责规定可生成怪物类型、最低存活数量和生成间隔；场上数量不会仅因为时间流逝而自动线性增加。怪物强度随生存时间提升，但强度曲线属于后续数值策划内容。

## 7.2 波次配置逻辑

**1.** 关卡开始时立即生成初始普通怪物，初始生成数量受全局数量上限约束；若配置数量超出可用容量，只生成到上限为止。

**2.** 普通波次原则上按分钟切换配置。每个波次指定当前允许生成的怪物类型池、最低存活数量目标和生成间隔。

**3.** 每次周期生成检查时，如果场上存活敌人数低于当前波次最低数量，生成当前波次怪物以补足目标。

**4.** 如果场上存活敌人数已达到或超过当前波次最低数量，则按当前波次生成规则继续周期性生成怪物（每个已配置怪物类型至少一次的参考规则）。

**5.** 普通周期生成受全局存活敌人上限限制。总存活敌人达到上限时，普通周期生成暂停；当总存活敌人数重新低于上限时，普通周期生成自动恢复。

**6.** 精英怪与最终 BOSS 采用独立事件生成逻辑，不因普通周期生成器停止而被拦截。由于精英怪与 BOSS 可以独立生成，总存活敌人数允许超过普通生成器的默认上限。

**7.** 最后一组常规波次结束后，继续使用最后一组配置的怪物类型；后续阶段的数量目标与生成间隔另行配置。

## 7.3 当前生成器参数

| **配置项**       | **当前规则 / 状态**                                                                    |
|------------------|----------------------------------------------------------------------------------------|
| 全局存活敌人上限 | 默认 300，可配置调整。                                                                 |
| 统计口径         | 达到上限判断时，统计总存活敌人数量；普通怪物、精英怪和最终 BOSS 均计入“当前总存活数”。 |
| 上限触发         | 总存活敌人数达到或超过上限时，停止普通周期生成。                                       |
| 上限恢复         | 总存活敌人数降到上限以下后，普通周期生成自动恢复。                                     |
| 初始生成         | 开局立即生成；受同一上限约束。                                                         |
| 怪物数量增长     | 不采用单纯随时间线性加怪；每个波次的最低数量、生成间隔与类型池由配置决定。             |
| 强度增长         | 随生存时间逐步提升；具体属性项、曲线与倍率待战斗/数值策划案确认。                      |
| 后期波次         | 沿用最后一组怪物类型；后续数量与间隔采用独立配置。                                     |

# 8. 精英怪生成系统

## 8.1 已确认规则

| **规则点** | **要求**                                                         |
|------------|------------------------------------------------------------------|
| 出现形式   | 按预设的时间段与固定间隔出现，不是无限随机即时刷新。             |
| 时间窗口   | 每段配置有起始时间与结束时间。                                   |
| 首次生成   | 到达起始时间后等待一个完整刷新间隔，再生成第一只。               |
| 后续生成   | 在时间段内，按固定间隔继续生成。                                 |
| 类型轮换   | 按照关卡配置的固定顺序轮换；同一种精英怪可重复出现。             |
| 同时存活   | 前一只精英怪尚未死亡时，仍可生成下一只，允许多只精英怪同时存在。 |
| 生成位置   | 玩家摄像机视野之外的合法位置。                                   |
| 时间段结束 | 停止生成新的精英怪；已经生成的精英怪继续战斗。                   |
| 掉落       | 所有精英怪死亡后必定掉落宝箱。                                   |

## 8.2 推荐配置数据结构（具体数值待填）

| **字段**          | **用途**                       | **示例 / 备注**                      |
|-------------------|--------------------------------|--------------------------------------|
| EliteScheduleID   | 精英刷新时间表唯一 ID          | 如 EliteSchedule_A（仅字段示例）     |
| StartTime         | 该时间段起始游戏时间           | 待配置                               |
| EndTime           | 该时间段结束游戏时间           | 待配置                               |
| SpawnInterval     | 相邻刷新计划之间的固定间隔     | 待配置                               |
| EliteRotationList | 按顺序循环的精英怪类型 ID 列表 | \[Elite_A, Elite_B, Elite_C\] 仅示意 |
| SpawnPositionRule | 玩家视野外合法位置             | 已确认原则；寻点失败后的处理待确认   |
| DropChest         | 是否保证掉落宝箱               | 所有精英怪固定为 true                |

## 8.3 时间窗口实施约定（待评审）

> **建议采用半开区间**
>
> 为避免结束时刻发生额外刷新，建议时间窗口按 [StartTime, EndTime) 处理：起始时间有效，结束时间不再安排新的精英怪。如果 StartTime + SpawnInterval 已到达或超过 EndTime，则该时间段不生成精英怪。该约定符合“起始后等待完整间隔”“时间段结束后停止新生成”的已确认规则，但仍需在评审时冻结。

- 每一段精英怪轮换列表和每种精英怪的资源 ID。

- 视野外合法生成点不足、被障碍物阻挡或无法寻到位置时的重试与兜底规则。

- 精英怪对固定障碍物的碰撞与寻路方式。

# 9. 最终 BOSS 事件流程

## 9.1 触发规则

| **项目**       | **规则**                                                       |
|----------------|----------------------------------------------------------------|
| 数量           | 本 Demo 关卡只有 1 个最终 BOSS。                               |
| 预警开始       | 游戏内生存计时达到 5:00 时触发。                               |
| 预警表现       | 特殊演出、音效和 UI 提示组合。                                 |
| 预警时长       | 10 秒游戏内时间。                                              |
| 正式出现       | 预警结束后，按当前规则在 5:10 正式出现（以有效游戏内时间计）。 |
| 行为           | 出现后主动寻找并追击玩家。                                     |
| 战斗期间普通怪 | 继续按普通怪物波次规则生成。                                   |
| 战斗期间精英怪 | 继续按预设的时间窗口与固定间隔刷新。                           |
| 生存计时       | BOSS 出现后继续计时，但计时不决定首领战结束条件。              |
| 被击败         | 结束整局并进入胜利流程。                                       |
| 掉落           | 最终 BOSS 暂定不掉落宝箱，也不掉落材料。                       |

## 9.2 事件流程

**1.** 持续监听游戏内有效生存时间。

**2.** 当时间首次达到 300 秒且尚未触发预警时，锁定 BOSS 预警状态并播放预警演出、音效和 UI。

**3.** 预警倒计时按有效游戏时间推进 10 秒；系统 UI 打开时，倒计时暂停。

**4.** 倒计时归零时生成最终 BOSS，进入 BOSS 战状态；生成必须绕过普通生成器的上限判断。

**5.** 最终 BOSS 持续追击玩家；普通怪物与精英怪生成器继续按其自身规则运行。

**6.** 玩家死亡优先进入失败结束；最终 BOSS 死亡则进入胜利结束。

## 9.3 待确认项

- 最终 BOSS 的具体生成位置规则（地图固定出生点、视野外合法位置或其他方式）。

- 最终 BOSS 的碰撞、障碍物寻路与被卡住后的恢复规则。

- 最终 BOSS 死亡后的演出时长、战斗输入是否立即禁用、何时切换到胜利结算界面。

- 最终 BOSS 不掉落材料/宝箱为暂定规则，需在系统奖励设计冻结时再次确认。

# 10. 精英怪宝箱与奖励

## 10.1 触发与开启

**1.** 精英怪死亡后，必定生成对应的宝箱。

**2.** 玩家靠近宝箱后，宝箱自动开启，不要求额外交互输入。

**3.** 宝箱奖励由精英怪类型关联的掉落配置决定。

**4.** 每种精英怪对应自己的专属材料；宝箱奖励必须包含该精英怪对应的专属材料，并额外发放普通炼金材料。

## 10.2 奖励规则

| **奖励类别**   | **已确认规则**                               | **未确认内容**                             |
|----------------|----------------------------------------------|--------------------------------------------|
| 精英怪专属材料 | 每种精英怪有自己的专属材料；对应宝箱必定发放 | 每次发放数量、是否有多个专属材料 ID        |
| 普通炼金材料   | 在专属材料之外额外获得普通材料               | 普通材料池、数量、固定/随机规则            |
| 最终 BOSS      | 当前暂定不掉落宝箱、不掉落材料               | 正式版是否保持该规则需后续复核             |
| 入库位置       | 奖励用于炼金合成                             | 局内暂存库存还是局外永久库存待系统策划确认 |

## 10.3 防止重复领取的实现注意事项

程序实现时需要保证同一个宝箱的奖励只被结算一次，避免玩家反复进入检测范围而重复发放。建议为宝箱设置“未开启 / 已开启”状态；这是避免重复奖励的技术性实现建议，宝箱打开后是否保留可视物、是否播放开启动画可在后续 UI/美术需求中确定。

# 11. 局内暂停与时间管理

> **已冻结的核心规则**
>
> 打开任何局内系统界面时，整个游戏模拟与所有计时暂停。此项不是仅暂停玩家输入，而是暂停整个关卡模拟。

## 11.1 暂停时必须冻结

- 玩家、普通怪物、精英怪和最终 BOSS 的移动与行为逻辑。

- 投射物、技能效果、伤害结算和持续状态计时（如系统按游戏模拟运行）。

- 普通怪物波次的生成计时、精英怪时间窗口与固定间隔计时。

- 生存计时、最终 BOSS 预警倒计时，以及其他所有由游戏内时间驱动的事件。

## 11.2 恢复规则

- 关闭系统界面后，从暂停时的状态继续运行，不补算暂停期间经过的现实时间。

- 如果暂停发生在 BOSS 预警期间，剩余预警时间保持不变；恢复后继续倒计时。

- 如果暂停发生在精英怪计时窗口内，起止时间与下一次计划刷新时刻均应冻结。

## 11.3 待系统策划确认

“任何局内系统界面”已确定为统一暂停原则，但具体界面清单（例如暂停菜单、炼金界面、图鉴、设置、材料库存等）需在系统策划案中逐一列出。所有被定义为局内系统界面的页面必须调用同一暂停状态，不允许各界面单独实现彼此冲突的时间控制。

# 12. 胜负与结算规则

| **触发条件**            | **局内结果**   | **结算规则**                                                               |
|-------------------------|----------------|----------------------------------------------------------------------------|
| 玩家生命归零 / 角色死亡 | 本局立即结束   | 进入失败结算；结算界面具体内容待系统策划确认。                             |
| 最终 BOSS 被击败        | 本局结束       | 进入胜利结算；最终 BOSS 本身暂不掉落宝箱或材料。                           |
| 精英怪被击败            | 继续当前关卡   | 生成宝箱；不结束整局。                                                     |
| 普通怪被击败            | 继续当前关卡   | 掉落货币与普通材料，具体概率和数量引用数值配置；不制作经验等级或经验掉落。 |
| 游戏内计时持续增长      | 不直接结束本局 | Demo 无强制总时长；最终 BOSS 死亡才是胜利结束条件。                        |

> **规则解释**
>
> 此前“单局 10–20 分钟”的描述已被后续确认取代。当前不强制总时长，第一关在 5:00 触发预警、5:10 出现最终 BOSS，玩家需要击败它才能胜利。

## A.2 《吸血鬼幸存者》生成机制参考

用户要求普通怪物生成参考《吸血鬼幸存者》。本稿采用公开社区 Wiki 对其常规敌人生成的描述作为机制参考：进入关卡时生成初始敌人，之后按时间波次切换；每个波次有最低敌人数与生成间隔；未达到最低数量时补足，达到最低数量时仍按波次规则生成；存活敌人达到 300 时常规周期生成暂停，首领或地图事件单位仍可独立生成。该说明来自社区维护资料，并非开发者公开的完整源代码，因此本项目应以可观察、可配置、可测试的规则为准，而不是声称逐行还原原作内部实现。
