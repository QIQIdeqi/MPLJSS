01 / 冻结输入

先确认尺度、碰撞与生成语义

以当前 UE 原型尺度为工作参考；新布局和坐标转换仍需评审。统一加权抽样与分批补充，确认镜头参数和敌人绕障能力。

02 / 白盒搭建

边界、出生、8 段障碍、可走区域

将坐标换算到 UE 地面平面。中央和外围连通；装饰片不自动带碰撞。各障碍组至少两侧绕行，测试冲刺、投射物与大型单位。

03 / 全程验证

完整跑到 Boss，并覆盖 6:00 精英

保持强化等级、镜头和版本一致。基线与 TUNE-001B / DROP-001 分开记录。观察材料回收、首次制作、连锁、死亡原因及战长。

04 / 验收后表现

把碰撞轮廓转成全 2D 片的场景表现

保持贴片遮挡不盖住玩家和预警；美术资源不改变已验收通路宽度。完整怪物/Boss 行为尚未补齐时，不宣称关卡体验全部通过。
