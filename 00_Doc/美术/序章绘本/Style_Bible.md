# 《冒牌炼金术士》序章绘本 Style Bible

更新：2026-10-31。用户已明确要求“video skill，生图完成序章图片”，现已完成[八画首轮图片](storyboard/README.md)，使用内置image_gen并保存本地。方向：羊皮纸主底、深褐单色手绘、少量有叙事意义的点色；首版仍可继续审美精修，不等同于动画或最终美术冻结。

依据：[故事总纲](../../故事/冒牌炼金术士_故事总纲.md)、[第一幕P00](../../故事/第一幕分场大纲.md)、[莉莉塔原始形象](参考/莉莉塔_用户原始三视图.jpg)。视觉参考：[单色排线](参考/风格参考_01_单色排线.png)、[书页排版](参考/风格参考_02_书页排版.png)、[特殊彩色](参考/风格参考_03_特殊彩色.png)。只借鉴视觉语言，不复制角色、台词、图案、水印或界面。旧水彩和纯轮廓稿归入“探索”，不作现行风格基准。

## 1. 核心观感

**一本温柔、略带笨拙幽默的旧童话：人物像从书页里画出来的，感情却是真实的。**

温暖、有爱、轻快，故事从莉莉塔的生活感受出发；黑暗先藏在旅人的指点和夜里的行囊中。画面通过角色大小、轮廓、夸张表情与留白成立，避免写实人体和堆满家具的背景。

单色不是只剩干净轮廓。参考图的识别点是**粗细变化的墨线、顺形排线、深墨块与纸面留白的对比**。不做涂色本线稿，不将精细日漫或水彩滤成棕色；也不做阴暗恐怖版画。

## 2. 纸面、线条与明暗

| 项目 | 固定规则 |
| --- | --- |
| 主底 | 浅羊皮纸 `#E8D8B6`，整体保持纯净平稳；可有很轻、固定的纸感，不反复生成烧焦边、黄褐光晕与脏污 |
| 主墨 | 深褐 `#513B2B`，通过线条疏密表现明暗；不增加写实灰色铺面或彩色阴影 |
| 外轮廓 | 比内部结构线粗，略有手压、断笔与毛边；拒绝均匀光滑的矢量描边 |
| 内部线 | 只交代必要结构，头发与布料用少量方向清楚的线；不逐根画发丝或画满蕾丝 |
| 排线 | 沿头发、布料或器物形状走，集中于披风背面、袖口、遮挡处；脸和大面积纸面保持干净 |
| 墨块 | 小面积加强披风、鞋底或遮挡，不能把银白头发填成黑色 |
| 背景 | 每幅优先保留两三件看懂事件必需的物件；密度低于人物，不恢复复杂水彩场景 |

色号是制作目标，生成图允许轻微偏差和抗锯齿，但明显的跨画底色漂移须修正。全篇纸感应来自统一底层，不能在动画中滚动或随机变化。

## 3. 颜色承担叙事

日常单色；出现颜色表示“莉莉塔此刻特别看见、理解或记住了什么”。不是给本来有颜色的物件逐个涂色，红瞳与玫瑰花环也不固定例外。

| 层级 | 用法 | 约束 |
| --- | --- | --- |
| 常态 | 浅纸与深褐墨，含同墨排线的深浅 | 序章绝大多数画面 |
| 局部点色 | 一种低饱和色，只在一个关键对象上，约占插画面积5%以内 | 首轮P05已采用面前一株草药点灰绿，制作目标 `#79835C`，表示开始真正认识草药；最终统一方案仍可精修，可保留单色版作比较 |
| 情感高潮 | 暖金 `#C7A04D` 可围绕核心人物或意象适当扩展，保留原墨线 | 留给后续重逢等节点，不在序章每画使用，不据参考增加星海或法术 |

P04不画彩色爆炸火球，P06不用红黑滤镜强调敌意，P07也不因夜晚自动加蓝色。加色必须预先写明对象与理由；模型随意补色属于偏差。

## 4. 两位角色的固定符号

### 格蕾丝

42岁女性，偏瘦，普通草药医生，**不会魔法**。成年轮廓约四至五头身，与莉莉塔明显区分；低发髻、一根木簪、两缕颊边发、略长脸与温和小眼睛。长裙、卷袖、腰系围裙、正面一个大口袋、简单短靴。银灰头发用纸色留白和少量线条表示。

温柔来自眉眼、微笑和照顾人的姿态；略严肃也有亲近感。不能画成同龄少女或老妪；不加魔女帽、法杖、尖耳、法术。回忆中的她更年轻，脸部纹理减少，发型与服装轮廓保持。

角色规格见[grace.md](角色/grace.md)。[现有全身候选](角色/格蕾丝_排线风格候选.png)仅用于辨认身份，比例与精细程度仍待简化，不能作为正式绘本的景别模板。

### 莉莉塔

保留原图的**大弯呆毛、长发、玫瑰花环、短披风**。花环简化成约五个玫瑰螺旋与少量叶子；围巾扣为双螺旋，披风一枝蕨叶，肩绒用短轮廓表示，裙边保留波浪，系带靴不刻画每条鞋带。

幼年约两至三头身，圆脸、短四肢；十四岁仍娇小，腿与披风下摆略拉长。发色内部留纸色，普通画面眼睛与花环也用褐墨。婴幼儿画面不套全套冒险服；家务与采药不用法杖。单色角色候选与正式角色板尚未确认；八画首版的交付不把探索稿升级为最终身份锁定。

角色规格见[lilita.md](角色/lilita.md)。[现有全身候选](角色/莉莉塔_排线风格候选.png)只提示身份符号，后续角色板以半身表情、蹲姿及局部细节为主。

### 背景人物

病人只留枕头、被子和普通疲惫表情，无伤口或死亡暗示；旅行者用简化旅行帽与斗篷，在边缘较小。二者不另开人物线，病人不作为笑料。

## 6. 书页与未来动画

**构图必须灵动，身份基准不等于站姿模板。** 允许人物出框、近大远小、越肩遮挡与不对称留白；连续画面不能一律正视、同距离、全身并排。完整方案见[序章构图与节奏](序章构图与节奏.md)。八画的景别节奏为：贴近的主观仰视 → 饭勺连接的双人中近景 → 门边越肩 → 沮丧脸与门边笑意 → 草药牵引的双人近景 → 集市前后景交错 → 夜里的局部窥见 → 空房间留白全景。

全身与远景在有叙事目的时使用，尤其最后一画用小小身影衬出母亲缺席。变化靠观看位置和信息主次，不靠鱼眼、歪镜头或堆砌道具；不改变八画情节，不增加切镜或任务量。

默认采用展开书页的阅读关系：左侧约四成放独立旁白、右侧约六成放插画，边距统一；不要让每幅原画自己生成一本书。P01近景可跨页；窄屏时文字移到画面下方。文字使用可读的中文衬线字体，不照抄参考字幕，不压在密排线上。

动画以定稿插画为稳定底图，用翻页、淡入淡出和1.00—1.025倍缓慢推拉；不让视频模型重画母女的脸与衣服。建议八画6、7、7、8、7、7、8、7秒，约57秒；允许暂停、手动翻页与跳过。P08呼喊后稍作停顿，再进入队长AVG。

这只是后续制作约定，当前不做完整动画、配音或角色分层。未来若加烟团、眨眼等动作，应先做与原画一致的独立图层和少量关键姿态，再制作，不能将整图生成视频当作已证明稳定。

## 7. 一致性测试与正式制作条件

用户本轮已授权按既有设计完成八画，实际使用同一组人物与风格参考逐幅生成；08另加07作为室内布局参考。八张工作原画均为1672×941的近16:9横幅，未另作程序裁切或重绘。实际参考与完整提示词已保存，见[八画生图记录](制作记录/序章八画_生图记录.json)；未新做角色板、动画或配音，工具未返回费用数字，故不推算费用。

提示词固定为 `STYLE＋IDENTITY＋SCENE＋COLOR`；只改场景与明确的点色对象。风格截图只管笔触，单人图只管角色；禁止继承截图角色、文字、水印或书页边框。每张从同一基准出发，不逐张相互当角色参考，不把seed当作一致性的保证。

| 检查项 | 通过条件 |
| --- | --- |
| 同一风格 | 不同构图仍保持同样粗细线、排线疏密、浅纸主底与背景简化程度 |
| 同一角色 | 发髻与花环不串人，呆毛/披风/扣饰持续可认，母女年龄体态有别 |
| 构图成立 | 主观视角正确、裁切有理由、画内人数准确；近中远景有明确节奏，不回退为重复全身站姿 |
| 情绪适配 | 亲情、失败与好奇均温暖，忧虑不转成恐怖，病人不成为笑料 |
| 点色可控 | 只有指定草药出现灰绿，纸面、人物与其他物件不跟着染色 |
| 流程可复现 | 保存实际提示词与参考编号，记录偏差；不只写“同上” |

本轮逐幅查看了生成结果：01未再出现婴儿头顶，04没有重复格蕾丝，05局部灰绿受控，07半包行囊可见，08只有莉莉塔、空椅及原有床窗，没有信件或养母剪影。此项检查不等于所有细节已定稿；后续可继续统一排线密度、人物年龄与末画留白，动画需另作连续性验证。
