# 村庄外围（第一关）｜美术与关卡制作说明

> 当前试玩与编辑入口见 [Godot 工程说明](../../02_Prototype/AlchemyGodot/README.md)。正文中 Unreal 工程验证和截图为对应迭代的历史记录。

更新：2026-11-05。场景定位：格雷弗德边境村庄外围的开阔草原，少量树林、旧木篱与乡野物件点缀，供莉莉塔战斗、收集和成长。

## 1. 这次要做成什么

**普通关卡与 Boss 都使用两层随机：地面纹理随机组合，物件独立摆放。** 村庄保持现有布局；三处画风、角色尺度和60°近景方向统一。

普通场与 Boss 增加 TOD 昼夜过渡。首测从 13:00 开始，战斗推进时由日间转为暖暮色和冷夜色，进入 Boss 继续本局时刻。树、灌木、短篱和箱袋以贴图轮廓投出长影，影根沿原图脚线贴地，影尾向背光方向拉长并渐隐。预警和掉落在夜间仍需清楚。 [TOD 预览与调参](https://github.com/QIQIdeqi/MPLJSS/blob/fa5c91c74fc1336bb89296af87611b0b8f41ea17/02_Prototype/AlchemyHD2D/Docs/%E5%85%B3%E5%8D%A1TOD%E4%B8%8E%E6%B8%90%E5%8F%98%E6%8A%95%E5%BD%B1.md)

参考图负责画风、配色、尺度和环境语言，图中固定的树、车、篱笆位置不作为每局布局。制作时使用独立纹理和可摆放物件，保证换布局后仍像同一片乡野。

玩法与生成规则统一见[1.4关卡](1.4关卡.md)，本页重点说明场景表现和素材制作。

## 2. 地面与物件怎样搭配

| 部分 | 当前使用 | 制作重点 |
| --- | --- | --- |
| 地面 | 草地为主，少量裸土与鹅卵石路 | 形成自然斑块，相邻地面过渡顺；避免棋盘感、明显重复和过强对比。石路不要误当自然碎石 |
| 普通场物件 | 橡树、灌木、短篱、箱袋 | 大面留空，小簇点缀；短障碍可供绕行、聚怪，但不能围死玩家或堵住回收路线 |
| Boss 内场 | 同套地面、少量低矮灌木 | 中央开阔、纹理安静，让角色、弹丸与地面预警清楚 |
| Boss 外围 | 同风格短篱、箱袋及低矮植被 | 形成边缘层次，不能侵入战斗区或在近镜头侧遮住角色；较高地标待专项适配后再加入 |

当前同套素材已在工程中可用，树、灌木、篱笆和箱袋可继续扩展变体。田车、溪岸、阵石可作为后续环境丰富方向，**不列为已进入当前随机池的物件**。

地面比例、物件密度和间距由策划配置，不画死在整张背景里。当前草地/裸土/石路相对权重为78/20/2，只是起测比例；具体配置见关卡正文。

## 3. 本轮美术制作范围

**先做当前使用的7类素材：** 草地、裸土、鹅卵石路、橡树、低矮灌木、短木篱、箱袋组合。已有素材先统一画风与尺度，再决定增加多少变体；本轮不要求把第一关重画成一张固定背景。

**待确认扩展5类：** 短草与小花簇、自然石块、弃置田车、旧阵石、溪岸边缘模块。它们用于后续丰富环境，尚未加入当前随机池；需求表中的建议尺寸和数量需评审后再制作，不自动增加交互、采集、奖励或挡招玩法。

### 尺寸怎样看

美术需求中的尺寸统一使用**像素（px）**，写作“画布宽×高”。它表示交付PNG的分辨率，包含透明留边，不等于角色在屏幕上的大小，也不直接从游戏里的米数换算。

当前草地、裸土、石路、橡树、灌木、短篱、箱袋的源图画布均为**512×512 px**。当前橡树、短篱和箱袋的脚线为**y=488 px**，以画布左上角为原点；交付时标明脚底位置及底部轮廓，便于接地与设置阻挡。

扩展项建议画布：草花簇256×256 px、自然石块512×512 px、田车512×512 px、阵石256×512 px、溪岸模块1024×512 px。以上为待评审的制作建议，不代表已定稿；游戏内比例和碰撞由关卡配置及实际试玩确认，具体战斗距离仍统一见[1.4关卡](1.4关卡.md)。

### 素材交付与摆放要求

- **地面纹理：** 可平铺，同套尺度和色调一致；检查单张重复及与其他地类交接。地面图案本身不新增碰撞、减速或伤害。
- **独立物件：** 透明背景，脚底位置明确；提供尺寸参照和适合的摆放地面。当前独立素材为512×512像素，新增素材保持清晰度与实际显示尺度一致。
- **尺度：** 以工程中的莉莉塔和现有物件为参照，在实际近景镜头下比较。不要直接照搬参考整图中的像素大小。
- **落地与碰撞：** 树按树干、篱笆按底部占地设置阻挡；树冠与光晕不当作整块撞体。灌木等装饰可无阻挡，但仍要检查视觉遮挡。
- **层次：** 前后遮挡和脚点一致，不漂浮、不埋地；近镜头侧优先低矮物件。强对比和亮色留给角色、掉落与危险提示。
- **可扩展：** 同类变体交付时注明名称、建议尺寸、脚点、是否阻挡和适用区域，便于加入现有关卡编辑器。

## 4. 普通关卡与 Boss 的空间区别

| 项目 | 普通关卡 | Boss：雾界草甸 |
| --- | --- | --- |
| 空间体验 | 开阔草原中穿插少量短障碍，支持绕行、聚怪和回收 | 横向略长的近椭圆内场，中央保持净空，侧移和读招清楚 |
| 出生与交互 | 出生位于预留通路内的合法随机点；主要通路、教学活动和传送接近区域受保护 | 玩家南侧、Boss北侧，开场距离依关卡规格；2秒准备提示不挡双方 |
| 有效边界 | 现有矩形活动范围，实际阻挡跟随随机物件 | 近椭圆可走区，规格见关卡正文；外围布景不计入有效战斗区 |
| 摆放限制 | 不围死、不断主路；树冠不能遮住出生与交互点 | 场内只放低矮无阻挡装饰，实体障碍留在合法外围；不增加掩体挡招玩法 |
| 镜头 | 60°近景跟随 | 同一近景风格，开场与近距交战兼顾双方和界面避让 |

近景镜头按不同画幅适配，取景规格统一见关卡正文。可走范围、地面覆盖和镜头可见范围不是同一件事；必须用实际画面检查树冠、边缘和技能栏是否挡人。

## 6. 美术交付与共同验收

先提交基础样式与角色同屏的比例样张，再在随机地图内确认，避免一口气完成大量同类变体后返工。每类物件交付可编辑源文件及PNG，附名称、主体尺寸、脚点、阻挡占地与适用区域；建议数量见Excel，不把表中的建议当成已确认排期。

待确认扩展项先评审用途、尺寸和是否阻挡，通过后再排期。地面纹理与透明物件分别交付，不能把地面、景物和阴影合成不可拆的整张场景。

普通场打开工程内 `打开关卡与技能编辑器.cmd`；Boss 打开 `打开Boss随机关卡编辑器.cmd`。分别调整地面与物件，重抽比较，微调后锁定满意部分，保存后从村庄进入正式流程试玩。[详细操作](https://github.com/QIQIdeqi/MPLJSS/blob/fa5c91c74fc1336bb89296af87611b0b8f41ea17/02_Prototype/AlchemyHD2D/Docs/%E9%9A%8F%E6%9C%BA%E5%85%B3%E5%8D%A1_%E4%B8%A4%E5%B1%82%E7%BC%96%E8%BE%91%E4%B8%8E%E9%AA%8C%E8%AF%81.md)。

美术与策划共同看这五件事：

1. **像同一个世界：** 配色、明暗、纹理密度和物件尺度与村庄一致。
2. **能看清：** 不遮角色、掉落、敌人轮廓与危险预警；不同画幅下都成立。
3. **能战斗：** 有退路、绕行与闪避空间，Boss 内场不被装饰挤占。
4. **能操作：** 出生安全，材料能回收，传送阵能走到、站入并交互。
5. **换图仍成立：** 比较多个随机布局，不只批准一张漂亮截图。

当前两层随机、编辑保存、碰撞和代表通路已通过自动检查。下一步重点是实际试玩密度、观感与手感；尚未生成包含此次随机地图的新Windows试玩包。详细测试放在[验证记录](https://github.com/QIQIdeqi/MPLJSS/blob/fa5c91c74fc1336bb89296af87611b0b8f41ea17/02_Prototype/AlchemyHD2D/Docs/Verification/RandomLayers_20261104/README.md)，不作为美术定稿或平衡结论。
