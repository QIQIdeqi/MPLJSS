# 1.4 关卡｜五关与无限地图

本页是关卡策划当前入口。普通场采用无限区块，Boss 采用独立有限竞技场。以下节奏和难度是首轮试玩默认，需按玩家反馈调整。

## 技能测试场

从主菜单进入独立练习关。玩家可直接装备全部基础技能、调等级或切换为指定的组合配方。木桩可切换为 1、3、5 根，始终固定在场地内，承接真实命中、冻结和组合判定。可切换分裂炼金、独立普攻、半血或满血，并一键重置冷却，方便重现回复和命中条件。关卡没有出战消耗与掉落结算，配置在返回菜单时清除。[测试场操作](../../02_Prototype/AlchemyGodot/README.md#技能测试场)

选择雷衣、回浪镜、净路剂、照影或收露瓶后，面板会出现对应的测试条件按钮。测试事件用于复现受击、敌弹、孢子、前摇和拾取，木桩保持固定、永不死亡。回流锚的合围与寒晶墙的实际绕行用可移动的实战敌人验证。

| 关卡 / 稳定 ID | 主要判断与场景组织 | 优先威胁 | 对应 Boss |

| 朝圣路 `pilgrimage_04` | 长石道串起歇脚地，石碑与灯龛引导方向 | 狼扑咬、蝙蝠俯冲与远处水弹 | 突袭型首领：诱导后横移，应对第二次俯冲 |

五个普通关目前都可从村庄出战准备中选择，各自关联一个 Boss；本轮不做剧情解锁条件。首关 Boss 沿用已有形象，其他 Boss 的名称、外形和招式表现属于玩法概念，不据此新增故事事实。

## 无限地图怎样展开

- 标准区块为 **1280×720 px**。附近保持 3×3 个活动区块；移动到新区块时加载邻块，远处移出显示。
- 本局种子、关卡 ID 与区块坐标共同决定地面和物件。相同种子与配置可复现，返回旧区域保持原布局，支持负坐标。
- 数量范围和密度范围按**每个标准区块**计算，不是无限世界的总量。两者同时设置取交集；不能满足时明确报错，保留上一份有效布局，不偷偷减少数量。
- 地面与物件分别随机；贯通主路、区块中心、出生点和跨块连接保留净空。主题主路使用各关配置的道路纹理。
- 普通场没有外圈红线和环山封边；Boss 保留有限边界与细红色提示线。编辑器的普通场画布是一个标准区块预览，不是世界边界。
- 远处未拾取的金币、经验球和材料保存为本局位置数据；回访时恢复一次，不自动拾取。切入 Boss 或结束本局后，未拾取物清除。
- 沿用局外的透视镜头、TOD、天气、积雪、景深与前景淡出。物件按脚底碰撞，树冠不作为整块撞体。

## 时间与心流

| 时间 | 阶段 | 刷新间隔（秒/只） | 存活上限 |
| --- | --- | --- | --- |
| 0～30 | 认识战场 | 1.00 | 12 |
| 30～65 | 第一次合围 | 0.80 | 20 |
| 65～80 | 回收与整备 | 1.30 | 14 |
| 80～130 | 第一次换线 | 0.65 | 28 |
| 130～145 | 整理构筑 | 1.10 | 18 |
| 145～210 | 远近配合 | 0.55 | 36 |
| 210～230 | 地标与收集 | 1.00 | 24 |
| 230～285 | 开门前高峰 | 0.45 | 48 |
| 285～300 | 挑战前整顿 | 0.95 | 28 |
| 300～345 | 继续成长 | 0.43 | 48 |
| 345～375 | 循环高峰 | 0.35 | 48 |
| 375～390 | 循环喘息 | 1.05 | 28 |

300 秒后按“45 秒加压＋30 秒高峰＋15 秒喘息”循环，怪物权重由各关自己的波次表控制。喘息降低新增速度，不删除还在追击的怪物。生命随时间和关卡提高，伤害和移速温和增长；读招时长保留，详见[数值入口](1.6数值.md)。界面暂停时计时同步暂停。

有效战斗达到 300 秒后，在玩家当前区块的预留中心开放一个固定位置的 Boss 入口。可以继续探索，靠近按 F 后再次确认才进入。未完成教程或可选事件都不能阻止挑战；普通场没有强制撤离倒计时。

## 可选支路

可选点按种子稀疏分布，接近触发，同一块在本局只触发一次。它们不改变主路的通行，也不作为开 Boss 的前置。

| 关卡 | 首测事件 |
| --- | --- |
| 外围 | 林缘收集点，出现露与火粉掉落 |
| 商路 | 路障旁物资，可绕开或回收 |
| 庄园 | 孢子支路，局部孢子与材料回收形成取舍 |
| 朝圣路 | 歇脚地，4 秒新增怪物缓冲与经验球；不回血、不清追兵 |
| 下城 | 街口遭遇，额外追兵受当前存活上限约束，可绕开 |

事件奖励和出现频率只是测试默认，不代表最终经济定案。局内沿用当前的自动攻击、升级与素材拾取流程；本轮不重新启用旧版 Q 局内炼金。

## Boss 与跨场

每个 Boss 使用独立场景、布局和稳定 ID。有限场继续随机物件，中央和主要躲招区域保持净空；飞行俯冲不被地面摆件挡住，仍受场地边界约束。

进入时保留生命、等级、经验、技能与升级、能力、冷却、已拾金币和本局材料账本，并延续镜头/TOD/天气状态。地面未拾取物及飞行中攻击离场清除；不因入场回血。胜负或暂停退出继续走原有结算和防重复入账流程。

首关已有招式时序和命中规则沿用现行 Boss 实现；新四种招式是本轮玩法实现，正式外形与完整动画仍需美术迭代。国王当前使用既有 Boss 形象占位，不能当作正式人物设计交付。

## 策划与美术怎么修改

1. Godot 底栏「关卡总表」选择关卡，可快速打开普通或关联 Boss 场景。
2. 「地块与物件设置」进入「Alchemy 关卡」。普通关打开“无限地图”，预览一个标准区块；Boss 关闭无限，可调整有限宽高并实时查看红线。
3. 修改素材条目的次数、密度、尺寸与脚点碰撞，再重摇地面或物件。保存当前关卡配置；每关独立，不覆盖其他关。
4. 「怪物波次设置」调整每波出场权重、间隔与上限。在 Inspector 打开该表可调整循环和成长字段；展开怪物行可改基础生命、伤害与移速倍率。
5. 美术使用[五关需求 Excel](../../outputs/five_regions_art_20261124/五关_场景美术需求案.xlsx)，全部尺寸为 px，含参考缩略图、数量/密度、脚线和碰撞。原第一关与村庄需求表保留。
