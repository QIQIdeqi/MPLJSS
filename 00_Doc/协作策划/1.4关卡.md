# 1.4 关卡｜当前制作方案

更新：2026-11-05。本文供关卡策划、美术共同使用，只保留当前有效规则与关键待办。

## 1. 本轮关键迭代

- **局内改为两层随机地图：** 地面纹理随机组合，物件独立随机摆放；普通关卡与 Boss 都使用这套方式。
- **继续使用原关卡编辑器：** 地面和物件可分别重抽，手工调整的内容可以锁定，不必重做整张地图。
- **先保证战斗空间：** 出生、主要通路、教学活动和传送接近区域不能被摆件堵住；Boss 中央和躲招区域保持开阔。
- **统一画面：** 村庄、普通关卡、Boss 延续同一套乡野画风与60°近景方向。参考图指导画风和尺度，物件位置由布局规则决定。

上述随机地图已接入当前工程。地面比例、物件密度与最终观感仍需试玩调整。

## 2. 一局怎样推进

村庄准备 → 进入普通关卡 → 战斗、收集、炼制与成长 → 5分钟开放 Boss 传送阵 → 玩家自行确认挑战 → 独立 Boss 战 → 胜负结算回村。

| 阶段 | 玩家体验 | 关卡要提供什么 |
| --- | --- | --- |
| 刚进入普通关卡 | 看清角色、敌人和拾取物，找到移动方向 | 合法随机出生点、清楚的退路，不落在树后或障碍中 |
| 早期成长 | 体验基础攻击与炼制带来的变化 | 可回收材料的空间；首次范围技能有小群近战怪可试用，能看见多目标受击 |
| 持续成长 | 在清怪、绕行、回收与炼制之间选择 | 短障碍帮助整理敌群，同时保留绕行和撤退路线；精英与商人允许并存，由玩家选择先后 |
| 有效战斗时间达到300秒 | 选择继续成长或挑战 Boss | 开放随机、避障、可走到的传送阵，提供箭头和交互提示；不强制传送 |
| 进入 Boss | 用本局成长挑战独立战斗 | 清楚的边界、入场准备和读招空间；胜负前不能返回普通关卡 |

5分钟后主要通过增加怪物数量和刷新频率加快压力，具体增长曲线与收益仍待试玩。系统界面暂停时，战斗与战斗计时同步暂停。

**教学不限制自由进 Boss。** 未完成的外围教学在 Boss 场暂时停用，回村再出发后继续；不因进入 Boss 自动标记教学完成。教学材料、炼制与技能成长按[当前战斗策划案](../冒牌炼金术士_Demo战斗策划案.md)执行，本文不再另列一套旧配方和秒数表。

## 3. 两层随机怎样分工

| 内容 | 地面层 | 物件层 |
| --- | --- | --- |
| 当前素材 | 草地、裸土、鹅卵石路 | 普通场：树、灌木、短篱、箱袋；Boss：低矮灌木、短篱、箱袋 |
| 随机方式 | 按比例形成自然斑块，相邻地面有过渡 | 按素材比例、密度、间距、适用地面和允许区域摆放 |
| 编辑方式 | 单独重抽或手工锁定局部地面 | 单独重抽、微调位置，锁定希望保留的物件 |
| 战斗影响 | 纹理变化不新增减速、伤害或阻挡 | 装饰与阻挡分开设置；阻挡按脚底占地，不按整张树冠 |

两层叠在同一张地图上，物件下面仍有地面。“没有物件”是合法结果。不能把带着固定树、车、篱笆的整张参考图铺在底下，再叠随机摆件。

### 必须保留的空间

- 出生点有站立、移动和闪避余量，不能只满足中心点不重叠。
- 主要活动区保持连通；短障碍可用来聚怪，但必须留绕行和退路。
- 教学小群敌人有可达开阔处，不能被障碍分隔到无法体现范围技能。
- 传送阵整体占地及接近路线可用，不能生成在封闭空地或障碍中。
- 树冠、近景物件和界面不能遮住角色、拾取物与危险预警；需要在实际镜头下检查。
- 新布局不合格时不能覆盖上次可用预览，也不能为了生成成功偷偷解除手工锁定。

### 每局如何变化

进入普通关卡或 Boss 时生成，战斗中和暂停界面里不重新洗牌。新开局换地图种子；相同种子、配置和锁定内容可以复现布局，方便共同讨论同一张图。地面、物件和战斗使用独立随机序列，刷怪与炼制不应改变布景。

## 4. Boss 场地与战斗要求

场地为“雾界草甸”，延续普通草原的素材与画风。有效战斗区为横向略长的近椭圆，**32m×26m**；外围布景不计入这个尺寸。

- 中央、双方开场位置和主要躲招空间保持净空；内场只放低矮、无阻挡装饰。
- 大型景物与实体阻挡放在外围合法区域，不能伸进内场形成卡点；本轮不增加利用掩体挡冲刺或挡弹的新玩法。
- 玩家南侧、Boss 北侧，开场中心距 **10m**。画面可操作后有 **2秒准备期**：玩家可移动，Boss 原地等待，双方不攻击；倒计时结束开战。
- 准备期提示避开角色、Boss 血条和技能栏。镜头在准备和近距交战时兼顾双方，不让玩家被界面挡住。
- 传送保留当前生命，不额外回血；技能、冷却及已持材料延续。地面已生成材料按库存上限回收；未拾金币、经验球和宝箱离场清除，确认页需提示。
- Boss 场不额外补炼制材料；可继续使用入场材料炼制并调整技能。炼制、结果与配置界面暂停战斗及准备计时；已有待领取结果先处理再继续。

### 招式给场地和表现的约束

以下是已确认的首轮测试规则，保留用于空间、预警和动画制作；平衡仍需试玩。

| 项目 | 直线冲刺 | 稀疏扇形弹幕 |
| --- | --- | --- |
| 首招选择 | 两种首招各50% | 两种首招各50% |
| 基本节奏 | 1秒预警 → 0.6秒冲刺 → 1秒原地收招 | 一次招式连续两波，每波5颗，两次发射相隔0.8秒 |
| 瞄准与锁定 | 预警全程站定；前0.6秒跟随瞄准，后0.4秒锁定 | 第二波重新瞄准；第一波发出后0.5秒锁定，0.8秒发射 |
| 危险范围 | 沿锁定方向冲12m，伤害总宽2m | 总角度60°；相对中心方向为−30、−15、0、15、30°；速度8m/s，判定直径0.6m |
| 预警表现 | 锁定时地面轮廓由虚变实，并有一次短提示音 | 第二波锁定时显示对应5条实际弹道的预警线，并有一次短提示音；不把整个扇形画成连续伤害区 |
| 命中规则 | 每次冲刺最多一次有效伤害，减伤前24点；命中后继续原方向冲完 | 每颗减伤前18点；每波最多一次有效伤害，两波合计最多两次；有效伤害后该弹消失，无敌接触不消耗弹丸 |
| 后续处理 | 触边提前停下、结束冲刺伤害并收招1秒；不补距离或反弹 | 某波命中封顶后，该波剩余弹丸立即停伤并短暂淡出，不影响另一波 |

冲刺有效命中后，玩家沿锁定方向在0.15秒内被推1m；遇边界或阻挡可截短。击退期间接管移动，结束立即按当前输入恢复，不重复触发或增加独立眩晕。所有阶段遵守暂停续算与现有受伤无敌，伤害按[1.6数值](1.6数值.md)处理。

弹幕封顶后的淡出时长尚未定稿，工程暂用0.15秒。第一波预警、完整后续攻击循环及未细化的弹丸回收表现，以后续专项设计为准，不在场地制作中自行补规则。

## 5. 策划可调整的起测配置

这些是当前工程默认，允许调整，不代表最终数值。

| 配置 | 普通关卡 | Boss |
| --- | --- | --- |
| 地面格数与格长 | 24×18格，每格6m | 14×12格，每格4m |
| 布景覆盖范围 | 144m×108m | 56m×48m；有效战斗区仍是32m×26m椭圆 |
| 地面相对比例 | 草地78 / 裸土20 / 石路2 | 同左 |
| 每格尝试放物件的概率 | 24% | 30% |
| 物件额外间距 | 1m | 1m |
| 保护通路宽度 | 6m | 6m |

比例是抽样权重，不保证每局恰好达到该面积；物件概率也不等于最终数量，间距与保护区会减少落点。地表覆盖、可走边界和镜头可见范围需要分别看，不能混作一个尺寸。

## 6. 怎样编辑与评审

普通关卡打开工程内 `打开关卡与技能编辑器.cmd`；Boss 打开 `打开Boss随机关卡编辑器.cmd`。两者定位到各自配置，试玩仍从村庄开始。

1. 先选同套素材，调整地面比例和斑块大小。
2. 再调物件密度、间距及允许区域；保留出生和通路保护。
3. 分别重抽两层，手工微调并锁定满意的部分。
4. 保存后从正式流程试玩，记录种子、画幅和问题位置，便于复现。

评审重点：**能走、能绕、能回收、能看清、能躲招**。至少比较不同种子，并检查出生、障碍旁、边缘、传送阵和 Boss 开场；普通/超宽/4:3画幅都需看，不能只用编辑器俯视图判断。

详细字段与操作见[编辑器使用说明](../../02_Prototype/AlchemyHD2D/Docs/随机关卡_两层编辑与验证.md)。

当前工程已接入两层随机、真实碰撞与通路检查、分层重抽和锁定、地面过渡及60°近景。自动检查覆盖多种子、多画幅、编辑保存和失败保护，详见[验证记录](../../02_Prototype/AlchemyHD2D/Docs/Verification/RandomLayers_20261104/README.md)；尚未生成包含本次随机地图的新Windows试玩包。
