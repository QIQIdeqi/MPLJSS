《冒牌炼金术士》Demo 更新｜2026.10.28

这次主要完善 PC 界面可读性和战斗反馈，最新 Windows 试玩包已经同步到 Git 远端。

1. 字体与 HUD
默认调整为中号90%、大号72%，小号保持不变。新增 F7 字体调试，可分别微调中号、大号并保存；旧档可点击“恢复推荐值”应用新设置。生命、材料、技能和面板信息重新整理，图鉴长内容支持分页。

2. 怪物受击与掉落反馈
加入实际伤害飘字和受击反馈。普通小怪不显示血条，精英血条常驻，Boss血条移到屏幕上方。

金币改为专用图标，材料分成六种图标，所有掉落物和宝箱已放大。

3. 技能特效
接入 Niagara 命中火花、范围爆发和弹丸尾迹，以橙／蓝／绿／紫区分元素效果。敌人地面预警继续保留；打开局内面板时，粒子和伤害数字会暂停。

4. 当前可体验内容
已接入7组普通材料组合、21个普通技能、3个精英专属技能和10套自动连锁。普通炼金支持3–10个材料投入，可点击或拖拽投料，并查看当前实际品质概率。

5. 下载与启动
最新完整包：冒牌炼金术士_Demo_Win64_字体90_72.zip
https://github.com/QIQIdeqi/MPLJSS/blob/main/03_Build/HD2D_PC_UI/%E5%86%92%E7%89%8C%E7%82%BC%E9%87%91%E6%9C%AF%E5%A3%AB_Demo_Win64_%E5%AD%97%E4%BD%9390_72.zip

通过文件页下载完整 ZIP，全部解压后双击“启动Demo.cmd”，无需安装UE。启动脚本与Windows文件夹需要放在一起。使用Git获取项目的同学，请先执行 git lfs pull。

新增UE关卡/技能编辑工具（需要完整UE工程）：格子素材面板、种子随机、锁格微调、图片与材质替换、可编辑碰撞；技能、配方、连锁、品质用四张DataTable编辑。工程内双击“打开关卡与技能编辑器.cmd”，按使用说明操作。
