UE关卡与技能编辑器

适用当前UE5.8.4工程 02_Prototype/AlchemyHD2D。这是引擎编辑模式工具；Windows试玩包用于运行游戏，编辑工作使用完整UE工程。当前默认地图、技能表已放入工程，无需先手工搭建。

第一次打开

  1. 双击工程目录中的 打开关卡与技能编辑器.cmd。它先编译编辑器模块，再打开Research地图并选中工具Actor。
  2. 若自动查找不到引擎，在PowerShell执行 Tools/OpenDesigner.ps1 -EngineRoot '你的UE5.8目录'，或设置 UE_ENGINE_ROOT。支持本机D盘、已知F盘安装与UE5.8注册路径；需要UE和C++编译环境。
  3. 世界大纲搜索 Alchemy_Level_Designer，选中它，在右侧Details使用“关卡工具”“技能工具”按钮。
  4. 编辑前停止Play；改完保存，再按Play试玩。工具不会在修改参数时擅自随机重做关卡。

关卡：生成后直接微调

默认24列×18行、每格600cm、Seed=77，共432个地面格；另有8个独立可编辑碰撞块，保留原Layout A的碰撞布局。

  1. 读取全部图片素材：把 /Game/Art 中所有贴图加入Palette，保留已有条目的设置。新图片先拖入该内容目录，再点击此按钮。
  2. 展开Palette，按Name找到素材。RandomWeight>0 才参与随机；默认Grass/Dirt/Stone权重75/20/5，其他角色、道具、建筑等图片为0，可手工使用。
  3. 点击 一键随机生成：每次自动换一个与上次不同的新Seed，保留已锁格的位置与外观，重建其他格子。喜欢某次结果时记下Seed；想复现时填回该数值，点击 按当前Seed重新生成（复现布局）。相同Seed、行列、尺寸、笔刷权重及锁格状态会复现相同布局。
  4. 在视口选中一个格子，或在世界大纲的 Alchemy/EditableCells 中按坐标查找。可直接移动、旋转、缩放；勾选 Lock Random 后，再次随机不会覆盖它。
  5. 单格外观改 Texture、Material Override、Ground、Visual Size。自定义材质优先；想直接换图片时清空Material Override。Ground勾选为水平地格，取消为竖直图片摆件。工具提供默认透明图片材质。
  6. 也可在工具Actor的“微调”中选BrushIndex，拖动PaintCursor三维手柄，再点 在光标格子应用笔刷并锁定。
  7. 碰撞块位于 Alchemy/EditableCollision。勾选 Blocks Movement 并设置 Collision Half Size；实际运行会读取这些格子的碰撞。当前使用水平轴对齐包围盒，旋转后取外包矩形，不是贴图像素碰撞。
  8. Play Half Size 控制以世界原点为中心的可通行半尺寸，默认7060×5330cm；它与美术格子的数量分开设置。默认出生点仍为(0,0)，修改布局时保留出生空间和可绕行路线。
  9. 点击 保存当前关卡和技能表 或Ctrl+S，然后Play。编辑器的预览灯只用于编辑观察，试玩使用游戏自己的灯光。

可以多选同类格子，批量改材质或锁定。随机生成保留手工锁格；八块默认碰撞块不属于随机地面格，不会被随机重建。图片摆件用于场景外观，怪物生成仍使用现有波次逻辑。

技能：原生DataTable编辑器

点击工具Actor的四个“打开”按钮，或在内容浏览器打开 /Game/Design 下的数据表。表格可检索行，选中一行后在行编辑器修改，支持UE原生CSV导入/导出。

表 修改内容 行编号
DT_Skills 技能名称、伤害、冷却、搜索距离、半径、减速、施法类型、目标数、弹丸速度、Niagara、颜色、效果倍率与保留时间 0–24为既有技能，可从25起连续追加
DT_Recipes 普通组合的三档技能结果；精英配方的六类材料数量和结果技能 0–6普通，7起精英
DT_Chains 配对技能A/B、冷却、搜索距离、伤害、范围/目标数、减速和Niagara 0–9为既有连锁，可从10起连续追加
DT_Quality 低/中/高权重，候选过滤后归一化显示 0代表投入3个，依次至7代表投入10个

先改一个技能

  1. 打开DT_Skills，选行 1（炎弹）。Damage是基础伤害，CD单位秒，Range/Radius单位cm；100cm对应原案1设计单位。
  2. Cast选择弹丸、直接命中、自身范围、目标范围或跳跃命中；Targets用于多目标，Slow为减速秒数，Factor为剩余移动速度倍率（0.65表示保留65%速度）。
  3. Hit Effect选命中特效，Trail Effect选弹丸尾迹，Cast Effect用于范围施放。内置系统支持Color配色；自制Niagara系统可在自身资产中设置材质和颜色。
  4. Effect Scale是本行Niagara整体倍率，设0关闭Niagara。Cast Life/Hit Life控制组件保留秒数，避免把长特效过早清掉。留空效果引用会使用原型默认效果。
  5. 点击 校验技能与配方，通过后保存；重新Play观察实际伤害、施法和效果。数值表在Play开始时读取，不进行战斗中热更新。

新增与配方连接

  1. DT_Skills添加连续的新行，例如25，填写名称、施法方式、数值、特效。
  2. 在DT_Recipes选择一个普通组合，把LowSkill/MidSkill/HighSkill中的一项改为25，即可在对应品质池获得新技能。三个结果需不同。
  3. 普通组合Mask：火粉=1、露水=2、魔法碎片=4，混合相加；前七行须覆盖1–7，不能重复。投入比例不改变材料种类组合。
  4. 精英行开启Elite，Costs依次为火粉、露水、魔法碎片、兽核、虚空晶、根须心，六项数量总和3–10，至少包含一种精英材料；LowSkill是固定结果。
  5. DT_Chains新增连续行，A/B填两个技能ID。装备齐全后自动按完整冷却触发；卸装暂停并保留剩余。Targets=0为目标位置范围，>0为跳跃命中数。
  6. 校验、保存，再Play。已有技能/配方/连锁编号关联存档，不要重排既有编号；追加行号需连续。教学三料组合继续保留范围技能，材料与同品质强度仍需策划试玩评估。

原有CPP配置只用于首次生成默认表和历史基线检查；已经保存的数据表为运行时配置。再次运行CreateDesignTools.py只补缺失的表，不覆盖已改好的表和关卡。
