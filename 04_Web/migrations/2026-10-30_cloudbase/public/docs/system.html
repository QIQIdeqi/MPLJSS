一、系统目标与整体循环

沿用已确认方向：材料组合探索为主、成长爽感为辅，保留生存挑战。系统应让玩家不断回答：缺什么能力、去哪里回收材料、现在炼还是攒料、装备哪组技能、何时挑战Boss。

局内循环：移动聚怪与自动战斗 → 掉落及回收材料/金币/经验 → 选择材料种类与投料量 → 炼金结果与技能安排 → 连锁/属性成长 → 继续收集或挑战Boss。局外循环：胜负结算金币 → 永久强化与查看发现记录 → 下一局。

最新关卡规则来自1.4关卡：https://github.com/QIQIdeqi/MPLJSS/blob/main/00_Doc/%E5%8D%8F%E4%BD%9C%E7%AD%96%E5%88%92/1.4%E5%85%B3%E5%8D%A1.md 。5:00开放随机避障可达传送阵并提供UI箭头；阵内按交互键确认进入独立Boss关卡；生命原样继承、不额外恢复。原图5分钟后主要加快怪物数量与刷新频率。返回规则、其他状态携带、压力数值仍待确认；旧5:10原地强制Boss流程不作为新设计。

四、优先问题1：少量多炼与攒料的价值

当前基础品质权重按投入3至10依次为：70/20/10、65/22/13、60/25/15、50/30/20、45/32/23、40/33/27、35/34/31、30/35/35（低/中/高，%）。候选满级或无法存放时先排除，再归一化；全部不可接收则不扣料。

受控推演：不计刷新、容量过滤、技能满级、战斗回收，且组合始终可炼。3料高品质单位材料期望=(1−5%)×10%÷3≈0.03167；10料=(1−1%)×35%÷10≈0.03465。30材料对应10次小投或3次大投，至少一次核弹概率分别为1−0.95^10≈40.13%与1−0.99^3≈2.97%。这是固定条件计算，不是实战收益或平衡结论。

源码核弹结算：只击杀普通怪，精英与Boss不受影响；普通击杀计数、经验、金币与材料掉落照常。它不授予本次普通技能，也不走普通技能品质抽取；教学与精英固定配方不触发。结果刷新、材料回收与怪群密度会进一步改变策略价值。

已确认方向与首轮测试表（系统第1—15问，2026-10-30）：少量探索和应急，高投入追求品质与构筑，各有用途；高投入仍可出低品质，无额外品质保底；3–10料完整平滑表为普通品质首轮起测基线。核弹作为额外奖励，触发后仍抽取本次技能；本次中、高品质基础概率各相对降低50%（乘0.5），差额全部转给低品质，统一适用于3–10料，先作为起测值。即中'=中×0.5，高'=高×0.5，低'=低+中×0.5+高×0.5；3料为85%/10%/5%，10料为60%/17.5%/22.5%（低/中/高）。先调整基础权重，再过滤不能接收的候选并归一化；最终显示的实际中高概率不保证恰好减半。降权仅作用核弹触发后的本次技能，下一次炼金恢复普通表；不改变后续核弹概率。核弹后的技能结果允许按既有次数及解锁前提刷新，刷新继续使用本次降权后的基础权重，排除当前结果及不可接收候选后归一化；沿用一次降权，不因刷新再乘0.5，也不恢复普通权重。若无其他可接收结果则不能刷新；第11问已确认刷新不重新判定核弹。第12问已确认核弹触发概率保留3料5%、10料1%，中间线性下降，作为首轮起测值；p(n)=5−4×(n−3)/7（%，3≤n≤10），计算保留插值精度，显示两位小数。第13问已确认核弹直接击杀普通怪后，经验、金币和材料均按正常击杀规则结算，作为起测规则；沿用原有概率和数量，不额外削减、不额外加倍，也不自动拾取。第14问已确认核弹清除当前战斗地图内全部已生成且存活的普通怪，包括屏幕外普通怪，精英和Boss不受影响，先作为起测规则；不清未生成的怪，不波及其他关卡。第15问已确认核弹清场后不额外暂停普通怪生成，沿用当前阶段普通波次及最低数量补怪规则；不新增3秒或5秒回收保护窗口，也不重置刷怪计时。结果页等系统界面仍按原规则暂停战斗，关闭后恢复正常模拟。旧源码及旧收益推演仅作对照，本轮只同步策划，未修改UE参数或实现；首次教学三料70%/20%/10%保持现有规则。

水 近身应急脱困（第16问已确认） 已确认：敌人贴近时及时减速，帮助玩家拉开距离；品质递进和具体参数待细化 近身压迫下的脱困率与空窗

火魔 集中爆破 突出远处密集群体的爆发收益 聚怪后的收益与空放代价

同组品质递进应在主要用途上成立，不要求伤害/频率/范围全升。当前默认火组灰烬弹18/1.5=12、炎弹26/1.8≈14.44、石刺38/2=19名义伤害/秒，顺序成立；射程900/900/800cm，仍须测接敌、溢伤和命中。火水组20/2.5=8、30/4.4≈6.82、44/5=8.8，说明中品质以更大范围换频率；不能仅凭品质标签承诺对单体也更强。

建议按三种固定遭遇比较：单精英、分散小群、聚拢密群；并加贴身包围观察控制。记录首次生效时间、有效伤害、击杀、受伤与控制覆盖。若七组区分仍不足，先调施法中心、频率和覆盖，再考虑新效果，避免先扩技能数量。

六、优先问题3：连锁如何支持构筑

已确认基线：十组连锁替换旧两组；所需技能装备齐全后启动完整冷却。卸下任一技能暂停并保留剩余时间，重新装齐继续；已经开始的效果正常结束。局内界面暂停；新连锁实际触发后解锁发现。

完善提案（待确认）：每组连锁写明要解决的战斗问题、两技能来源与品质、装备位成本、冷却收益和何时值得追求。结果页用已发现连锁提示当前缺哪个技能；未发现只给方向线索，不直接公布全部答案。装备界面显示已激活及差一项的已发现连锁，避免让玩家靠反复翻图鉴记忆。

获取路径风险：低+中、高+中、低+高等配对需要不同投料策略；满级过滤与排除当前结果的刷新会改变凑齐成本。十组应按同一材料预算比较成型概率及成型后收益；不能只比较连锁一次伤害。核弹不出技能的机会成本也应计算。

七、优先问题4：商人与永久成长的衔接

商人现价：普通买8/8/10、卖2；精英买24/30/28、卖8；刷新5/10/15/20/25封顶，每位重置。直接买回再卖均亏损；但掉落出售→买缺料会牺牲结算银行金币。建议界面清楚显示花的是本局金币、会减少本局结算余额；仍为提案。

局外源码前置需要属性节点5级全满。生命五级总价60+90+130+180+240=700，伤害80+120+170+230+300=900，再买刷新180，累计1780银行金币才能解锁刷新（从零、无其他变化）。本轮没有每局净收入数据，因此无法判断需要几局或是否过慢。应先核对刷新入口确实受解锁控制，再评估要不要前移功能节点。

优先保留现有线性天赋框架；先用新档与已有强化档各测代表局，记录第一项功能解锁前的重复游玩成本。是否调整前置或价格为待确认提案，不自动改成分支树，不新增货币。

八、主动Boss挑战与跨系统交接

已确认生命不回血；其余仍待确认。建议候选：技能、等级、装备/储备、本局金币、材料、局内属性与经验保持同一局状态；技能/连锁剩余冷却继承，不借切图重置。传送过程不推进战斗模拟或承受过渡伤害，落地后正常战斗；这是衔接提案，尚非已确认规则。

5分钟后更多怪也会带来更多经验与材料，可能让强构筑越刷越强，弱构筑却进不去Boss。需同时看单位时间资源净收入、受伤、退路可达和传送等待时间，不能只提高刷怪量。商人是否继续、精英是否继续、旧清场奖励是否取消、地面掉落是否带走均待确认；不擅自增加传送费、强制倒计时或精英门槛。

1.4当前未决问题是能否从Boss关卡返回；此页保留该问题归属，不替另一轮讨论作决定。1.5负责构筑与经济、跨系统状态合同；1.4负责时间、场地和传送入口。涉及共同规则时链接并同步，避免两页各有一套。
