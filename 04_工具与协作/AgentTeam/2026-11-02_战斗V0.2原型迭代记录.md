# 战斗 V0.2 首版原型迭代记录

日期：2026-11-02（北京时间）。基线：`5f113ab`，工作区开始时干净。现行输入为[Demo 战斗策划案 V0.2](../../00_Doc/冒牌炼金术士_Demo战斗策划案.md)及 Git 1.4／1.5／1.6；用户本轮要求按最新战斗案迭代一版游戏。本轮没有提交、推送或重打 Windows 包。

## 当前工作区实现

- 保留自动基础普攻。旧七组合即时炼金从正常首局入口退出；局外关卡页可选“随身试剂”或“驻留坩埚”，模式写入既有存档，并在开局带入本局。
- Q 炼丹页分开选择新制、同方强化、换主材、换辅材。主材选火粉／露水／魔法碎片的本体候选池，辅材独立倾向强击／延伸／迅捷词条。数量改变各自候选权重；没有合法候选、目标、库存或容量时不扣料。
- 起炼一次性扣料并记录目标、操作、模式和材料；关闭配置页后随战斗时间推进。随身试剂可移动，驻留坩埚离起炼点过远即停进度；任何系统界面打开时沿用整体暂停。完成事件只生成一份待处理结果。
- 结果页展示旧新本体、主材、词条、成长和品质。接受前旧技能仍生效；拒绝保留旧丹但不返料。换主材保留成长、词条及剩余攻击冷却，换辅材只改变词条；新制与强化分别加入技能与增加成长。
- 虚空晶作为**首测暂定**特殊材料：额外消耗一份，把新制／换辅材结果确定转换到指定辅材词条。普通辅材仍只提高倾向。兽核、根须心的 V0.2 功能未定，正常商店暂不出售这两种材料，已有库存仍可出售。
- 普通怪掉落改成少量碎片并自动归集；原基础普攻在无材料、炼制中、Boss 无补给时继续可用。首次进入 V0.2 的存档获三种普通材料各一份，并通过 Q 页提示主辅材；旧固定三料教学仅供原隔离回归使用。
- 旧装备配对连锁仅在旧检查／捕获路径运行，避免直接成为正常 V0.2 炼丹的前置或额外收益。旧“技能刷新”永久强化在正常 V0.2 流程暂禁新购，防止花币买到无效能力；旧存档的已购标记保留但当前不生效。
- 图鉴中的旧组合与旧配方仍可查阅，但正常 V0.2 流程不再一键填入旧炼金锅；点击时引导玩家改选主材和辅材。旧 UI 隔离专项保留原填入动作。

主要入口：[运行状态与制丹](../../02_Prototype/AlchemyHD2D/Source/AlchemyHD2D/AlchemyBrew.inl)、[战斗接线](../../02_Prototype/AlchemyHD2D/Source/AlchemyHD2D/AlchemyWorld.cpp)、[界面](../../02_Prototype/AlchemyHD2D/Source/AlchemyHD2D/AlchemyHUD.inl)、[原生专项](../../02_Prototype/AlchemyHD2D/Source/AlchemyHD2D/AlchemyBrewChecks.inl)。试验数值与仍待验证的平衡边界已追加至[1.6数值](../../00_Doc/协作策划/1.6数值.md)。现行战斗案原文件名与入口不一致的问题已修复，`00_Doc` 内四处链接目标已核对。
