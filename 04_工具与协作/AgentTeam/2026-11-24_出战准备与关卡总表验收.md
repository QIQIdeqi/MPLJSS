# 出战准备与关卡总表验收

日期：2026-11-24（北京时间）。本轮为 Godot 工程实现及验证记录；提交范围以 Git 历史为准，Windows 包未重新生成。

## 已落地

- 原生可编辑出战准备面板：目的地列表、关卡预览、七种炼金能力、真实库存、底部汇总和一次确认。切关保留能力；取消不消耗；打开时锁角色移动，并与工房互斥。外框九宫，内纹独立平铺，七张能力卡完整可见。
- 统一关卡总表：目前只有村庄、第一普通关与其 Boss。稳定 ID 对应独立完整场景、随机配置、怪物表、出生点及 Boss 关联。没有将示意图的 02—06 占位关做成正式内容。
- 编辑器底部新增「关卡总表」；选关同步「Alchemy 关卡」的两层随机预览和「怪物波次」。新建生成独立场景、地块物件配置和怪物表；支持校验、保存、打开场景。宽高仍用 px，红线实时更新。
- 场景与布局完整初始化后才提交入场库存事务；加载或保存失败停留准备页，库存回滚，忙碌时拦截重复确认。工房产出真正保存；旧存档兼容、备份恢复、较新格式拒绝覆盖。
- 普通关 300 秒后仍自愿挑战 Boss。切入独立 Boss 场景时续接同一局生命、经验、技能/升级/冷却、能力、金币、材料账本与旧炼金背包，延续镜头/TOD/天气。布局种子独立派生；不重复扣入场库存。
- 胜负、暂停返回开始界面统一结算金币和材料，失败可重试，重复调用不会重复入账。继续游戏仍返村。
