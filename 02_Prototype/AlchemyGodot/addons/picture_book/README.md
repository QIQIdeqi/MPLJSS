# 绘本编辑器 · 图文时间轴

使用 Godot 4.7.2 Standard 打开本工程 `project.godot`，等待资源导入完成，在顶部主屏标签选择 **绘本**。插件已在项目启用；若标签没有出现，到“项目 → 项目设置 → 插件”启用“绘本编辑器”。这是项目内的 Godot 工具，不导入或导出 PPT。

也可打开 `res://addons/picture_book/editor.tscn` 按 **F6（运行当前场景）**，获得独立工具窗口；不要用 F5 打开工具，F5 仍走原游戏入口。

## 制作一本绘本

1. 点“新建”，或“示例”打开独立的四页样例。示例不含正式剧情。
2. 左侧“+页”“复制”“删除”管理页面；拖动缩略图到另一页改变顺序，也可用“上移/下移”。“批量加入项目内图片”按选择顺序新增页面。
3. 每页最多一张图片、一个文本框；右侧可将各层分别设为“保留前页”“换成新内容”或“清空”。保留只继承内容，当前页位置、尺寸、字色和字号仍由当前页控制；首屏保留等同空内容。
4. 在画布单击选择图/文，拖动移动，拖右下角方块缩放；双击文字直接编辑，失焦或 Ctrl+Enter 完成，Esc 取消当前文字编辑。右栏可精确改坐标、尺寸和字体。“在画布写字”也能唤起文本输入框。
5. 下方时间轴共用秒数标尺：拖动图片或文字条移动起点，拖两端改变起点/终点；拖标尺定位预览。图文可以留空隙或重叠。右栏支持精确到 0.01 秒的延迟/时长，以及“一起淡变”“图先文后”“文先图后”“直接切换”快捷配置。时间轴“▶ 本页”播放到淡出结束，“返回布局”恢复画布拖拽。
6. 默认手动翻页；勾选单页自动翻页后，阅读停留从该页实际图文入场完成后开始，随后整页淡出。右栏分别设置停留和淡出时间。纯图、纯文及继承页按解析后的内容计时。
7. “重播入场”从透明状态重播当前页并停在阅读；“从此页放映”从当前页连续播放。点击画面、Enter/空格每次只做一步：入场（包括等待）→补完本页；阅读→开始淡出；淡出→直接进入下一页入场。末页淡出完成只发一次结束事件。纯放映画面不显示按钮、页码或提示；Esc 关闭工具预览。每页是独立的完整入场/淡出，继承图片仍使用本页时序。
8. “另存为”写入项目内 `.tres`，之后“打开”继续编辑。建议将自有绘本存放在 `res://picture_books/`；编辑示例时先另存。图片也必须先放入项目并完成导入。

撤销/重做覆盖页操作和内容布局；新建/打开覆盖未保存编辑前会二次确认。独立窗口正常关闭也有未保存确认，进程被强制结束则不能保护未保存内容。

## 运行时与范围

资源模型和共享播放器在 `res://scripts/picture_book/`，不在导出排除的 addons 下。编辑器放映与独立演示 `res://picture_books/demo/play.tscn` 使用同一 `player.gd`。已有导出配置为 `all_resources`，排除 addons/tests；本次未做 Windows 导出验证。

共享播放器已用于 New Game 的 P00 开场；本次只调整该展示层，不扩展战斗、关卡或剧情触发。没有多图层、多文本框、富文本、音频轨、任意关键帧、PPTX 导入；图片导入按钮引用项目内素材，不自动复制外部文件。

## 全屏表现与旧绘本

“图片铺满”采用保持比例的覆盖裁切；右栏可选完整包含。旧绘本自定义图片矩形保留。文字保持 1280×720 设计坐标并等比适配，过长文字会缩字号以免截断；右栏可设置衬底和字色。P00 使用透明衬底、低不透明阴影及整句排版，只在句号后按内容分行。拖时间指针时画布只预览，不误触布局修改。

## P00 逐页节奏

P00 正常播放及评审版闲置时只有图片和叙事文字，不显示页码或提示；鼠标活动短暂唤起左下快进按钮，指针停在可见按钮热区时保持显示，离开或最后有效鼠标活动后满 3.0 秒才开始淡隐。Esc 暂停会压暗全屏并提供恢复播放、重新播放、跳过剧情三个横排按钮；快进与暂停跳过共用确认窗。取消回到调用来源，确认才单次保存完成。R/S 不再执行任何动作；保存失败时显示错误与重试说明。八页原画和原文保持原顺序，阅读停留不含入场与淡出，全部自动播放约 78.9 秒。

## 隔离档真人试玩（Linux）

下面入口加载真实主菜单，点击“开始游戏”后仅在内存中把 P00 副本改成手动翻页，并停在第一页已显示状态。原资源自动节奏不变。Esc 打开暂停层，可恢复、从第一页重播、或确认跳过；R/S 无快捷功能。跳过仍走实际游戏保存与村庄入口，数据只写本次临时目录。不要带正式数据目录运行。

## 纸面转场

绘本资源可选 `background_texture`，由共享播放器作为全窗口、不参与图文 alpha 的底层显示。P00 使用 `picture_books/prologue/images/blank-paper.png`：参考第一页左上空白纸面生成的无笔画暖色纤维纹理，原八幅插画未修改。入场和淡出只改变图片、文字的不透明度，透明度归零时露出纸面；自动或点击跳过均直接进入下一阶段，不增加停顿。未配置纹理的旧绘本继续用原 `background_color`。

P00 及编辑器放映期间临时扩展窗口画布以覆盖非 16:9 窗口，结束时恢复原缩放设置；图文安全区仍等比缩放。原生检查：`tests/picture_book_paper_smoke.gd`，其 `-- --paper-capture` 选项在图形环境在隔离的 `user://` 数据目录输出三种实际窗口比例的空白转场帧。

## UI 动效与输入屏障

快进使用 28×22 的无底双箭头图标，普通、悬停、按下和焦点状态均无背景框；鼠标点击与悬停共用图标外接矩形，随显隐位移移动。图标用 0.22 秒的连续淡入/淡出与最多 4 像素的轻移，无缩放弹跳。悬停保留；离开后重新计 3 秒，键盘聚焦或零位移鼠标事件不延长时间。淡隐中移动从当前透明度反向，完全隐藏时不接收画面点击。

暂停蒙版、标记/按钮、确认层采用约 0.18 秒的分层透明度过渡及不超过 4 像素位移。暂停来源的确认保留淡淡的暂停层但禁用其按钮，播放来源没有此层。暂停立即冻结图文，恢复/重播/确认的退场完成后才释放输入或执行一次操作；快速反向 Esc 不重建动画、不重复连接信号，取消与退场点击不会穿透。
