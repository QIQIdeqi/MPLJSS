# P00｜序章：格蕾丝和我

八幅原画来自项目 `00_Doc/美术/序章绘本/storyboard/scene-01.png` 至 `scene-08.png`，逐字旁白以同目录 README 及第一幕 P00 为准。图片按原文件精确复制，保持 1672×941 与原有比例；文案仅加入阅读换行，字词、标点与顺序不改。来源和指纹见 `source_manifest.json`。

## 打开与调整

- 绘本工作台点“打开”，选择 `res://picture_books/prologue/prologue.tres`。左侧选择八页，右侧调整图文布局、转场及停留时间；右上角“从此页放映”预览。
- 剧情工作台点“打开”，选择 `res://stories/prologue.tres`。唯一节点 `story_p00_prologue`（P00）在战前绘本槽关联本书，点“编辑 / 新建”可进入同一本绘本；修改绘本后保存，返回剧情。
- 序章没有已完成关卡条件、战后绘本或到达事件；新游戏读取此节点的战前绘本槽并播放 P00，完成后进入现有村庄。此接入不自动执行其他剧情节点、事件或第一幕 AVG。

## 演出与操作

1280×720 设计画布，纸底与褐墨正文，左侧文字、右侧完整插画，等比适配窗口。图片先入场，文字随后淡入；换页时新旧图、文分别交叉淡变。前六页较轻快，第七、八页转场稍慢。

每页自动翻页，完整入场后分别停留 6／7／7／8／7／7／8／7 秒；阅读停留合计 57 秒，含转场总长约 65.15 秒。空格、回车、画面单击或“确认 / 下一页”可手动继续；淡变中第一次确认只补完当前页，再次才翻页。“上一页”可回看；Esc 退出预览。

纸底和阴影是绘本级资源属性：`background_color` 与 `text_shadow_color`，可在 Inspector 调整。旧绘本仍使用原来的深色背景和文字阴影。

游戏中只新增 `[story] prologue_completed` 存档标记：新档为 false，播完或主动跳过后保存 true；返回菜单不记完成，未完档继续会从首图重播，旧档无字段默认不重播。新游戏先保留 `.before_new_game` 旧档副本，已有同名备份时递增使用 `.2`、`.3` 后缀，不覆盖旧副本；写盘失败会留在当前界面重试。Esc 返回菜单会保留当前存档路径。

没有插入教学、改动战斗或关卡解锁，也未新增剧情和配音。V01 药屋搜查、V02 村民对话及整幕触发仍未接入。
