# 冒牌炼金术士 · Godot 试玩

用 Godot 4.7.2 Standard 导入本目录的 `project.godot`，按 F5 从开始界面运行。

- 点击「开始游戏」先播放八页 P00 序章，播完或「跳过并进入村庄」后进入现有村庄。支持自动翻页、空格／回车／单击确认、上一页，Esc 返回开始界面；未看完返回后「继续游戏」会从第一页重播。
- 已有进度用「继续」；旧档缺少序章标记时直接进入村庄。开始新游戏仍会重置旧材料、能力和配方记录；重置前将原文件独立备份为 `progress.cfg.before_new_game`；若已存在则使用 `.2`、`.3` 等后缀，既有备份不会被再次开始或后续序章保存覆盖。绘本与节点入口见[序章说明](picture_books/prologue/README.md)。
- 村庄 WASD 移动，Q 打开工房，从五种材料中选择不同种类尝试隐藏配方。成功后扣除材料并产出能力，失败不扣材料。此工房方案在远端提交中标为讨论版，阶段解锁与保存缺口见下方策划核对。
- 靠近右侧雾门按 F 打开出战准备，选择目的地和本局能力。取消不扣库存，场景与布局准备成功并保存后才消耗一份；基础炼金免费。镜头在村庄、外围和 Boss 跟随玩家并限制在地图内。
- 外围用空格闪避，魔法弹独立自动攻击。击杀后拾取金币、经验球与地面素材，升级时三选一，最多装备六个 V2 技能。局内 Q 炼金入口已关闭。
- 升级池包含二十个基础技能，卡面标注星火、潮汐、晶核或以太属性和战斗用途。技能背包及技能槽悬浮提示也显示属性。基础技能最高五级，魔法弹独立于技能槽。当前固定组合表为空。
- 局内满 5 分钟开放 Boss 传送阵。走到传送阵按 F 后可以挑战或继续探索，教学和炼金进度不限制进入。进场保留生命与已拾取的本局资源。腐化之源的橙色线提示冲锋，蓝色线提示扇形弹。挑战结算后按 F 回村。

当前整合基线为远端 main `37a2b0b1`（2026-11-24）。资源保存、主动退出结算、Boss 奖励和部分能力机制的现有缺口见 [新旧策划差异核对](../../00_Doc/协作策划/2026-11-24_新旧策划差异核对.md)。11 月 11 日 Windows 包沿用其发布时的流程。

新增关卡、关联 Boss、快速打开场景、跳转原关卡编辑器，以及次数和密度的填写示例，见[工具使用文档](Docs/关卡总表与出战准备.md)。

## 关卡编辑器

打开编辑器底部「Alchemy 关卡」，选择「普通战斗」或「Boss 场地」。点「编辑配置」，在 Inspector 的 Palette 里调每种素材的 Count Range 和 Density Range。X 为最小值，Y 为最大值，−1 表示无此限制。点「按 Seed 生成」复现布局，或单独重摇地面与物件。左键涂格并锁定，右键解锁。点「保存配置」写入对应的 `levels/*.tres`。

「区域宽度」和「区域高度」控制实际可走范围，输入时红框会实时更新，普通场和 Boss 场可分别保存。战斗中的淡红流光线标记同一范围。

正式开局读取配置并生成新种子。预览锁定和重摇偏移只影响编辑器。普通场保留传送阵通道，Boss 场保留中心战斗空间。

## 第一关怪物配置

打开 Godot 编辑器底部的「怪物波次」，可编辑怪物名称、四向图集和各波权重，以及每波开始秒数、出怪间隔、同屏上限和开局生成数量。保存后开一局读取新配置。也可在 Inspector 打开 `levels/first_level_enemies.tres` 添加资源行或波次列。

权重 0 表示该波不生成该怪。某只怪的出现比率等于它的权重除以该波总权重。图集使用 4×4 格，四行依次朝下、右、上、左，四列依次为待机、移动 A、移动 B、攻击。

默认在 0 秒开放水蓝史莱姆和骨棒骷髅，30 秒加入灰狼，60 秒加入蝙蝠，95 秒加入黑斑蛛，135 秒加入赤斑菇，170 秒加入流水灵。波次切换后，场上已有怪物继续活动。

七种小怪与腐化之源使用独立的逐帧受击和死亡图集，运行资源在 `art/enemies/reactions/`。

## 迁移边界

村庄、局内和 Boss 使用独立的 3D 渲染视口与透视跟随镜头。局内和 Boss 共用 60 秒昼夜、天气和积雪进度，T 切换时段、Y 切换天气、V 循环切换中间机位、俯视和低机位。地面继续读取随机地块，角色碰撞、攻击判定和怪物波次沿用原有 2D 坐标，预警贴到 3D 地面显示。Niagara 对应 Godot 2D 粒子和 PixelFX 图集，金币扫光与经验球局部柔光使用 2D 材质。村庄碰撞可在 village.tscn 的 WalkBoundaries 节点编辑，正式怪物生态、虚空晶来源、局外养成和 Unreal 存档沿用各自工程的范围，Godot 仍使用独立存档。

整合验证使用 `v2_skill_data_smoke.gd`、`v2_projectile_fx_smoke.gd` 和 `battle_startup_smoke.gd`。启动检查传入 `-- --migration-test`，跳过正式进度读写。旧 `flow_smoke.gd` 的局内炼金和旧刷怪断言需要随新流程更新。实际鼠标手感和完整战斗节奏由真人试玩验收。

## HD-2D 技能特效

战斗基础技能由 [技能管理器](scripts/skills/skill_manager.gd) 触发。飞行物、刻印和持续区域的特效跟随对应的战斗状态。共用的渲染工具和原十个基础技能的造型在 [V2 特效脚本](scripts/v2_skill_fx.gd)，爆裂药瓶使用独立的[飞行](scripts/blast_flask_flight.gd)与[落地](scripts/blast_flask_impact.gd)脚本。

分裂炼金可用火粉和土髓在村庄工房炼出。攻击分支为青绿和紫色，各造成原伤害的 60%，分支共享一次冷却。扩展的控制、机动和回复技能按各自规则分区、分段或分次结算。

灵胶以半透明的琥珀色液球飞向目标，球内液纹回旋，命中时溅起一圈短促的液珠。飞行与命中分别取自 PixelFX 的 Water Orb 与 Splash，[素材来源与调色说明](art/vfx/v2/spirit_gel/NOTICE.md)随图集保留。

其余技能也按实际事件使用不同的 PixelFX 素材。爆裂药瓶落地后炸出火团与烟尘，脆化刻印在敌人身上留下琥珀裂纹，直接攻击破印时迸出晶屑，秘银亮珠按实际目标弹跳。引力石铺开紫色旋涡，蚀骨药剂留下冒泡的绿池，迷雾瓶散出低处冷雾。晶簇从逐段判定点冒出，黑曜飞刃命中时带出紫色刀弧，魂针以细青光呈现。参见[技能源素材表](art/vfx/v2/pixelfx/NOTICE.md)和[爆裂药瓶素材记录](art/vfx/v2/px_blast_flask/NOTICE.md)。

从当前目录运行下列检查可依次触发原十个基础技能的效果并保存战斗截图到 `.godot/v2_hd_fx_review`。使用 `--headless` 并去掉 `--capture` 时只检查触发、命中与清理。

```sh
godot --path . --fixed-fps 60 --script res://tests/v2_hd_skill_fx_review.gd -- --migration-test --capture
```

雷盐、火油、水银环、霜粉、风压瓶、轻羽药、风纹靴、回风粉、回春瓶和甘露剂通过同一升级流程获得。回风粉就绪时，首次闪避结束后可以再按一次空格转向闪避。回春瓶把回复池放在角色施放时的脚下。十项新增技能的 [Word 实装规格](../../00_Doc/协作策划/附件/冒牌炼金术士_技能扩展实装方案.docx) 和 [PixelFX 素材记录](art/vfx/skill_expansion/NOTICE.md) 包含分裂规则及特效来源。

以下检查在固定的战斗场景中触发新增技能的普通和分裂效果，可生成二十张截图至 `.godot/skill_expansion_fx_review`。

## 格雷弗德 HD-2D 村庄

F5 从封面进入村庄，或在 Godot 打开 `scenes/village.tscn` 按 F6。局外每 60 秒循环白天、黄昏、夜晚。天气每 12 秒切换，从晴天、下雨、干雷、雷雨和下雪中按轮洗牌。T 预览下一时段，Y 预览下一种天气，V 切换低机位与俯视，F 进入右侧雾门。树、灯笼和前景民居挡住莉莉塔时会淡出，走开后恢复。项目使用 Forward+ 渲染器，以启用 3D 景深和阴影。

- `scripts/hd_village.gd` 设置透视跟随镜头、焦距范围、灯光、独立贴片的放置和粒子。
- `scripts/hd_village_terrain.gd` 生成真实高低地形、河床、石岸和木桥。道路从村庄可走轮廓取形，莉莉塔的 3D 贴片高度按地面和桥面采样。
- `art/village_hd/generated` 包含本轮 ImageGen 拆出的炼金屋、谷仓、作坊、井、橡树、雾门。其他道具复用本项目 Greyford 素材。
- 参考 winkidney/hd-2d-godot 的独立 3D 场景、固定角度透视与角色景深思路，本项目自行实现。建筑用可受光的像素贴片，桥、石岸与地形用 Godot 原生网格。

村庄布置按用途分组。运行时可在远程场景树的 `VillageProps` 下查看炼金药圃、谷仓货场、作坊院、水井广场、灯笼休息点、雾门、南街民居、水车木桥和西岸菜圃。摆放数据在 `scripts/hd_village_districts.gd` 和 `scripts/hd_village_gardens.gd`。

## 五关无限地图（2026-11-24 工程版）

从开始界面进入村庄，在雾门按 F 打开出战准备，可选择格雷弗德外围、旧商路与受灾村庄、贵族庄园、朝圣路或王都下城。每关有独立普通场、Boss场、随机配置及怪物表。当前测试不设置剧情解锁门槛。

普通场按1280×720 px标准区块无限展开，数量/密度按每块计算；离开后卸载，回访保持布局和未拾掉落。300秒后自由挑战Boss；之后按45/30/15秒循环加压、高峰与喘息。保留原技能成长、出战库存、结算、透视镜头、TOD、天气、积雪和景深。

编辑入口：底栏“关卡总表”→地块与物件设置/怪物波次设置。普通场的“无限地图”开启，Boss保持有限；各关运行配置为levels/<id>_layout.tres，原normal.tres/boss.tres保留。详细步骤见[工具手册](Docs/关卡总表与出战准备.md)。

[五关美术需求表](../../outputs/five_regions_art_20261124/五关_场景美术需求案.xlsx)按每关一个工作表组织，共5页、40条需求和40张内嵌参考图，含像素尺寸、脚点、碰撞、数量密度与优先级。15张本轮生成测试素材在art/regions/，原图及提示词在项目ArtSource/Regions_20261124；新Boss正式外形仍为后续美术需求。
