# 冒牌炼金术士 · Godot 试玩

用 Godot 4.7.2 Standard 导入本目录的 `project.godot`，按 F5 从开始界面运行。

- 点「开始游戏」。WASD 移动，沿村庄空地往右上走，靠近右侧雾门按 F 进入外围。镜头在村庄、外围和 Boss 都会跟随玩家并限制在地图内。
- 外围首局发放火粉、露水、魔法碎片。空格闪避，技能自动释放，击杀后拾取金币和经验球。按 Q 打开炼金，可点击或拖放主材和辅材，确认两次后炼制，出炉后接受或放弃。
- 炼金使用 Unreal 当前 V0.2 规则，提供新制、同方强化、换主材、换辅材。随身炼制可边走边打，驻留模式离开坩埚起炼点后暂停。正式技能表迁入 25 个技能，使用 2D 命中与特效。
- 局内满 5 分钟开放 Boss 传送阵。按箭头走到传送阵，按 F 后可以挑战或继续探索，无需完成炼金。进场保留生命、材料、金币和丹药。腐化之源的橙色线提示冲锋，蓝色线提示扇形弹。挑战结算后按 F 回村。

## 关卡编辑器

打开编辑器底部「Alchemy 关卡」，选择「普通战斗」或「Boss 场地」。点「编辑配置」，在 Inspector 的 Palette 里调每种素材的 Count Range 和 Density Range。X 为最小值，Y 为最大值，−1 表示无此限制。点「按 Seed 生成」复现布局，或单独重摇地面与物件。左键涂格并锁定，右键解锁。点「保存配置」写入对应的 `levels/*.tres`。

正式开局读取配置并生成新种子。预览锁定和重摇偏移只影响编辑器。普通场保留传送阵通道，Boss 场保留中心战斗空间。

## 迁移边界

局内与 Boss 使用 Camera2D 跟随与构图。村庄使用独立的 3D 渲染视口，角色仍沿既有碰撞轮廓移动。地面用 2D 分块，未搬入 Unreal 的九邻域材质过渡。Niagara 对应 Godot 2D 粒子和 PixelFX 图集，金币扫光与经验球局部柔光使用 2D 材质。村庄碰撞可在 village.tscn 的 WalkBoundaries 节点编辑，正式怪物生态、虚空晶来源、局外养成和 Unreal 存档沿用各自工程的范围，Godot 仍使用独立存档。

主流程自动检查使用模拟输入和加速 Boss 开放时间，拖放调用实际槽位回调。实际鼠标手感和完整战斗节奏由真人试玩验收。在项目目录运行以下回归命令，测试使用隔离存档：

```sh
godot --headless -s tests/flow_smoke.gd -- --migration-test
```

直接预览村庄降雪可运行 `godot res://scenes/village.tscn -- --village-snow-preview`。工程附带关卡编辑器和 [Godot MCP Bridge](addons/godot_mcp/LICENSE)。

## 格雷弗德 HD-2D 村庄

F5 从封面进入村庄，或在 Godot 打开 `scenes/village.tscn` 按 F6。局外每 60 秒循环白天、黄昏、夜晚。天气每 12 秒切换，从晴天、下雨、干雷、雷雨和下雪中按轮洗牌。T 预览下一时段，Y 预览下一种天气，地面、屋顶和树冠随下雪逐渐积雪，停雪后逐渐融化。V 切换低机位与俯视，F 进入右侧雾门。树、灯笼和前景民居挡住莉莉塔时会淡出，走开后恢复。项目使用 Forward+ 渲染器，以启用 3D 景深和阴影。

- `scripts/hd_village.gd` 设置透视跟随镜头、焦距范围、灯光、独立贴片的放置和粒子。
- `scripts/hd_village_terrain.gd` 生成真实高低地形、河床、石岸和木桥。道路从村庄可走轮廓取形，莉莉塔的 3D 贴片高度按地面和桥面采样。
- `art/village_hd/generated` 包含本轮 ImageGen 拆出的炼金屋、谷仓、作坊、井、橡树、雾门。其他道具复用本项目 Greyford 素材。
- 参考 winkidney/hd-2d-godot 的独立 3D 场景、固定角度透视与角色景深思路，本项目自行实现。建筑用可受光的像素贴片，桥、石岸与地形用 Godot 原生网格。

村庄布置按用途分组。运行时可在远程场景树的 `VillageProps` 下查看炼金药圃、谷仓货场、作坊院、水井广场、灯笼休息点、雾门、南街民居、水车木桥和西岸菜圃。摆放数据在 `scripts/hd_village_districts.gd` 和 `scripts/hd_village_gardens.gd`。
