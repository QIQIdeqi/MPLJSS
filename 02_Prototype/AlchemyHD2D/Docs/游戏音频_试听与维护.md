# 游戏音频：试听与维护

从主菜单进入格雷弗德村庄，听完村庄音乐和环境底声后，从雾门进入第一关。走路、闪避、攻击和受击时，留意音效会不会盖住敌人的预警。击败怪物后，分别拾取金币、经验球和材料；金币偏清脆，经验球是上扬的蓝色魔法音，材料偏短促。进 Boss 场后会换曲，胜负结算会停掉战斗音乐并播放对应提示。

| 声音组 | 覆盖内容 |
| --- | --- |
| 音乐 | 主菜单、村庄、普通战斗、Boss，按场景切换 |
| 环境 | 村庄循环环境底声 |
| 战斗与交互 | 莉莉塔走路、闪避、攻击、受击、死亡；敌人走路、攻击预警、攻击、受击、死亡；Boss 锁向和出招；商人、传送阵与炼金 |
| 奖励与界面 | 金币、经验球、材料、碎片、宝箱、升级、失败提示和结算 |

UE 内容浏览器中，素材和四条分组在 `/Game/Art/Audio`；总音量继续由 `/Game/Audio` 下的主音量资产管理。替换素材时沿用现有资产名，保留相应分组和循环设置。原始 WAV 在 `ArtSource/GameAudio`，由 `Tools/GenerateGameAudio.py` 生成；`Tools/ImportGameAudio.py` 是 Unreal 编辑器导入脚本。

怪物近处更响，不同类型用不同音高；成群时同类提示会限频。普通怪物共享行为音色，Boss 的关键提示单独处理。本轮没有录制角色对白。
