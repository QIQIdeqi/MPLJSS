# 关卡 TOD 与渐变投影

在 `Greyford_Flow` 从村庄出发，普通随机关卡与 Boss 草甸使用同一轮昼夜变化。从 13:00 开始，每 20 秒有效战斗推进 1 小时，完整循环为 8 分钟。300 秒开放传送时为次日 04:00。Boss 继承进入时的时刻，准备阶段与战斗暂停界面保持当时光照。

环境从下午过渡到暖暮色，再进入冷色夜景。场景灯同步变化，画片、地表与场景特效通过镜头色调统一，界面保留原配色。此版时间和色调是首测参数。

## 投影表现

- 树、灌木、短篱与箱袋读取各自贴图的透明轮廓，沿背光方向铺出渐变长影。影根沿原图脚线对齐，整条脚线在太阳转动时保持原位。
- 18:00 的长影朝画面左下延伸。橡树保留树干到树冠的轮廓变化，箱袋和灌木按各自高度形成较短的影子。基础浓度为 0.56，近脚处轮廓清楚，越往尾部边缘越软，并逐渐融入地面纹理。
- 太阳高度较低时影子拉长，夜间降低浓度。光向接近画片横轴时，轮廓收窄并淡出。角色使用原接触影，战斗预警绘制在物件影子上方。
- 阴影属于画面表现。实际移动与寻路仍按物件的脚底阻挡计算。

## 在工程里预览

用 UE 打开 `Greyford_Flow` 后点击 Play，从村庄进入普通场。运行期间在世界大纲选择 `AlchemyWorld`，在 `TOD` 分类中调整起始时刻、循环时长、太阳高度和投影浓度。运行参数也可用于固定对照画面：

| 启动参数 | 效果 |
| --- | --- |
| `-MapSeed=77 -TODHour=18` | 固定地图种子及 18:00，适合美术对照 |
| `-TODStartHour=13 -TODCycleSeconds=480` | 设定随战斗推进的起点与循环时长 |
| `-TODShadowOpacity=0.25` | 调整投影浓度基准 |
| `-NoTOD` | 打开原光照对照 |

投影材质为 `/Game/Design/M_TODPropShadow`，可在材质编辑器调整渐隐曲线和 `TailSoftness`。运行时 `TOD` 分类中的 `SunAzimuthOffset` 同时调整光向和投影方向。新物件使用透明底贴图并校对编辑器中的 `FootFraction`，投影与画片共用该脚线。`Tools/CreateTODShadowMaterial.py` 用于生成材质。

## 实机检查

`Tools/TestGreyfordTOD.ps1` 启动原生 D3D12 检查，默认 60 FPS 时间步，可用 `-FPS 10` 检查低帧时间步。当前光影对照保存在 `Evidence/TOD_20261106/ArtMatch/`。同种子同机位对照下午、黄昏与夜色，黄昏另存关闭投影的画面，Boss 记录入场和地面预警。

2026-11-06 轮廓版通过 Editor 编译和 D3D12 的 11 项检查。检查覆盖原图透明通道、影根横轴固定、低角度拉长、角色移动时仅场景物件投影，以及普通场与 Boss 切换。
