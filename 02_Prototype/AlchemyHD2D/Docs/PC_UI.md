# PC UI 与 HUD 可读性调整

2026-10-27。使用已安装的 game-ui-ux，沿用 UE 原生 Canvas HUD；没有把浏览器 UI 技术栈引入游戏。

## 字体与阅读层级

旧代码以动态创建 UFont 的默认 LegacyFontSize=9 绘制，再乘 Size/16，导致标注字号与实际显示不一致，并放大低字号栅格。现在用带 FSlateFontInfo 的 FCanvasTextItem 按显示尺寸直接栅格化中文，文字加轻微阴影，保持明亮前景与深色底板。

以1280×720为布局参考，1080p按1.5倍布局缩放。现在按文字层级独立调节：小号（基础字号16–18）固定100%，中号（19–25）默认90%，大号（26及以上）默认72%。百分比相对代码中的基础字号，窗口缩放仍生效。此次替代此前100/103.5/117的全局档位，小号不再跟随全局变化。

游戏内按F7，或点击面板右上“F7 字体调试”。中号/大号各有-5%、-1%、+1%、+5%，范围50%–120%；即时预览并保存，失败则回退。面板提供小/中/大样例、精确百分比和恢复90/72按钮。告诉策划“中号XX%、大号YY%、窗口分辨率”即可复现。按F7或Esc关闭。点击区域不随文字缩小。

存档新增MediumTextScale/LargeTextScale，旧档缺字段采用90/72推荐值，保留旧UITextScale仅用于兼容反序列化；字体测量、段落行高和按钮居中共用分层字号计算。

## 布局与操作

- 生命、闪避、材料、计时与金币分组；六技能采用居中横排；生命条增厚。开启面板时隐藏战斗卡片，提供充分阅读空间。
- 面板扩大为1136×550参考单位，保留清晰返回按钮、字号入口和底部主要操作；长说明按字体度量换行。
- 炼金左炉右背包，使用同一矩形定义显示/点击/拖拽区域；字号变化不使命中区域错位。
- 图鉴按类别及内容分页：组合/技能每页5组，连锁每页4条，精英配方每页3条。放大字体后仍可查看全部记录。
- 键盘↑/↓选择、Enter激活，Esc继续使用原有返回规则；焦点边框可见。代码支持方向键与手柄方向键/A的对应输入，但只实测了PC键盘和鼠标。
- UI使用居中的16:9安全框，按窗口短边缩放；超宽屏两侧继续显示游戏，顶底背景覆盖整个屏幕。场景设施提示限制在安全框内。全局通知临时替换整个顶栏，避免只遮住一部分标题。
