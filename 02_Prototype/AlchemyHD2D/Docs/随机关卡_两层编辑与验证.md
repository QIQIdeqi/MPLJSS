# 随机关卡：两层编辑与正式流程

2026-11-04任务。玩法边界统一维护在[1.4关卡](../../../00_Doc/协作策划/1.4关卡.md)文首；本文记录实际工具操作、首轮工程参数和验证入口。

## 打开与编辑

- 普通局内：双击工程根目录 `打开关卡与技能编辑器.cmd`，选中 `Alchemy_Random_Normal`。
- Boss：双击 `打开Boss随机关卡编辑器.cmd`，选中 `Alchemy_Random_Boss`。
- 两个入口均打开正式 `Greyford_Flow`，显示目标子关卡并聚焦配置；Play仍从村庄正式流程开始，进入局内/Boss时读取同一配置。旧 Research 入口保留为 `Tools/OpenDesigner.ps1 -Scene Legacy`。

第一关的大纲只列出正式配置 `Alchemy_Random_Normal`。选中后在右侧展开「素材 → Palette」编辑。旧灰盒配置由工程保留作历史数据。

在 Details 的“两层随机”及原“关卡工具”区域操作：

1. `Palette` 中 `Ground=true` 为地面候选，`false` 为物件；两组各自按 `RandomWeight` 抽样，不再互相替换。地面连续铺设，物件可以为空。
2. `Seed` 是预览复现种子。`LayerMask` 的1/2/3分别表示地面/物件/两层；按当前Seed生成使用该范围。“只重摇地面”“只重摇物件”分别改变对应的种子偏移，不重抽另一层。
3. 选中生成的 `AlchemyTileCell`，微调位置、图像、材质、尺寸和碰撞，再勾 `Lock Random`。同一格可分别锁地面与物件；`PaintCell` 按所选笔刷的 Ground 分类操作对应层，空物件格也可绘入。
4. `ObjectDensity` 是每格尝试放物件的概率，不是保证数量；间距、保护区、合法占地筛选可能减少实际数量。`CollisionHalfSize` 控制脚底占地，不把树冠当作整个撞体。`FootFraction` 对应图内脚线。
5. `ProtectedPoints` 使用Designer局部坐标，保护从原点到各点的通路；`ProtectedPathHalfWidth` 是半宽。首轮保留出生/主通路，不建议直接删除这些保护点。
6. 自定义 `Material Override` 保留原样；标准Greyford草地/土/石路采用独立的 `GroundBlendMaterial` 做相邻格过渡。`CameraFacingObjects` 使画片面向60°相机并保持脚点；该模式首轮Yaw范围为0。
7. 保存当前关卡后试玩。正式开局使用新地图种子，按保存的配置重抽两层，编辑预览锁格只影响编辑器。相同种子和配置可复现正式布局。运行中的暂停、配置界面不会重新洗牌。

生成校验失败时保留旧布局与锁定内容并显示原因。正式流程普通场生成失败返回村庄，本局与首次教学仍待开始。Boss 生成失败保留本局实体、掉落和入口，可重试。

## 逐项调整出现次数与密度

在 Details 展开「素材 → Palette → 对应地面或物件」。两个范围的 X 是下限，Y 是上限。`-1` 表示该端不限。

| 字段 | 控制什么 | 示例 |
| --- | --- | --- |
| `CountRange` | 该素材在本层的总格数。编辑器重抽时含手工锁定格 | `(3, 8)` 允许 3 至 8 格，`(4, 4)` 固定 4 格，`(0, 0)` 关闭该素材 |
| `DensityRange` | 该素材占地图总格数的比例，填写 0 至 1 | `(.01, .02)` 表示 1% 至 2%，下限向上取整，上限向下取整 |

两个范围同时使用时取交集。例如普通场有 432 格，次数设 3 至 8 且密度设 1% 至 2%，实际允许 5 至 8 格。物件先尝试满足各项下限，再按全局 `ObjectDensity` 和素材权重补放。需要生成新实例的笔刷使用正权重。地面保持连续覆盖，生成器会调整部分未锁格以满足范围。保护区、间距、适用地面和锁格均参与校验，配置放不下时查看「操作结果」中的原因。

只想控制数量时，密度 X、Y 都填 `-1`。密度 `(0, 0)` 表示最多放 0 个，与正的数量下限冲突。重摇后编辑器会提示结果，成功时显示新摆和保留的物件数量，失败时显示原因。

修改后点击「按当前 Seed 重新生成」复核同种子结果，或使用分层重摇比较不同布局。两项都为 `(-1, -1)` 时沿用已有权重和种子布局。

2026-11-06 编辑器专项通过 94 项检查。测试覆盖范围交集、固定数量、零上限、锁格、失败保留和保存重开。未启用范围的普通场与 Boss 共六组种子，与原布局签名一致。

## 已接入的首轮配置

以下是可调工程起测值，不是新增的玩法冻结数值。

| 参数 | 普通局内 | Boss |
| --- | --- | --- |
| 地面格 | 24×18，600cm | 14×12，400cm |
| 布景半尺寸 | 7200×5400cm | 2800×2400cm |
| 有效战斗边界 | 普通场既有矩形范围 | 既有32×26m椭圆，独立于外围布景范围 |
| 地面相对权重 | Grass 78 / Dirt 20 / Stone 2 | 同左 |
| 物件尝试概率 | 0.24 | 0.30 |
| 物件间距余量 | 100cm | 100cm |
| 保护通路半宽 | 300cm | 300cm |
| 素材 | 同套Greyford草地、土、石路；Oak、Bush、Fence、Crates | 同套地面；低矮Bush可入内，Fence/Crates仅合法外围 |

Stone素材是鹅卵石铺路，不冒称自然碎石。当前复用独立512像素素材，未把含固定树、车、围栏的参考整图当作随机底图。新配置独立加入两个现有子关卡；旧Designer、旧手工格和固定参考场景资源保留。正式模式隐藏旧布景并仅从实际随机物件建立阻挡，旧对照模式用 `-ReferenceScene` 显式打开。

地图随机流独立于刷怪、碎片和炼药随机流。日志 `RANDOM_LAYERS_READY` 记录主种子、场地种子与两层数量；`-MapSeed=77` 可复现普通场主种子，Boss使用对应派生种子。预览Boss时填写日志中的场地种子。

## 实现与验证入口

- `AlchemyDesignTools.h/.cpp`：原编辑器扩展，两层生成、分层锁定/重抽/涂格、运行时共用逻辑、物件占地与脚点、可选九邻域纹理过渡。标准材质外的自定义材质不被混合覆盖。
- `RandomBattleScene.inl`、`GreyfordFlow.inl`：普通/Boss正式接线；真实阻挡进入原有Walkable/Move/FindPath，不保留原参考图的隐形树车碰撞。60°近景保留，Boss准备/近距双方取景使用实际HUD上下边界。
- `Tools/SetupRandomLayers.py`：首次配置；已有带tag的配置保留，不重建作者内容。`CreateRandomGroundMaterial.py` 只建立独立新材质，不改原Greyford材质。
- `Tools/TestRandomLayers.py`：独立测试地图的Seed、锁定、分层操作、失败保护、脚点/朝向、混合与自定义材质、保存重开；不改共享技能表。
- `Tools/TestRandomLayers.ps1`：正式Flow原生检查，默认1280×720，支持 `-Width 1024 -Height 768` 或2560×1080。三个Seed各走普通场、真实传送和Boss；包含零物件密度与技术失败保留本局的实际路径。

最终运行结果、图像、构建/日志和资产哈希见[验证目录](Verification/RandomLayers_20261104/README.md)。原生检查及截图不能替代真人对密度、绕行体验、视觉风格与性能的验收；本任务未生成新Windows包。
