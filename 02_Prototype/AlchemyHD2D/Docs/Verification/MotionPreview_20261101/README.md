## 复跑与限制

先编译Editor，再运行`Tools/PreviewLilitaMotion.ps1`；每次在项目Evidence/MotionPreview_20261101的时间戳目录捕获。只编码已有帧可用`-EncodeOnly -Frames <绝对目录>`。复用项目SSD的01_Skill/tools/ffmpeg，无新依赖；脚本检查原生结果、完整帧序列、20FPS/分辨率/帧数及完整解码。

预览不是逐帧等价的正常Tick回放：UpdateFeedback位于事件后，新Niagara管理寿命可能当帧多推进0.05秒，死亡暂停也可能早一帧；不用于VFX精确时序验收。固定可见也不呈现完整受击无敌闪烁。单画幅静音演示不能替代自然移动/战斗、声音辨识、性能、最终动作连续性或风格定案。未Cook、打包或发布；视频是预览材料，旧Windows试玩包未更新，长期目标继续。
