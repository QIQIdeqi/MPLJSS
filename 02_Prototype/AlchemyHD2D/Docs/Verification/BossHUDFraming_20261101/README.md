# 制作人：4:3 Boss角色与HUD避让

2026-11-01，北京时间；基线`b9341b5`。上一阶段确认的莉莉塔/技能栏、Boss头部/计时遮挡，已在中央准备期和选定近距离构图中修复。制作人负责实现和原生验收，关卡岗位定位视口与UI比例差异，UI/引擎岗位复核安全带与移轴计算。

## 行为与取舍

原相机按完整视口的76%高度容纳双角色，但4:3下参考HUD居中等比显示，其计时器和技能栏占据这段取景范围。现在读取实际TimerText下缘、SkillGroup上缘，留4像素间距，约束双角色取景高度和移轴中心；布局几何尚未就绪时用原1672×940布局回退。扩大视野立即满足当前所需范围，随后在源图边界允许的区间内限制移轴。

固定眼点、60°俯角、场景画片及注册、32×26m椭圆、10m入场间距和2秒准备期保留。普通村庄/战斗路径不使用这段Boss双人约束；Widget资产未重建或移动。

**4:3准备期会暂时拉远以完整容纳双方。** 开战近景的角色画布高约143.4px，普通战斗约163.8px，比例87.5%，仍满足原15%近景偏差检查；准备期约113.5px。1280×720、2560×1080的开战近景/普通战斗比例均约100%。不把准备期的双人取景说成角色尺寸处处相同。
