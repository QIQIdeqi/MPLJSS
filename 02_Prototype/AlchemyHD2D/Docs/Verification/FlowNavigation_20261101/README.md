# 结算导航与保存失败恢复验收

2026-11-01，北京时间。基于`d84238e`及本轮修改。生产改动仅Action分发、HUD入口及提示，不改掉落、数值、地图或Boss自由入场条件。

## 修复

- 胜利/失败结算页顶部“Esc 返回”现在回村，与底部返村、键盘Esc一致。原先`close`在Flow分发后才被转换，误落入直接StartRun路径。
- 保存失败时，在面板导航与字号操作之前拦截，只允许重试。原先可先进入字体页，再通过返村/新开局丢失尚未入账的RunCoins。字体入口现禁用，顶部“Esc 重试”与正文“重试保存”均走同一重试动作。
- Flow开局提示改为实际可用的WASD/Space/Q/B/Esc，不再声称R可重开。非Flow预览原有R操作保留。
- Boss确认页补全当前清理事实：未拾金币、经验球、精英宝箱不会带入，确认后消失；材料容量回收、当前生命/技能/冷却、胜负前不能返回的原说明保留。没有改变或新冻结掉落收益设计。
