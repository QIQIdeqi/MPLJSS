## 已确认和修复

使用原图提取清单、已保存的当前原生1672×940帧和实际Widget参数比较。新增[只读比对工具](../../../Tools/CompareReferenceHUD.py)，只读取截图和PNG并写JSON，不编辑图片、纹理或蓝图树。它仅比较指定11项图元alpha=255的像素，排除透明边缘、动态数字、条内填充、技能图和地图内容，不能据此宣称整HUD逐像素1:1。

修复前头像/徽章、闪避框、计时两侧装饰、骷髅/金币、加号与经验框共9项、30,192个不透明像素在原位置RGB完全一致。小地图框有120个像素被后绘制的动态格子覆盖，最佳±3像素位移仍为0，属于绘制层问题。NativePaint现用MapGeometry的绝对坐标PushClip/PopClip，把数据限制到提取框的透明内孔[7,7]–[242,141]；标记保留原映射，中心夹到X12–237/Y12–136，容纳最大±5像素十字，不重新缩放地图位置。

当前原生截图小地图框4,524个不透明像素全部恢复RGB完全一致，累计10项、34,716个不透明像素一致。见[修复前数据](before.json)、[修复后数据](after.json)及[hud-1672.png](hud-1672.png)。本轮未重建Designer树或修改Widget/纹理资产。
