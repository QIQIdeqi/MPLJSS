## 原生验证

`EnemyBehaviorChecks.inl`将生产表复制到内存，连续追加变体行，并逐例调用真正的ReadEnemyDefinitions校验。使用固定合法整数轴走廊摆放玩家与敌人，禁用夹具内的自然波次、自动武器、精英和商人，然后允许真实World.Tick继续执行敌人AI与UpdateShots，不以直接调用Hurt冒充AI攻击。

10例包括基础/Tuned两种来源各自的Contact、Area、Ranged零伤害6例；Min=Keep=200、Max=Keep=750两个端点；199和751两个边界外对照。逐例验证真实生成/精确距离、攻击前摇或弹丸产生/回收、HP、受伤无敌及动作状态；端点还观察单次弹体和冷却递减。零伤害后另行直接Hurt(0.1)验证最低1点、紧接Hurt(8)验证正常受伤保护，这两项明确是直接控制。

Editor/Game构建、常规制作人及Boss回归、377文件保护结果也记录在verification.json。377包含364资产/地图、11真实存档、品质及怪物种子CSV各1；生产资产与数值未被此夹具覆盖。EnemyBehaviorTest在存档读取前启用bCapture，常规启动不会进入此检查；内存变体及合成战斗状态不写回生产资源或玩家存档。

## 复跑与范围

编译Editor后串行运行`Tools/TestEnemyBehavior.ps1 -FPS 60`与`-FPS 10`。脚本使用本机D盘UE5.8与工程ASCII联接入口，nullRHI、benchmark固定步进；180秒上限只终止本次进程。

这是固定配置的原生逻辑验证，不是渲染截图、自然刷怪、真人战斗手感或性能验收。夹具将移动速度设0，未新增验证追逐/退避；Hybrid范围优先和原移动分支由源码核对保持，没有新增专项证明所有混合配置。CollisionRadius仍服务净空/碰撞/寻路，不擅自绑定接触攻击距离。未调整现有怪物数值、素材、波次、奖励、自由Boss准入或待批准品质表；未重新Cook、打包或发布。
