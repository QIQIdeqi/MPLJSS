## 计量边界

库存逐helper帧观察；地面/field每至少0.25个observedElapsed秒采样，另含帧量化。`firstFieldAvailable`必须是同一采样时刻三种材料各自位于库存或有FindPath45可达掉落，不取三种历史首次时间的最大值。它可以包括屏外掉落；机器人只追视口内可见的缺料。

两例`库存齐备−field齐备`的原始观察差为−0.167/−0.233秒。先后未分辨，实际非负回收耗时未测；不截断为0。死亡例两时间均未观察，其差为null，不能把−1−(−1)算成0。一般正差也只是观察差，非精确回收耗时；误差需依据相邻样本的实际observedElapsed间隔，不能硬标±0.25战斗秒。

无可达供给被观察到不能区分未掉落、掉在不可达区、路径判断失败或采样遗漏。HUD证据是上一绘制帧的文字集合，不是OCR或肉眼阅读验收。菜单暂停RunTime，observedElapsed包含菜单帧；同一RunTime的Craft/Accept不表示同一物理帧或零操作耗时。wallElapsed还包含StartRun建场，不能混用。相同种子跨画幅也可能消耗不同随机数，不作分辨率因果比较。

## 策略与隔离

使用生产移动、碰撞、拾取、自动攻击、闪避和菜单动作；每0.5秒重规划FindPath45，优先可见缺料，其次绕最近敌人保持距离/固定巡逻点。炼金前保持300–500cm、160cm内可闪避；炼金后140–180cm、90cm内应急闪避。方向量化为相机相对八方向，升级选首项，材料齐备至少等0.25个observed秒再开炼金。菜单为快速调用生产动作，不是物理按键或人类反应。

没有加血、加材料、清怪、改出生、传送、改时钟、改概率或改波次。新进度与种子仅用于初始化实际StartRun。读取存档前启用既有bCapture隔离；常规启动不进入这些钩子。存档、资产和品质表保护及构建/回归结果见[verification.json](verification.json)。
