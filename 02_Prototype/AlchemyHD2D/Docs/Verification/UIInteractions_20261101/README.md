# UI交互与概率显示验收

2026-11-01，北京时间。基于Git `4b84ffe`及本轮修改；正式参考图UMG保持，修改集中在原生HUD交互，不重建Widget或导入美术。

## 本轮修复

- 正式战斗HUD左下的“Esc 暂停”可点击。按字体实际测量定位，只该文字片段注册热区，Q/B提示不受影响；悬停变金色。
- 顶部“Esc 返回”与暂停菜单“继续游戏”原来同名，Unreal拒绝注册第二热区。顶部使用独立`modalclose`并转发既有`close`动作，两个入口均可命中与关闭。
- 炼金锅同种材料多份原来共用热区名称，只有首格能点击。每格名称增加槽序号，前导编号仍指向对应材料；十格均可取回一份，未炼成前不改变库存。
- 品质概率显示两位小数，含被过滤候选的`0.00%`和归一化后的`66.67% / 33.33%`。本轮不修改品质权重。
