超宽实拍能看到地面圆与1.5秒提示，玩家靠近后重新完整预警，随后对应位置出现原精英贴图。小画幅走严格屏外分支，没有圆圈符合预期；生成后的精英仍在主视野之外，小地图出现红点，不把这些图称为目视验过屏外精英贴图。三画幅均未通过移动敌人位置来排布截图。

[机器摘要](verification.json)保存结果、实际日志断言及去重名称数量、日志哈希、编译与真实存档指纹核对结果。超宽覆盖33条日志断言、26种去重名称；另外两种画幅各27条、20种。六类面板暂停检查与重复截图检查有重复名称，不能把总断言数当独立功能数。

验收涵盖：预检不提前生成／记奖励、真实半径与路径、当前属性速度和一次闪避距离缓冲、玩家靠近后的重警、暂停／炼金／技能／结果／升级／传送确认冻结、伤害与核弹不影响预约、一次实际生成才推进90秒调度与轮换、重开和真实Boss切场清理、普通与Boss同步语义。另让真实生产Tick从约88.5秒推进至90秒，三画幅均只生成一个精英，超宽实际经历预警，未只测试手动调用helper。

首轮截图同帧创建并采集Primitive，曾出现缺圈及黑块。最终截图拆到后续实际绘制帧并等待Editor资源编译，使用原有地面Disc和原怪物材质；独立禁深度材质试验已撤回生产并归档SSD Evidence，不作为修复资产。关卡/UI岗位查看最终9张图。图片属于隔离进度下的原生测试取证，不能替代真人手感、平衡、音频或性能验收。

复跑：先编译Editor，再执行`Tools/TestEliteSpawn.ps1 -Width 2560 -Height 1080`；另两画幅按表指定宽高。原UI、动态图鉴、制作人、Flow、Boss规则及超宽统一镜头另作回归；详细数字以机器摘要为准。没有重新Cook或打包旧Windows试玩。

当前工程安全参数与边界见[配置合同](../../局内战斗表现与怪物配置.md)。无合法安全点时仍每1秒重试，不绕过碰撞或路径；严格脚本`SpawnEnemy`在超宽中心仍可能拒绝精英，它没有被改成异步函数。解决的是自然精英刷新因屏外空间不足而持续等待的当前默认场景。
