## 仍未证明的部分

高白/高亮边界只是近似读数，不证明整句逐像素相同。等级字段外包围盒对齐不等于前缀Lv和数字的每个笔画一致；参考前缀与数字的视觉高度有区别，现用DejaVuSerif统一字号，字宽、字形和局部文字层级仍待收口。HP字体/位置与框图残留的10个原数字像素有耦合，保持待决，不在本轮用重排掩盖残字。

UI岗位确认字宽并非全局等比例偏大：旧截图Level65/参考56、HP93/84、Timer91/87、Kills41/41。SSD现有STIXGeneral及OFL许可可作后续隔离候选；PIL等可见高18时Lv12较窄，但也会缩窄目前宽度已接近的击杀数字。因此本轮没有全局替换字体，也不能确定参考图使用哪款字体。没有下载或引入新的字体依赖。

HP残字、小地图底纹亮斑和技能占位素材继续按[前轮差距报告](../UIReferenceAudit_20261101/README.md)维护；像素脚本/美术净图问题仍待用户选择。本轮不以四个Y坐标证明整个HUD 1:1完成。
