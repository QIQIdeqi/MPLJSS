运行方式
双击同目录的“启动完整试玩.cmd”，从 Greyford_Flow 村庄开始。
保留整个 Windows 文件夹；游戏可在未安装 Unreal Engine 的 Windows 电脑上运行。
本目录是未压缩的可玩包，没有 ZIP 文件。源码更新不会自动改变已打包程序。

操作
WASD 移动；Space 闪避；F 与设施或传送阵交互；Q 局内炼金；B 局内技能管理；
C 局外图鉴；Esc 暂停或返回。战斗中的技能自动施放。

流程
村庄 → 草原战斗 → 5:00 后可选择进入独立 Boss 战场 → 胜负结算回村。
炼药保留随机结果；普通材料的种类决定结果池，投入数量影响权重。
这是战斗 V0.2 十轮迭代后的当前工程构建，不等于策划案全部内容已验收。
