# 战斗反馈与 Niagara

2026-10-27，UE5.8.4原型实现。

- 字号：现使用F7分层调试，小号固定100%，中号/大号默认90%/72%，独立±1%/±5%调整，详见PC_UI.md。此前全局档位属于历史实现。
- 怪物：普通怪受伤显示小血条，精英常驻，Boss使用原顶部血条；实际扣血值向上飘出，分三条水平偏移避免完全重叠。命中时短暂挤压精灵。
- 单体/弹丸和范围技能通过同一个DamageEnemy入口处理实际扣血、数字与粒子；不改伤害数值、怪物血量、波次或掉率。
- /Game/VFX/NS_AlchemyImpact：径向命中火花；NS_AlchemyBlast：范围爆发；NS_AlchemyTrail：短寿命弹丸尾迹。火橙、冰蓝、酸绿、魔紫，使用自定义柔边加法材质和实例Tint。复制UE自带模板到本工程后修改，不改引擎原资产；生成代码在AlchemyVFXBuilder.inl，仅编辑器目标编译。
- 普通技能短时效果使用Niagara；敌人红色地面预警仍用原地面标记，保留危险范围信息。打开局内面板暂停粒子模拟与数字寿命，关闭面板继续；返回据点清空。
- 最多48个粒子组件、每帧最多6次受击粒子、96个数字；尾迹弱引用，组件到期销毁。限制只避免无界堆积，不构成满场性能结论。

复现：编辑器运行-AlchemyBuildVFX生成工程资产；-AlchemyFeedbackCapture为隔离渲染场景，检查真实粒子、伤害数字、血条、暂停及清理，不读写玩家进度。最终验证见Verification.md。

边界：这是第一轮可运行特效改进，未逐个技能制作独立演出、音效或正式美术资产；完整五分钟平衡、数百敌人帧耗与用户审美验收待试玩。
