# 冒牌炼金术士 · UE5.8 全2D片 HD2.5D 预研

本版是可玩技术原型，供验证全2D片场景、镜头和炼金循环。不是四份主案的完整验收版本，也不是最终美术。

## 启动

优先双击工作区 `03_Build/HD2D_v0_1/启动Demo.cmd`，可运行独立Windows版，无需打开编辑器。请保留同目录的完整Windows文件夹。

本机也可以右键 `LaunchDemo.ps1`，选择使用PowerShell运行。脚本优先启动上述打包版；没有打包版时，调用已安装的 `D:\02_UnrealEngine\UE_5.8`（已核验5.8.2），直接进入可移动村庄。

为避开 MSVC/UBA 在中文路径下的编译问题，工具通过 `D:\03_UEProject\AlchemyHD2DResearch` 目录链接访问本工程。链接与工作区里的工程是同一份文件，不是副本。源码、贴图源文件、UE资源、证据与说明均在本 SSD 工程内。

## 操作

| 按键 | 行为 |
|---|---|
| WASD | 按镜头屏幕方向移动；D向右、A向左 |
| Space | 2.8单位冲刺；位移0.24秒；冷却2秒；闪避无敌0.65秒 |
| F | 靠近据点设施后交互 |
| Tab / C / B | 炼金 / 图鉴 / 技能储备；局内打开时暂停全部模拟 |
| Esc | 暂停、关闭界面；结算后返回据点 |
| F6 | HD2.5D实验面板 |
| F1 / F2 / F3 | 正交与透视 / 角色受光 / 面向相机与竖直平面 |
| F4 / F5 | 48°与35°俯角 / 景深开关 |
| [ / ] | 缩小 / 放大视野宽度 |

前往村庄上方门框附近按F进入关卡选择；左侧图鉴台、右侧强化台也可靠近按F。原系统案写E，后续V0.2修改方案写F；当前新工程采用后者。按键重映射尚未制作。

## 本版已有的闭环

- 全部可见几何为Plane：地面、道路、房屋、树、石头、门、炼金台、角色、投射物和效果均使用2D片；没有立体房屋、圆锥树或球体角色。
- 像素贴图使用Nearest、不生成Mip；场景片接受光照；角色可比较自发光与受光。前后遮挡由深度测试决定；落地阴影也用2D圆片。
- 固定村庄三设施；固定战斗地图；屏幕相对移动、障碍和边界限制、独立受伤/闪避无敌计时。
- 自动魔弹、普通怪生成、自动拾取、三类普通素材和三类精英素材、自由组合炼金、九个可制作技能、6个装备位与6个储备位、装备交换。
- 无效合成不扣料；库存上限10；重复制作升级至5级；满级与容量不足时先拦截；图鉴未发现时隐藏精确配方。
- 两套自动连锁及首次触发图鉴解锁；局外金币、配方发现、连锁发现和线性天赋树保存。
- 普通波次采用数值主案W0–W5+：开局8只、300总存活上限、分波最低目标和独立批量；1:30起每90秒精英轮换；5:00预警、5:10生成最终Boss。
- 暂停后返回据点二次确认；胜负或提前退出结算已拾取金币，清理临时材料/技能。

## 规则来源与边界

按用户最新要求使用UE5.8、斜俯视HD2.5D和全2D片搭建；不沿用主案中的Unity与正俯视2D技术设定。

玩法数据引用 `00_Doc` 中四份V0.1主案的关联章节；冲突项采用《Demo 修改方案》V0.2：材料上限10、无效不扣料、储备6、线性天赋。没有修改源策划文件。

默认启用TUNE-001B测试值（玩家120生命、普通敌人逐项降压）和DROP-001测试掉率15.4%=22%×70%。可在据点的实验面板单独切回原始基线。它们仍是待平衡验收的测试值，不能称为已证明更好玩。

地图按100cm对应主案1世界单位换算，战斗边界14222×10760cm，约为默认16:9、48°正交视野的5×5屏。屏幕分辨率/缩放变化会影响屏幕单位比值。

## 明确尚未完成

- Boss只制作了追击、范围预警、范围伤害和50%血量双阶段转换，尚未还原完整横扫、弹幕、冲撞及交叉裂波的独立选择池、权重和动画命中帧。
- 精英使用简化行为，普通怪近战/远程也只是首版近似；尚未达到全部战斗主案验收项。绕障使用局部滑移，复杂导航规则仍待确认。
- 当前雷链/酸蚀等为原型表现；减速暂共用一个系数，未逐项还原25%/30%/40%；缺少正式特效、伤害飘字和音效。
- 所有角色与环境均为本次脚本绘制的原创占位图，未使用参考游戏素材；角色只有正背面与横向翻转，未完成正式四向/八向动画。
- 主菜单仅有暂停入口快捷功能；设置、音量、键位重映射、完整图鉴搜索筛选、存档备份恢复尚未实现。当前存档使用UE原生SaveGame，不宣称已满足主案完整容错要求。
- 参数目前集中在源文件数组与可编辑研究属性；未制作数值Excel导入与完整DataTable编辑流程。关卡在运行时搭建，编辑器地图本身是入口图。
- 没有测出稳定GPU耗时、最低配置或数百敌人的性能结论；不能用烟雾检查代替平衡或性能验收。

## 验证与证据

`Evidence/build-editor.log`：编译结果；`bootstrap.log`：资源生成/导入结果；`smoke.log`：逻辑烟雾检查；`capture.log`：UE直接渲染截图。最终检查状态见 `Docs/Verification.md`。

`Tools/Smoke.ps1` 会在独立测试进程运行，隔离存档写入。时间跳转仅存在于明确的 `-AlchemySmoke` 参数下，不改变正常5:00/5:10流程。`-AlchemyCapture` 仅用于自动构图和截图，也不写进度存档。

`ArtSource` 保存PNG源图；`Tools/make_art.py` 可重建原创占位贴图；`Tools/bootstrap.py` 供UE Python导入资源；`Source`为UE C++原型；`Content`为已导入原生资源；`Evidence`保存验证材料。

参考：[Rogue's Odyssey Demo官方页面](https://store.steampowered.com/app/5065480/)。本次直接查看其截图，参考像素角色与斜俯视空间的表现关系；不推断该游戏实际引擎、镜头投影或内部渲染实现。
