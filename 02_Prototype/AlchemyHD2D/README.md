# 冒牌炼金术士 · UE5.8 全2D片 HD2.5D 预研

本版是可玩技术原型，供验证全2D片场景、镜头和炼金循环。不是四份主案的完整验收版本，也不是最终美术。

## 启动

优先双击工作区 `03_Build/HD2D_PC_UI/启动Demo.cmd`，可运行本次PC字体及HUD更新的独立Windows版，无需打开编辑器。请保留同目录的完整Windows文件夹。03_Build仅保留本最新版；旧运行包已移除，历史验证记录保留在工程Evidence中。

本机也可以右键 `LaunchDemo.ps1`，选择使用PowerShell运行。脚本运行上述完整打包版；编辑工作使用“打开关卡与技能编辑器.cmd”。本轮2026-10-27核对Build.version及真实进程日志为5.8.4（CL58902052）；此前5.8.2为历史验证环境。

为避开 MSVC/UBA 在中文路径下的编译问题，工具通过 `D:\03_UEProject\AlchemyHD2DResearch` 目录链接访问本工程。链接与工作区里的工程是同一份文件，不是副本。源码、贴图源文件、UE资源、证据与说明均在本 SSD 工程内。

## 操作

PC界面：按F7或面板右上入口打开字体调试：小号固定，中号/大号独立±1%/±5%，推荐90%/72%，即时生效并保存。↑/↓移动界面焦点，Enter确认，鼠标点击和拖拽照常；长内容分页。新字体按显示字号直接栅格化，不再缩放默认9点字形。已检查720p、1080p和2560×1080超宽屏，详见Docs/PC_UI.md。

| 按键 | 行为 |
|---|---|
| WASD | 按镜头屏幕方向移动；D向右、A向左 |
| Space | 2.8单位冲刺；位移0.24秒；冷却2秒；闪避无敌0.65秒 |
| F | 靠近据点设施后交互 |
| Tab / C / B | 炼金 / 图鉴 / 技能储备；局内打开时暂停全部模拟 |
| Esc | 暂停、关闭界面；结算后返回据点 |
| F6 | HD2.5D实验面板 |
| F1 / F2 / F3 | 正交与透视 / 角色受光 / 面向相机与竖直平面 |
| F4 / F5 | 48°与35°俯角 / 景深开关 |
| [ / ] | 缩小 / 放大视野宽度 |

前往村庄上方门框附近按F进入关卡选择；左侧图鉴台、右侧强化台也可靠近按F。原系统案写E，后续V0.2修改方案写F；当前新工程采用后者。按键重映射尚未制作。

## 本版已有的闭环

- 全部可见几何为Plane：地面、道路、房屋、树、石头、门、炼金台、角色、投射物和效果均使用2D片；没有立体房屋、圆锥树或球体角色。
- 像素贴图使用Nearest、不生成Mip；场景片接受光照；角色可比较自发光与受光。前后遮挡由深度测试决定；落地阴影也用2D圆片。
- 固定村庄三设施；固定战斗地图；屏幕相对移动、障碍和边界限制、独立受伤/闪避无敌计时。
- 自动魔弹、普通怪生成、自动拾取、三类普通素材和三类精英素材；ALCH-002七组普通材料组合、21个普通技能及3个精英专属技能，6个装备位与6个储备位。
- 无效合成不扣料；库存上限10；重复制作升级至5级；满级与容量不足时先拦截；图鉴未发现时隐藏精确配方。
- 十套自动连锁替换旧两套；首次实际触发后解锁新连锁图鉴，卸装暂停并保留剩余冷却。局外金币、技能/组合发现和线性天赋树保存。
- 普通波次采用数值主案W0–W5+：开局8只、300总存活上限、分波最低目标和独立批量；1:30起每90秒精英轮换；5:00预警、5:10生成最终Boss。
- 暂停后返回据点二次确认；胜负或提前退出结算已拾取金币，清理临时材料/技能。

## 规则来源与边界

### ALCH-002（2026-10-27）

- 普通素材改显示名为火粉、露水、魔法碎片；旧ID保留。单次普通炼金3–10个，材料种类决定七组结果池，数量决定低/中/高权重。仅显示候选过滤后的实际概率，不预告具体技能。
- 炼金界面左炉右背包；普通素材支持点击或拖到炉中投入1个、点击炉内材料取回。精英素材仍使用固定配方。
- 新玩家首次只能三料各1个，品质正常随机。约35秒有效战斗时间后，每次击杀额外补1个缺少种类，考虑库存和地面待拾取材料；原随机掉落不变。材料齐备提示主动打开；新范围技能单次命中至少2个不同敌人后永久完成。失败未完成，下局完整重试。
- 老存档有金币、天赋或发现记录视为已玩过，跳过新教学；只有文件而无上述进度不跳过。保留成长和原技能发现，七组合及新十连锁重新发现。旧存档迁移前写入AlchemyResearch_backup；主档不能读取时尝试备份，两者都无法读取则拒绝覆盖。
- 技能映射采用工作区《ALCH-002_技能分配草案》。配置表位于AlchemyWorld.cpp的Skills、CombinationSkills、QualityWeights、Chains。旧六技能保留ID；石刺冷却暂调2秒；其余新增效果及数值为原型初值。施法中心、减速强度及跳跃数量逐技能配置，设计距离按100cm/单位换算。
- `-AlchemyUI` 为隔离界面检查入口，提供测试材料、停在炼金界面，不读写真实存档。普通启动不启用。`-AlchemySmoke` 包含ALCH002_CHECK检查及原有地图/时间轴回归。

详细确认规则与待验证内容见工作区 `00_Doc/系统/ALCH-002_规则确认与实施补充.md`。尚未证明40–60秒首次炼金、同组品质在所有战斗场景下递进或七组玩法差异成立，需人类试玩验证。

按用户最新要求使用UE5.8、斜俯视HD2.5D和全2D片搭建；不沿用主案中的Unity与正俯视2D技术设定。

玩法数据引用 `00_Doc` 中四份V0.1主案的关联章节；冲突项采用《Demo 修改方案》V0.2：材料上限10、无效不扣料、储备6、线性天赋。没有修改源策划文件。

默认启用TUNE-001B测试值（玩家120生命、普通敌人逐项降压）和DROP-001测试掉率15.4%=22%×70%。可在据点的实验面板单独切回原始基线。它们仍是待平衡验收的测试值，不能称为已证明更好玩。

地图按100cm对应主案1世界单位换算，战斗边界14222×10760cm，约为默认16:9、48°正交视野的5×5屏。屏幕分辨率/缩放变化会影响屏幕单位比值。

## 明确尚未完成

- Boss只制作了追击、范围预警、范围伤害和50%血量双阶段转换，尚未还原完整横扫、弹幕、冲撞及交叉裂波的独立选择池、权重和动画命中帧。
- 精英使用简化行为，普通怪近战/远程也只是首版近似；尚未达到全部战斗主案验收项。布局 A 已使用静态矩形可见性图绕障；普通35cm、精英70cm、Boss110cm半径分别处理，阻挡路径最多每秒重算。大型动态群体、复杂导航与性能仍待实测。
- 当前雷链/酸蚀等仍为原型表现；减速强度及持续时间已按技能/连锁独立配置，叠加时采用最强减速和最长剩余时长；缺少正式特效、伤害飘字和音效。
- 所有角色与环境均为本次脚本绘制的原创占位图，未使用参考游戏素材；角色只有正背面与横向翻转，未完成正式四向/八向动画。
- 主菜单仅有暂停入口快捷功能；设置、音量、键位重映射、完整图鉴搜索筛选、存档备份恢复尚未实现。当前存档使用UE原生SaveGame，不宣称已满足主案完整容错要求。
- 参数目前集中在源文件数组与可编辑研究属性；未制作数值Excel导入与完整DataTable编辑流程。关卡在运行时搭建，编辑器地图本身是入口图。
- 没有测出稳定GPU耗时、最低配置或数百敌人的性能结论；不能用烟雾检查代替平衡或性能验收。

## 布局 A 本轮实施（2026-10-26）

本轮按用户要求逐项评审并落地关卡灰盒，源策划案顶部新增同步口径，不将本轮测试当成最终平衡结论。

- 战斗地图保持14222×10760cm；出生改为世界(0,0)。中央48×32设计单位为开阔区。
- 四组8段固定矩形灰盒替换旧24个岩石与随机树碰撞；战斗树只在外围作无碰撞装饰。村庄保持原布局。
- 默认相机yaw90°：设计坐标x向右/y向下对应UE世界X=-100x、Y=-100y。矩形用转换后的中心和半尺寸，保持全2D Plane表现。
- 生成采用数值案现有权重与分批补充，最低数量统计总存活敌人；波次、上限、精英90秒间隔、5:00/5:10时序不变。
- 生成点随机40次失败后扫描离屏矩形，Boss至少距玩家800cm；半径为普通35/精英70/Boss110cm。没有合法点会输出日志，不能用无限延迟声称准点验收。
- 敌人遇阻时在8个矩形的膨胀角点图上寻路并缓存路径，最多每秒重算；玩家贴墙时大型单位选择附近可达接近点。没有使用NavMesh或增加行为树。
- 精英箱保底定义为箱内产出。库存上限10优先，满额部分不入库、不转货币；一次性开箱，显示实际入库量及满额提示，不再把未入库部分宣称已获得。
- HTML工作台与导出JSON已同步为V0.3：10项本轮采用，4项仍需验收（动态绕障/性能、数值测试优劣、6:00叠加体验、完整Boss空间）。

检查：编辑器编译通过；真实UE逻辑进程通过布局8段、坐标方向、三半径27条路径/27次生成、3种半径实际移动绕墙、原有炼金/暂停/边界/时序及6:00精英。见Evidence/smoke.log。过程使用隔离测试模式，不写玩家进度。

渲染检查命令使用 `-AlchemyLayoutCapture -RenderOffscreen`，输出 `Evidence/LayoutA_Top.png` 与 `LayoutA_Local.png`，不改变正常游玩镜头或计时。Windows可运行包放在工作区03_Build/HD2D_PC_UI；本轮打包结果见Docs/Verification.md最新补记。


战斗反馈：普通怪受伤血条、精英常驻血条、实际伤害飘字，以及Niagara命中/范围爆发/弹丸尾迹，规则与边界见[Docs/CombatFeedback.md](Docs/CombatFeedback.md)。
